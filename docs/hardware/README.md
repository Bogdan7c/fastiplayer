# Hardware evidence

Ранее в корне находился Vulkan capabilities dump для Intel UHD Graphics 620
(KBL GT2), driver 26.0.5, экспортированный через `vulkaninfo`.
Полный исходный JSON сохранён вне репозитория в приватном backup сессии S04:
он содержит `deviceUUID` и другие идентификаторы устройства.

Dump описывает возможности конкретного устройства и драйвера. Сам по себе он
не доказывает успешное декодирование, рендеринг, HDR output или производительность
Rustiplayer. Публичное hardware acceptance должно сопровождаться отдельными
проверками реального воспроизведения и описанием условий измерения.
