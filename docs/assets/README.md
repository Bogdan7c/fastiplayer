# Runtime assets

`rustiplayer-t480s-main.png` is an unedited capture of the actual Rustiplayer
window playing the owner-supplied AV1 4K60 SDR fixture on a ThinkPad T480s,
in a native Wayland window. It was captured with Spectacle, not generated
from a design concept. Capture source, executable checksum and experimental
scope are recorded in the [T480s report](../benchmarks/thinkpad-t480s.md).
