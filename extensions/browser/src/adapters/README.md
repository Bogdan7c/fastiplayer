# Адаптеры сайтов

Каркас. Адаптеры конкретных сайтов (подсказки о названии, длительности, серии) появятся в сессии 14,
см. `user/browser-bridge/`.

`ad-organs/` — уже живой узкий контракт `AdOrgans` (`matches`, `readAdState`, `pressSkip`) с читателями YouTube,
IMA и PlayerJS (сессия 09d); адаптеры сессии 14 войдут в него же, а не заведут свой путь к рекламе.

`subtitle-naming/` — именование документа субтитров страницы по его адресу (сессия 13b2, решение 276): адаптер
timedtext YouTube (язык из `tlang`/`lang`, `kind=asr` — автосубтитры) и общий читатель параметров `lang`/`language`.
Чистые функции без глобального `URL` (страница его подменяет); каркас 14 заберёт их в общий путь адаптеров.
