# Адаптеры сайтов

Адаптер — «пульт» от плеера конкретного сайта (сессия 14, решения 17, 19, 44, 279–283): что сайт показывает
(реклама, озвучки, качества, серии) и как нажать его кнопки. Качает по-прежнему страница.

## Раскладка

- `sites/<сайт>/` — всё, что знаем об одном сайте или семействе плееров: паспорт `identity.ts`
  (имя и версия для журнала разработчика), селекторы-данные и способности (`ad-organs.ts`, `timedtext-naming.ts`, …).
- `capabilities/<способность>/` — общий контракт способности и общие помощники, без знания конкретных сайтов:
  - `ad-organs/` — органы рекламы `AdOrgans` (`matches`, `readAdState`, `pressSkip`), сессия 09d;
  - `subtitle-naming/` — именование документа субтитров по адресу, сессия 13b2 (решение 276).
  - `variants/` — озвучки, качества и следующая серия `VariantAdapter` (сессия 14b); `quality-label.ts` —
    подпись качества ступенью «720p» для сайтов, где память выбора одна на весь сайт (15a, решение 289);
  - `player-hand/` — белый список вызовов функций плеера сайта в MAIN-мире (14b, решение 282).
- `registry/` — два реестра, по одному на мир, где код работает. Каждый бандл тянет только свой:
  - `isolated-world.ts` — изолированный мир фрейма (контент-скрипт): читает DOM и нажимает кнопки;
  - `page-world.ts` — мир страницы (MAIN): то, что живёт внутри скрипта страницы.
- `site-identity.ts` — паспорт адаптера.

## Правила

- Адаптер не видит портов, хранилища и прав фона: ему дают только взгляд на страницу.
- Текст страницы — враг (инвариант 1): наружу выходят только проверенные метки и числа.
- Ошибка адаптера — не ошибка экстеншена: передача видео идёт обычным перехватом.
- Новый сайт — папка в `sites/` и строка в нужном реестре.

## Сайты с вариантами

- `bench-series/` — страница «сериал» стенда (14b), отвечает только локальному хосту с меткой стенда.
- `youtube/` (15a) — рука-функция над элементом плеера `.html5-video-player`: качества, озвучки по коду
  языка, следующий ролик; память — одна на сайт. Shorts — без Next (16b).
- `twitch/` (15a) — рука-функция над `mediaPlayerInstance` React-компонента `.video-player`: качество
  эфира и записи; озвучек и серий нет.
