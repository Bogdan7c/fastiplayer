# Maintainers

Fastiplayer has **one core maintainer**:

| Name | GitHub | Responsibility |
| --- | --- | --- |
| Bogdan Korolyov | [Bogdan7c](https://github.com/Bogdan7c) | Core architecture, development, review, triage, and release decisions |

The global [CODEOWNERS](.github/CODEOWNERS) entry assigns review ownership to `@Bogdan7c`. It does not establish a larger review team or guarantee a response time. Contributors retain credit for their work in Git history; no additional core maintainers are implied.

Use [CONTRIBUTING.md](CONTRIBUTING.md) for contributions, [SUPPORT.md](SUPPORT.md) for bugs/questions/ideas, and [SECURITY.md](SECURITY.md) for private vulnerability reporting. The GitHub profile is an identity link, not a designated private security or enforcement inbox.

## Deliberately deferred community policy

A `CODE_OF_CONDUCT.md` is deliberately deferred until a separate private enforcement contact has been established and its handling responsibility agreed. No such contact is currently designated. Do not repurpose GitHub Private Vulnerability Reporting as a conduct-reporting channel. Contributors are still asked to communicate respectfully.

[GitHub Discussions](https://github.com/Bogdan7c/fastiplayer/discussions) and [Private Vulnerability Reporting](https://github.com/Bogdan7c/fastiplayer/security/advisories/new) are enabled. See [Support](SUPPORT.md) and [Security](SECURITY.md) for their respective routes. The project is open to support with development tools and equipment through Discussions.
