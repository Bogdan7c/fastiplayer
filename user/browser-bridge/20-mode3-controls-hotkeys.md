## Зачем

Решение 6: контролы и хоткеи наши, остальная страница живёт как обычно.

## Поправки по итогам 00b (29.10.2026)

- Фокус остаётся у страницы на всех столах (бэкенд возвращает его браузеру), поэтому хоткеи — пересылкой экстеншена; на X11 бэкенда нет, возврат фокуса делает само окно.

## Что сделать (ожидаемо)

1. **Протокол:** команды транспорта из экстеншена (play/pause, seek ±, громкость, mute, скорость, фуллскрин) — intent-сообщения, а не «нажата клавиша». Плеер выполняет их своим транспортом (`mem:player-core/command-delivery-reserve-ux17` — резерв очереди команд).
2. **Экстеншен:** перехват клавиш, когда фокус не в поле ввода. Зона настраивается (решение 58): вся страница кроме полей ввода (по умолчанию) или только зона видео / заглушки. Раскладка не латинская — по `code`, а не `key` (урок UX09 и B3).
3. **Фуллскрин:** кнопка фуллскрина страницы или F → наш фуллскрин; выход из нашего → страница в прежнем виде.
4. **Сайт со своими хоткеями** (YouTube) — наши в приоритете в зоне видео; конфликт записать в матрицу.

## Тесты

- Стенд: фокус на странице, пробел → пауза в плеере (состояние плеера, не нажатие); стрелка → seek; F → фуллскрин; фокус в поле ввода → клавиши уходят странице.
