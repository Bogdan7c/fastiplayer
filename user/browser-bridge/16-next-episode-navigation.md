## Зачем

Решения 16, 38, 42, 59. Вместо нашей очереди серии ведёт плеер страницы, и переход должен ощущаться как в обычном плеере.

## Что сделать

1. **Новая серия той же страницы** (MSE переподключён, новый init-сегмент, новая длительность) → новое поколение, заголовок обновлён, декодер пересоздан по правилам смены спецификации, окно и фуллскрин сохранены. Память выбора (14) выставлена до старта.
2. **Одностраничная навигация** (YouTube меняет ролик без перезагрузки): то же, что новая серия. Сайт ушёл на страницу без видео → «вкладка ушла» (решение 42).
3. **Полная перезагрузка страницы / переход на другую страницу** (решение 59): если в той же вкладке за пару секунд появилось видео того же сайта — продолжаем в том же окне, фуллскрин не слетает (новое поколение, как новая серия). Другой сайт или страница без видео — «вкладка ушла» (решение 42). Окно ожидания — настройка с разумным умолчанием.
4. **Live:** нет длительности, «живой край», переход live → запись.
5. **Сон и пробуждение** машины посреди просмотра → плеер страницы перезапрашивает → мы продолжаем; если страница сломалась — «вкладка ушла».

## Тесты

- Стенд «сериал»: конец серии 1 → автопереход → серия 2 в том же окне, **кадр в рендере**, A/V синхронны, озвучка та же; Next из плеера → то же.
- Стенд «одностраничник»: смена ролика без перезагрузки → новое видео, старые байты не попали в новое (поколения).
- Переход на следующую серию полной перезагрузкой (стенд) → то же окно, фуллскрин сохранён; переход на страницу без видео → буфер доигран → «Source tab closed» → окно закрыто.
- Стенд live.
