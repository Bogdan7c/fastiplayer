# Сессия 11a: заглушка и «Return»

Общий замысел и поправки — в [11-page-player-control.md](11-page-player-control.md). Разделение — решение 235.

> Выполни сессию 11a плана `user/browser-bridge/`: заглушка «Playing in Fastiplayer [Return]» поверх видео страницы, «Return» — видео играет на странице дальше, окно закрывается молча; поломка плеера сайта — конец как «вкладка ушла»; окно закрыли до первого кадра — страница на паузе (решения 236–238). Сначала прочитай `user/browser-bridge/README.md` и файл 11.

## Зачем

Решения 11, 12, 40, 42, 51, 52, 236–238. Человек в любой момент возвращается к странице, плеер сайта после этого полностью рабочий.

## Что сделать

1. **Заглушка** в закрытом слое страницы (10c) ровно поверх видео: едет за видео, работает внутри iframe, клики по видео не пропускает. Ссылку на элемент изолированному миру даёт MAIN-мир событием с секретным именем.
2. **«Return»** только по настоящему клику. Фон снимает тень на её секунде с игрой и закрывает связь кодом 4010 `viewer_returned_to_page`. Если уже идёт `return_to_page` — ничего, первое побеждает. Вкладка ссылки остаётся.
3. **Плеер сайта сломался:** ошибка элемента держится 5 с или источник снят сразу после ошибки — `tab_gone{page_player_failed}` (протокол 1.3, со старым плеером — `navigated_away`). Плеер досматривает и пишет «The page's player stopped…». Ошибка рекламного ролика при переходе к фильму сеанс не кончает.
4. **Дыра 238:** 4000/4001/4006 без прощания — страница на паузе.

## Тесты

- Экстеншен и плеер: фокусные тесты каждой границы, процессные тесты плеера (4010 — окно закрыто сразу и молча; `page_player_failed` — досмотр и свой текст).
- Стенд, Chromium и Firefox: «Return» настоящей мышью — страница играет с N ± 1 с, окно закрыто; закрытие окна — пауза на N; замена из второй вкладки — первая на паузе на своей секунде; «Return» вместе с закрытием — одно действие; после возврата перемотка, смена качества и следующая серия на плеере страницы; смещённое начало и вшитая реклама — правильная секунда; эфир — живой край; поломка плеера страницы — досмотр и сообщение; «Return» на вкладке ссылки — вкладка жива.
- Живая проверка на эталонных сайтах (передача по кнопке из 10).
