## Зачем

Решение 4 (PiP-вход в разведке, дальше — по вердикту). Все варианты режима 3 и PiP требуют управлять окном так, как winit сам не умеет на Wayland.

## Что сделать (ожидаемо)

1. **Crate размещения окна** (переиспользуемый, как рендер — для Fasticut тоже):
   - trait `WindowPlacement`: `keep_above(on)`, `place_at(geometry)`, `compact_pip(size, corner)`, возможности бэкенда (что умеет на этом столе);
   - бэкенды: KWin (скрипт или D-Bus, по 00a), X11 (EWMH), прочие — `Unsupported` с причиной;
   - швы Windows (`SetWindowPos`, `HWND_TOPMOST`) — только trait, без кода.
2. **Мини-окно PiP** в плеере: компактный вид без лишних панелей, «поверх всех» там, где можно; запоминание угла и размера; выход из PiP → обычное окно.
3. **Вход PiP** в экстеншене: хук `requestPictureInPicture` / `documentPictureInPicture` (09) → `OpenSession` с намерением «мини-окно»; страница — как в режиме 2 (заглушка, виртуальный элемент). Где «поверх всех» невозможно (GNOME) — решение владельца из 00b.

## Поправки по итогам 00a (29.10.2026, решения 73–75)

Подробно — `results/00a.md`, разделы «Находки» и «Требования к управлению окном».

**Плеер:**
- «Окно = видимая часть родного плеера» — фича плеера (решение 74): обрезка без масштаба, размер окна по видимой области, без зависимости от стола.

**Бэкенд размещения:**
- поставить окно в точку;
- держать над окном браузера, но не над всеми;
- спрятать и показать без пересоздания: winit 0.30 на Wayland `set_visible` не умеет;
- «поверх всех» для PiP;
- геометрия от композитора для «Театра».

**Окно «Наклейки»:**
- не берёт фокус;
- не попадает в Alt+Tab и панель задач;
- KWin активирует новое окно, это подтверждено живьём.

**KWin:**
- скрипт с долгим опросом по D-Bus;
- контракт строками: числа JS уходят как `int32`, ошибка `callDBus` до обратного вызова не доходит;
- сторожевой таймер;
- загрузка через `Scripting.start`;
- `bufferGeometry` для CSD-браузеров;
- порядок окон — через сигналы окна браузера: у `workspace` в KWin 6 нет `stackingOrderChanged`.

**Цена путей:**
- KWin двигает окно сразу, а картинка приходит кадром позже — 1–3 кадра.
- `layer-shell` обновляет всё одним commit — 1 кадр, но висит над всеми окнами, поэтому его надо прятать, когда браузер перекрыт.
- На X11 окно ставит себя само — 0–1 кадр.

Выбор — вердикт 00b.

**«Театр»:** размер от композитора (проверено), фокус у окна плеера или пересылка клавиш экстеншеном, выход по Esc и нашими контролами, обратная команда «плеер → страница» для паузы.

**Живые проверки:** вместо KDE X11 (решение 73) — Xwayland на KDE и Xfce X11 в приёмке.
