> Выполни сессию 10a2 плана `user/browser-bridge/`. Научи экстеншен отдавать нативный HLS: фон выдаёт номерки, переписывает плейлисты и качает ресурсы по запросам плеера, тень держит страницу для VOD и live. Стенд — до кадра в рендере в Chromium. Сначала прочитай `user/browser-bridge/README.md` (решения 186, 187, 199, 202, 228–230), этот файл, `results/10a1.md`, `results/09b.md`, `results/09c.md`, `mem:browser-bridge/core`.

## Что уже есть (разведка начала 10a)

- `page/element-source.ts`: `classifyMediaUrl` отдаёт `unsupported{native_hls}` раньше ветки файла. У `unsupported` поле `file_host` равно `null` (`page/video-candidates.ts`), поэтому проверка локального адреса для m3u8 сейчас не срабатывает.
- `background/handoff/video-choice.ts`: `HANDOFF_FORMS = ["media_source","file"]`.
- `background/tab-model/video-verdict.ts`: `native_hls` без игры и длительности — `empty` (Ashdi, оставить). Остальной `unsupported` проверяется раньше рекламы: HLS-реклама сейчас не получила бы `ad`.
- Цепочка файла: `file_source` → `startFileSource` → `range-fetcher.ts` с `localAddressBlock.around` и `fileReferrer.around`. Для ресурсов HLS нужен свой качальщик: целое тело или диапазон, без `ResourceIdentity`.
- Тень файла (`page/shadow/file-source-mode.ts`) останавливает элемент через `srcObject = new MediaStream()` — от формата не зависит. Для VOD, скорее всего, годится почти без правок. У live `duration` = `Infinity`, «весь файл» в `buffered` не подходит.
- В экстеншене нет разбора m3u8 и нет npm-зависимостей времени выполнения.
- Стенд: страницы `m3u8-in-src` и `native-hls`, ожидание отказа — `capture/refusals.rs`. Генератор `media/generate.sh` даёт один HLS: VOD, MPEG-TS, один вариант, 12 с. Chromium 156 на Linux нативный HLS играет, Firefox нет.

## Что сделать

1. **Форма видео.** `native_hls` с плейлистом в `src` становится передаваемой формой. Проверка локального адреса — как у файла. Незапущенный плейлист Ashdi остаётся «видео нет». HLS-реклама рядом с фильмом распознаётся так же, как файл.
2. **Стойка номерков в фоне.** Отдельный модуль на сеанс.
   - Таблица «номерок ↔ настоящий адрес» с потолком.
   - Корневой плейлист получает номерок 0 → `hls_source_added`.
   - Запрос плеера с чужим номерком — `refused`.
   - Смена поколения или конец сеанса гасит таблицу и все загрузки.
3. **Переписчик плейлиста** — не второй движок, а замена строк.
   - Строки-адреса и атрибуты `URI="…"` в тегах `EXT-X-KEY`, `EXT-X-MAP`, `EXT-X-MEDIA`, `EXT-X-I-FRAME-STREAM-INF`, `EXT-X-SESSION-KEY`, `EXT-X-PART`, `EXT-X-PRELOAD-HINT`, `EXT-X-RENDITION-REPORT`.
   - Относительные адреса считаются от адреса после редиректов.
   - Тот же адрес получает тот же номерок: обновление live не плодит записи.
   - Переписывается только ответ, который начинается с `#EXTM3U`.
   - Неизвестная схема, учётка в адресе или слишком длинный адрес — номерок не выдаётся, плеер получит `refused`.
4. **Качальщик ресурсов.**
   - `credentials:"include"`, для плейлистов `cache:"no-store"`, `Range` для byte-range.
   - Защита локальной сети на каждом запросе и редиректе (решение 199), Referer (решение 202).
   - Потолки: `max_bytes`, число одновременных запросов, очередь байтов сеанса.
5. **Тень.** VOD — как файл (решения 186, 187). Live — бесконечная длительность и окно `seekable`. `currentTime` идёт от часов плеера, интерфейс сайта показывает «в эфире». Возврат на страницу перезагружает `src` на текущем месте (VOD) или на краю эфира (live).
6. **Версии.** Плеер с общей версией 1.0 — честное «not supported yet», как сейчас.

## Стенд

- Генератор: HLS fMP4, мастер с двумя вариантами, AES-128. Live — сервер стенда отдаёт скользящее окно из VOD-сегментов по часам.
- `m3u8-in-src` уходит из `refusals.rs` в обычный `capture`. Chromium: кадр в рендере. Firefox: `unsupported`, как разрешено таблицей.
- `player-commands`: перемотка HLS VOD докачивает нужный сегмент, пауза и play доходят до страницы.
- Live: кадры идут дальше начального окна, тень держит страницу «в эфире».
- Атаки: плейлист со ссылкой на `127.0.0.1` со страницы из «интернета» стенда — отказ. Подмена номерка — `refused`.
- Журнал сервера: элемент под тенью ничего не качает, всё качает фон.

## Живая проверка

Сайт с m3u8 в `src` на эталоне не встречался. Если найдётся открытая страница с нативным HLS в Chromium (VOD или live) — короткая проверка на ней. Если нет — честно записать, что проверено только на стенде.
