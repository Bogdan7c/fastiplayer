# Сессия 12b: режим 2 — «Ask», правила в попапе и веха M2

Часть сессии 12 ([общий замысел](12-mode2-auto-handoff.md)), решения 246–254. Зависит от 12a.

> Выполни сессию 12b плана `user/browser-bridge/`: предложение «Ask» на заглушке, правило сайта в попапе, свой стоп-лист в настройках, живая веха M2. Сначала прочитай `user/browser-bridge/README.md`, этот файл, решения 246–254 и `results/12a.md`.

## Что сделать

1. **«Ask»:** видео на паузе под тенью, на заглушке маленькое предложение «Play in Fastiplayer / Play here» и «Always / Never for this site». Выбор пишет правило сайта. Охрана включается и для сайтов с «Ask» (сейчас `wantsAutoHandoffWatch` её не включает).
2. **Попап:** правило текущего сайта — Default / Always / Never / Ask.
3. **Настройки:** свой стоп-лист (добавить, убрать), список своих правил сайтов.
4. **Веха M2 вживую** (как в общем замысле): KDE Wayland, Chrome (Flatpak) и Firefox, эталонные сайты — автозапуск, заглушка, возврат, замена, ложные срабатывания за полчаса обычного сёрфинга. Владелец пробует сам, его вердикт и просьбы правок — в отчёт (решение 254).

## Критерий выхода
