# Сессия 07: каркас экстеншена Fastiplayer Bridge

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 07 плана `user/browser-bridge/`: заложи экстеншен на TypeScript — одна кодовая база, два манифеста (Chrome MV3; Firefox по решению из `results/00.md`), сборка без фреймворков и с минимумом npm-зависимостей, тесты на общих JSON-фикстурах протокола из 01, CI-задача, связь с посредником (`Hello`, версии, «плеер не найден» → страница-инструкция). Сначала прочитай `user/browser-bridge/README.md`, `results/00.md`, `results/01.md`, `results/05.md`.

## Зачем

Решения 27–28. Каркас задаёт порядок на годы: где что лежит, как собирается, как тестируется.

## Что сделать

1. **Раскладка** (например, `extensions/browser/`):
   - `src/background/` — порт к хосту, состояние вкладок, настройки;
   - `src/content/` — изолированный контент-скрипт;
   - `src/page/` — MAIN-мир, только подсказки (инвариант 1);
   - `src/popup/`, `src/options/`;
   - `src/adapters/` — пустой каркас (14);
   - `src/protocol/` — типы протокола и проверка формы входящих сообщений.

   Раскладку утвердить в отчёте.
2. **Протокол в TS:** типы зеркалят `browser-bridge-protocol`. Тесты разбирают **те же** JSON-фикстуры из `crates/browser-bridge-protocol/fixtures/`. Если фикстура меняется, ломаются обе стороны.
3. **Сборка:** `tsc` (и, если без него никак, один маленький бандлер с обоснованием). Скрипт собирает `dist/chrome/` и `dist/firefox/` с разными манифестами из общего кода. Зависимости:
   - `typescript`;
   - тесты на встроенном `node:test` (без jest и vitest);
   - `web-ext` — только dev-зависимость для Firefox;
   - каждая — с обоснованием в отчёте. `package-lock.json` в git.
4. **Связь с хостом:** `connectNative` при старте, `Hello` с версиями, переподключение с паузами, если хост упал. Нет хоста → иконка с пометкой, попап «Fastiplayer is not connected» со ссылкой на справку.
5. **Права по мере нужды** (решение 31): в манифесте только `nativeMessaging`, `activeTab`, `contextMenus`, `storage`, `scripting`, `declarativeNetRequest(WithHostAccess)`; `webRequest` и широкий доступ — в `optional_host_permissions` / `optional_permissions`. Точный набор — по 00.
6. **CI:** задача сборки и тестов экстеншена в GitHub Actions, линт (`tsc --noEmit` со `strict`). Проверка, что `dist/` не попадает в git.
7. **Справка:** `docs/browser-bridge/` — каркас пользовательской справки (установка, Flatpak из 06).

## Тесты

- Фикстуры протокола: валидные разбираются, невалидные отвергаются с той же причиной, что в Rust.
- Логика переподключения (на фейковом порте): плеер пропал → повторы с паузами → вернулся → `Hello` снова.
- **Сквозной вручную:** экстеншен загружен в Chromium и Firefox (`web-ext run`), установлен хост из 06, кнопка на панели отправляет `Handoff` текущей страницы локального видео → плеер играет. Автоматизация — в 08.
