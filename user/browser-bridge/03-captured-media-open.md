# Сессия 03: открытие пойманного в браузере потока (гибрид)

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 03 плана `user/browser-bridge/`: добавь в `media-source-open` вход «пойманное в браузере» — кандидаты progressive/HLS/DASH с заголовками и куками строго для своего origin — и гибридный выбор «пойманный поток или yt-dlp по ссылке страницы» на существующих `WebMediaIngressKind` и `WebMediaFallbackGate`. Подключи его к приёмнику моста из 02, чтобы `Handoff` реально играл. Сначала прочитай `user/browser-bridge/README.md`, `results/01.md`, `results/02.md`.

## Зачем

Это ядро режима «без резолвера»: страница уже добыла поток, мы его играем с теми же правами, что у браузера.

## Что сделать

1. **Вход** `BrowserCapturedMedia` в `media-source-open`. Кандидаты переводятся в существующие словари без второго каталога и второго словаря identity (как требовал N01):
   - progressive → путь прямого HTTP;
   - HLS / DASH → нативные открывальщики;
   - заголовки и куки → `SecretRequestContext` / `HttpCookieSeed`, привязанные к origin кандидата;
   - кросс-origin редиректы снимают секреты монотонно — как уже сделано в адаптивном транспорте.
2. **Гибридный выбор** (решение 2). Порядок:
   - пойманный кандидат играбелен → открываем его;
   - не открылся до `Installed` по разрешённой причине (`WebMediaFallbackGate`: просрочен, профиль не поддерживается) → yt-dlp по ссылке страницы (сессия 04);
   - сетевые и отменённые отказы fallback **не** запускают — это существующее правило гейта;
   - после `Installed` fallback запрещён, восстановление идёт через `WebMediaRecoveryStrategy` (свежий материал — сессия 16).
3. **Подписи и ошибки** — безопасные: домен страницы, без query и токенов (`SafeMediaLabel`). Причины отказа видны пользователю понятным текстом (по образцу UX08).
4. **Приёмник 02** вызывает этот вход через существующий диспетчер внешних открытий (`ExternalOpenRequest`), политика «играть сейчас / в очередь» берётся из сообщения, а умолчание — из config (решение 14; ключ config — в сессии 12, здесь только «сейчас»).
5. **Безопасность входа:** URL кандидатов — только `http`/`https`; `file:`, `data:`, `blob:` и внутренние адреса (`127.0.0.1`, `localhost`, частные сети) по умолчанию отвергаются. Отказ от локальных адресов обсудить с владельцем: локальный тестовый стенд 08 на localhost нужно разрешать без дыры для настоящих сайтов.

## Тесты

- **Сквозной:** локальный HTTP-сервер в тесте отдаёт mp4, HLS и DASH **только** при правильных `Referer` и куке. `Handoff` с этими данными → **кадры доходят до рендера** (по образцу playback-smoke), без них → понятный отказ.
- Кука не уходит на другой origin при редиректе; `Debug` и ошибки не содержат значения.
- Гибрид: просроченный кандидат (403 до `Installed`) → вызывается заглушка yt-dlp; сетевой обрыв → fallback не вызывается.
- Отвергнутые схемы и адреса.
