## Разведка (10 ноября 2026, невидимый Chromium, настоящие сайты)

**YouTube.** Плеер страницы — элемент `.html5-video-player` (`#movie_player` на странице ролика, `#shorts-player` в Shorts; на странице Shorts есть и пустой `#movie_player`). Функции элемента:
- качества: `getAvailableQualityData()` → `{quality, qualityLabel, isPlayable}` (`hd1080` → «1080p»); выбор `setPlaybackQualityRange(q, q)` меняет поток сразу, секунда не сбрасывается; `auto` возвращает автоматику; что выбрал человек — `getUserPlaybackQualityPreference()` (`auto` или уровень);
- озвучки: `getAvailableAudioTracks()` / `getAudioTrack()` / `setAudioTrack(track)`. Описание дорожки лежит во вложенном объекте под сжатым именем поля (было `Tb`, меняется от сборки к сборке): `{name, id: "<язык>.<n>", isDefault, isAutoDubbed}`. Подпись — на языке интерфейса YouTube, у оригинала приписка «(original)». Смена озвучки — новый `MediaSource` (новое поколение), время продолжается;
- следующий ролик: `nextVideo()`; есть ли он — кнопка `.ytp-next-button` с адресом (на странице ролика без плейлиста она может быть скрыта, но адрес есть);
- эфир: `getVideoData().isLive`, качества есть, озвучек нет;
- встроенный плеер (`/embed/`) — тот же элемент; до старта список качеств пуст.

**Twitch.** Плеер — объект `mediaPlayerInstance` в свойствах React-компонента над `.video-player` (подъём по `__reactFiber…` на ~24 уровня). Функции: `getQualities()` → `{name, group, height, isDefault}`, `getQuality()`, `setQuality(q)` (160p за 5 с), `isAutoQualityMode()`, `setAutoQualityMode(true)`. Меню настроек (`data-a-target="player-settings-…"`) тоже кликается, но открывать его ради чтения — заметно на странице; основной путь — функции, без них меню нет.

## Что сделать

1. **YouTube:** адаптер вариантов `sites/youtube/` с рукой-функцией — описание плеера одним вызовом, выбор качества и озвучки, Next. id озвучки — код языка, id качества — уровень YouTube (`hd720`), «Auto» помечен `automatic`. Ключ сериала — один на сайт (решение 289), ключ серии — id ролика. Shorts: меню качества без Next (ленты — 16b). Встроенный YouTube (Суспільне) — тот же адаптер.
2. **Twitch:** адаптер `sites/twitch/` — качества эфира и записи, «Auto» помечен `automatic`, ключ — один на сайт. Вшитая реклама — честное ограничение (кнопки пропуска нет).
3. **Помощник живой проверки** `live_handoff`: флаг выбора варианта из меню плеера по времени (тестовая переменная плеера, как стенд `series`).
4. **Живые проверки** на невидимом экране, Chromium и Firefox: меню у плеера, смена озвучки и качества — плеер на той же секунде, Next, эфир, Twitch; память — второй сеанс на том же профиле встаёт в выбранной озвучке.
5. **Проверка владельцем** (решение 291), 5–10 минут.

## Тесты

- Модульные на подделках плеера: `matches`, `describe`, `select`, `next` через настоящие клиент и исполнитель руки (как `bench-series.test.ts`); подделка без функций, с мусором, со сжатым полем под другим именем.
- Проверка проверок: нарочные поломки ловятся.
