# Сессия 10a3: HLS live — тень и стенд

Добавлена 7 ноября 2026 в начале сессии 10a2 по решению владельца 231. Общий замысел — [10a](10a-native-hls-in-src.md), плеер и протокол — [10a1](10a1-player-hls-via-bridge.md), номерки, переписчик и VOD — [10a2](10a2-extension-hls-handles-bench.md).

> Выполни сессию 10a3 плана `user/browser-bridge/`. Научи тень экстеншена держать страницу с нативным HLS live: бесконечная длительность, окно перемотки идёт по часам плеера, интерфейс сайта показывает «в эфире», возврат на страницу встаёт на край эфира. Стенд — live со скользящим окном до кадра в рендере в Chromium. Сначала прочитай `user/browser-bridge/README.md` (решения 186, 187, 228–231), этот файл, `results/10a1.md`, `results/10a2.md`, `mem:browser-bridge/core`.

## Что уже есть после 10a2

- Номерки, переписчик плейлистов и качальщик ресурсов работают для любых плейлистов, в том числе для обновлений live: тот же адрес получает тот же номерок, у таблицы потолок с вытеснением старых записей.
- Плеер (10a1) играет live через мост, встаёт у живого края, позицию страницы для live не использует.
- Тень VOD — тень файла (решения 186, 187). Она рассчитана на конечную длительность: `buffered` и `seekable` равны «всему файлу».

## Что сделать

1. **Тень live.** `duration` = `Infinity`. `seekable` — окно, которое едет вместе с часами плеера. `buffered` — честное окно у края. `currentTime` идёт от часов плеера и не прыгает в момент передачи: при передаче нужно сопоставить время страницы и часы плеера.
2. **Перемотка со страницы в live.** Сначала выяснить, умеет ли плеер перематываться внутри окна эфира через мост. Если да — передать с поправкой на сопоставление. Если нет — честно ограничить окно и записать в ограничения.
3. **Возврат на страницу.** Перезагрузить `src` и встать на край эфира, а не на T.
4. **Выбор и вердикт.** У live нет длительности: реклама по длительности его не задевает, незапущенный плейлист по-прежнему «видео нет».

## Стенд

- Сервер стенда отдаёт скользящее окно из VOD-сегментов по часам (новый путь в `site/routes.rs`, начало отсчёта — в общем состоянии сервера).
- Live: кадры идут дальше начального окна, тень держит страницу «в эфире» (отчёт страницы: `duration === Infinity`, `seekable` движется).
- Журнал сервера: элемент под тенью ничего не качает, обновления плейлиста качает фон.
