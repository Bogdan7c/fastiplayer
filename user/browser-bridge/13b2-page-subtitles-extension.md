# Сессия 13b2: субтитры страницы — экстеншен, стенд, живая проверка

Часть сессии 13b ([общий замысел](13b-page-subtitles.md)), решения 20, 54, 270–274.

> Выполни сессию 13b2 плана `user/browser-bridge/`: экстеншен ловит субтитры страницы (`fetch`/XHR с фильтром до чтения тела, `<track>`, реплики `TextTrack` → WebVTT), помнит их до передачи и отдаёт плееру протоколом 1.5 из 13b1; выключенные `<track>` скачивает фон; стенд в Chromium и Firefox, живая проверка YouTube и Ashdi/Tortuga. Сначала прочитай `user/browser-bridge/README.md`, `results/13b1.md`, `13b-page-subtitles.md`, этот файл целиком.

## Что сделать

- **Хуки MAIN-мира** рядом с `src/page/mse-hook.ts` через `prototype-wrap.ts`:
  - `fetch`: читается копия ответа, только если адрес, тип и размер похожи на субтитры;
  - XHR: текст, если `responseType` `""`/`"text"`; объект, если `"json"`; байты, если `"arraybuffer"`.
- **Признак «скачала = включено»** (решение 271): последний документ, который скачал плеер сайта, — `showing`. У `<track>`/`TextTrack` признак — их `mode`.
- **`<track>`.** Все объявленные дорожки. Выключенные качает фон через сеть браузера с заслоном локальных адресов (решение 272).
- **`TextTrack` без `src`** (hls.js, dash.js): реплики собираются в WebVTT. Растущая дорожка обновляется заменой документа.
- **Память до передачи.** Склад документов страницы со своим потолком. Отдача сразу после журнала MSE.
- **Новый вид события страницы** проходит по всей цепочке: проверка формы, бюджет, переводчик фона. Отправка — только при согласованной версии ≥ 1.5.
- **Файлы уже у предела.** `page-message-validation.ts` (698 строк) и `handoff-session.ts` (799) — новое кладём в новые модули.

## Тесты

- **Экстеншен:**
  - двоичные ответы и чужие типы не читаются;
  - потолок памяти;
  - распознаются `json3`/`srv3`/`vtt`/`srt`/TTML;
  - сборка WebVTT из реплик;
  - нет отправки при версии 1.4.
- **Стенд:**
  - страница с `<track>`;
  - страница, которая качает `.vtt` через `fetch`;
  - страница с XHR;
  - hls.js-подобная страница с `TextTrack`.

  В обоих браузерах дорожки должны оказаться в меню плеера, а выбранная — видна на кадре.
