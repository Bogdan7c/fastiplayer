# Сессия 13: субтитры со страницы, качество, «H.264 для старого железа»

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 13 плана `user/browser-bridge/`: тексты субтитров, которые загружает страница (`.vtt/.srt/.ass`, `<track>`, текстовые дорожки в MSE), идут в наш конвейер субтитров со своим стилем; качество выбирает плеер страницы, а наш плеер честно показывает текущее; политика «H.264, когда дёшев только он» (решение 43) — автоматически по возможностям плеера плюс переключатель в экстеншене. Сначала прочитай `user/browser-bridge/README.md`, `results/03.md`, `results/09.md`.

## Зачем

Решения 17, 18, 20, 43. Без этого передача теряет то, что было на странице.

## Что сделать

1. **Субтитры:**
   - текст субтитров перехватывается там, где его получает страница: `<track>` (его загружает браузер — текст берётся через `TextTrack` или повторной загрузкой браузером), `fetch` / XHR плеера страницы (хук ответа в MAIN-мире), текстовые дорожки в MSE (`wvtt` / `stpp` внутри fMP4 — разберёт наш демуксер);
   - форматы — наши парсеры (`subtitle-formats`); текст идёт по каналу протокола как дорожка субтитров с языком и меткой;
   - в плеере — внешние дорожки в меню CC, автовыбор по языку как сейчас, **без** записи в track-memory (решение 41); память выбора — в экстеншене (решение 44);
   - если на странице субтитры были включены — включаем те же (решение 54); иначе память экстеншена (44), дальше наш автовыбор по языку.
2. **Качество:** выбирает плеер страницы (ABR или его меню). Наш плеер показывает текущее разрешение и битрейт. Меню выбора качества появится с адаптерами (14). Без адаптера — пункт «Change quality on the page».
3. **Политика кодека (решение 43):**
   - плеер в `Hello` сообщает «дешёвые кодеки» — нейтрально, от возможностей активного рендера и декодера (`capability-core`), а не флагом «GLES2»;
   - экстеншен подменяет ответы о кодеках (09, п. 5) при `auto` (если дёшев только H.264), `always H.264` или не подменяет при `off`;
   - если сайт дал только AV1/VP9 — играем что дали, без отказа.
4. Граница «возможности плеера → экстеншен» — описать до правки.

## Тесты

- Стенд: страница с `<track>`, подгружаемым `.vtt` и `wvtt` в fMP4 → дорожки в плеере, выбранная видна на экране (существующие проверки субтитров на кадре).
- ABR-стенд сменил качество → наш плеер показывает новое разрешение, играет без разрыва.
- Политика: рендер с дешёвым только H.264 → стенд с выбором AV1 / VP9 / H.264 отдаёт H.264; wgpu с дешёвым AV1 → подмены нет; `off` → подмены нет.
