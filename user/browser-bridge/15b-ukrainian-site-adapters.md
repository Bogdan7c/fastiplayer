## Разведка (10 ноября 2026, невидимый Chromium, настоящие сайты)

- **uaserials (Tortuga).** Плеер — iframe `tortuga.tw/embed/<номер>` внутри теневого DOM элемента `<player-control>`. В iframe — PlayerJS: `window.pljssglobal[0].api(...)`. Отвечают `quality` («1080p»), `qualities` (`["480p","720p","1080p"]`), `audiotracks` (пусто), `playlist_id` («1-1»), `playlist_title` («Серія 1»). Над видео три выпадающих списка плейлиста PlayerJS: сезон, серия, озвучка. Активный пункт помечен классом `pjs-<id плеера>-active-pl`. Есть «Автоперем.» (автопереход серии). Обёртка Tortuga шифрует часть данных — опираться на API PlayerJS и меню, не на внутренности.
- **klonua (бывший uafilm, Ashdi).** iframe `ashdi.vip/vod/<номер>?multivoice` в теневом DOM. Озвучки — пункты плейлиста PlayerJS (`pjsdiv[fid]`, четыре озвучки у проверенного фильма), `playlist_title` — подпись выбранной. Качество у Ashdi одно.
- **Как нажимать.** `element.click()` по пункту плейлиста **не** срабатывает. Срабатывает последовательность событий мыши (`pointerdown`/`mousedown`/`pointerup`/`mouseup`/`click`) на самом пункте с атрибутом `fid`; дочерний текст пункта имеет `pointer-events: none`. После смены `playlist_id` и `playlist_title` меняются. `fid` — номер по порядку, а не постоянный ключ (память сравнивает по подписи, это годится).
- **Реклама.** Перед видео PlayerJS показывает «Реклама» и «Пропустити через N» (читатель 09d уже есть).

## Что сделать

1. **Адаптер PlayerJS** `sites/playerjs/variants.ts` (+ рука-функция для `api()`): озвучки и серии из плейлиста, качества из `api("qualities")`, Next — следующая серия плейлиста; ключ сериала — путь iframe плеера, ключ серии — `playlist_id`. «Нажатие как человек» — новая способность руки DOM (последовательность событий мыши), с тестами.
2. **Живые проверки:** «серия → следующая серия → другая озвучка → память озвучки» на каждом сериальном сайте (критерий 15); Ashdi — смена озвучки с рекламой и возвратом на ту же секунду (решение 280); после Next — не попадает ли промежуточный выбор страницы в память (ограничение 14b2).
3. **Таблица совместимости** `docs/browser-bridge/compatibility.md` (английский): все эталонные сайты 00 — режимы 1 и 2, Next, озвучки, качества, субтитры, возврат, пропуск рекламы; что нет и почему.
4. **Проверка владельцем** (решение 291).
