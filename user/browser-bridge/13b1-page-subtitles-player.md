# Сессия 13b1: субтитры страницы — протокол и плеер

Часть сессии 13b ([общий замысел](13b-page-subtitles.md)), решения 20, 54, 270–274.

> Выполни сессию 13b1 плана `user/browser-bridge/`: протокол 1.5 (`subtitle_track_offered` + двоичная рамка вида 3 с байтами документа) в Rust и TS, разборщик YouTube `json3` в `subtitle-formats`, склад дорожек страницы в плеере (переживает смены поколения), дорожки в меню CC, включённая на странице включается у нас, во время рекламы субтитры не рисуются. Сначала прочитай `user/browser-bridge/README.md`, `13b-page-subtitles.md`, этот файл целиком.

## Договор протокола 1.5

- **`subtitle_track_offered`** (страница → плеер, вне поколений):
  - `track` — номер дорожки страницы, u32 ≥ 1;
  - `language` — тег BCP-47, необязательный;
  - `label` — подпись до 256 байт, необязательная;
  - `format_hint` — `web_vtt | srt | ttml | srv3 | json3 | unknown`;
  - `origin` — `page_download | track_element | text_track_cues`;
  - `page_display` — `showing | not_showing`;
  - `byte_length` — от 1 байта до 8 МиБ.
- **Двоичная рамка вида 3:** `track` u32 и `offset` u64, груз до 1 МиБ. Куски идут подряд с нуля. Документ готов, когда пришло ровно `byte_length` байт.
- **Повторное предложение того же `track`** заменяет документ. За сеанс — не больше 64 дорожек.

## Плеер

- **Склад дорожек страницы** — на весь сеанс. Каждое новое медиа (поколение) получает все готовые документы.
- **Владелец субтитров** получает intent-метод «добавить дорожки страницы к текущему медиа». Разбор — нашими парсерами по подсказке и содержимому.
- **`page_display = showing`** — дорожка включается у нас (решения 54, 271). Иначе работает наш автовыбор по языку.
- **Пока на экране плашка рекламы,** субтитры страницы не рисуются.

## Тесты

- **Протокол:** фикстуры на каждое правило сторожа в Rust и TS.
- **json3:** равен srv3 того же содержания (событие в событие).
- **Плеер:**
  - документ из сообщения → дорожка в меню → пиксели на GPU;
  - `showing` включена;
  - мусор и превышение лимитов — честный отказ одной дорожки;
  - смена поколения не теряет дорожки;
  - во время рекламы пикселей субтитров нет.
- **Сквозной тест процесса:** документ по сокету → дорожка выбрана и показана в окне.
