# Итог сессии 12: режим 2 «автозапуск»

## Статус

**DONE, веха M2 принята.** 8 ноября 2026, двумя частями:
- [12a](12a.md) — двигатель, правила, стенд;
- [12b](12b.md) — «Ask», попап, свои списки, фильтры видео, живая веха.

Вердикт владельца: «я принимаю, проблем не обнаружил».

Цель режима: человек смотрит видео в браузере как привык, нажимает Play, и видео без кнопок и меню играет в Fastiplayer. Так и работает.

## Что получилось

- **Кто запустил.** В плеер уходит только видео, по которому человек кликнул мышью, если оно заиграло в пределах секунды (решение 262). Видео, которое страница запустила сама (баннер, превью, лента), и клик рядом не считаются. Клик по рекламе перед фильмом засчитывается и фильму, который сайт запустит после неё (247–248).
- **Как.** Сторож следующего видео ставит тень прямо в вызове `play()`, и браузер не успевает показать ни кадра. Судит фон, передаёт обычный двигатель режима 1 (`handOffTab`). Нового перехвата нет (246).
- **Правила сайтов.**
  - Always / Never / Ask — из попапа, из предложения на видео и со страницы настроек.
  - Свой стоп-лист.
  - Встроенный стоп-лист: звонки, банки и платежи, соцсетей в нём нет (250, 259).
  - Сайт без правила — по настройке «Play in Fastiplayer» или «Ask first» (251).
- **«Ask».** Видео замирает, поверх вопрос и четыре кнопки. «Always» и «Never» записывают правило и сразу действуют. Вопрос висит, пока человек не выберет. После «Play here» то же видео не спрашивает (255–257).
- **Фильтры видео.** Звук, длина (порог 60 с), цикл. По умолчанию выключены, у каждого — галочка «везде» и свой список сайтов (260–261).
- **Концы.** После «Return» видео само назад не уходит, новое нажатие — новая передача (252). Несколько вкладок — играет последняя (12a). Окно уже открыто — видео играет в нём (249).

- Firefox отдавал клик по нашей полупрозрачной панели своей кнопке «Картинка в картинке». Панель стала непрозрачной ([12b](12b.md)).
- Хвост аренды переезда после «Return» отнимал видео у режима 2. Память отказов сторожа разделена по причине задержки ([12a](12a.md)).
