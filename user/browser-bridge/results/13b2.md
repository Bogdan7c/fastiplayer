# Результат сессии 13b2: субтитры страницы — экстеншен, стенд, живая проверка

**Статус:** DONE 9 ноября 2026. Коммиты — следующие за `7756c380`.

## Решения владельца

- **275.** Включённые `<track>` тоже качает фон. Получается один путь для всех `<track src>`, и плеер получает оригинал документа со стилями и позициями. Реплики браузера — только запасной путь для адресов `blob:` и `data:`.
- **276.** Маленький адаптер timedtext YouTube делаем сразу в 13b2. Он берёт язык из адреса, а автосубтитры получают подпись «English (auto-generated)». Иначе в меню CC были бы два одинаковых «English». Каркас адаптеров (14) потом его заберёт.
- **Ashdi и Tortuga** владелец поручил проверить агенту самому, по снимкам экрана, без владельца за компьютером.

## Что сделано

**Договор и пограничник** (`extensions/browser/src/shared/`):
- **Два новых события страницы.** `subtitle_document` — готовый документ: скачан плеером сайта или собран из реплик. `subtitle_track_source` — `<track src>`, его качает фон. Каждое несёт ключ дорожки внутри документа, сырые язык и подпись страницы, признак автосубтитров и признак «показана на странице».
- **Свой пограничник** для этих событий. Общие проверки вынесены из `page-message-validation.ts`: файл был у предела размера, стало 621 строка.
- **Опознание документа по содержимому:** WebVTT, SRT, TTML, srv3, json3. Отдельно опознаётся кусочек HLS: WebVTT с `X-TIMESTAMP-MAP` дорожкой не считается, его собирает hls.js, и он приходит через реплики `TextTrack`.

**MAIN-мир** (`src/page/page-subtitles/`):
- **`fetch`.** Странице возвращается тот же промис. Копия ответа берётся только если адрес, тип и размер похожи на субтитры. Видео, звук, картинки, шрифты и манифесты HLS/DASH не читаются никогда. Копия читается с потолком 8 МиБ.
- **XHR:** текст, JSON (только при субтитровом адресе), `arraybuffer`.
- **Склад документа до передачи:** до 16 МиБ и 32 документов, старые выселяются первыми. Одинаковое содержимое — та же дорожка. Самый свежий документ — «показан на странице» (решение 271).
- **`<track>` и `TextTrack`.** У `<track>` с http(s) фон получает адрес. Реплики `TextTrack` без файла собираются в WebVTT. Растущая дорожка пересылается целиком, не чаще раза в 5 с, по тикам часов плеера.
- **Отдача.** Склад уходит сразу за журналом MSE, пойманное после передачи — сразу. После конца передачи не уходит ничего. Любой сбой субтитров передачу не рвёт.
- **Адаптер именования** `src/adapters/subtitle-naming/`. Для YouTube timedtext язык берётся из `tlang`, иначе из `lang`, а `kind=asr` означает автосубтитры. На остальных сайтах — общий `lang`/`language`.

**Изолированный мир:** точная копия байтов документа перед отправкой фону; у `<track src>` своё происхождение документа для Referer; бюджет 256 событий субтитров в секунду.

**Фон** (`src/background/handoff/page-subtitles/`):
- **Номера дорожек — на весь сеанс.** Дорожка узнаётся по фрейму, метке документа и ключу. Второе видео того же документа заменяет свои дорожки, перезагруженный документ получает новые номера. Не больше 64 дорожек и 32 МиБ: замена считает новый размер вместо старого, как плеер.
- **Только плееру 1.5.** Плееру версии 1.4 не уходит ничего, сеанс живёт. Пока страница «ушла» (сирота), ничего не шлётся.
- **Закачка `<track src>`:**
  - через сеть браузера: куки, заслон локальных адресов, Referer правилом, повторная проверка адреса после редиректа;
  - целиком до 8 МиБ, срок 30 с, 3 закачки одновременно;
  - отмена при смене документа и конце сеанса;
  - скачанное проверяется содержимым.
- **Подпись к протоколу:** неверный тег языка — «язык не назван»; подпись очищена и обрезана до 256 байт. Автосубтитры без подписи получают «English (auto-generated)» через `Intl.DisplayNames`.
- **`handoff-session.ts` остался в пределе:** 796 строк, два связных куска вынесены без изменения поведения.

**Стенд:**
- **Команда `page-subtitles`, четыре страницы:**
  - `<video src>` с двумя `<track>`: английская включена, украинская выключена;
  - `.vtt` через `fetch` со второго сайта;
  - XHR `.srt`, затем XHR json3;
  - hls.js-подобная страница: `addTextTrack`, после передачи реплики добавляются.
- **Помощник живой проверки** `examples/live_handoff.rs` получил клик мышью стенда (`--click-at`) и снимки невидимого экрана (`--screenshots`) для сайтов, где видео стартует только по клику.

**Риск решения 271** («сайт, который качает субтитры заранее»): на этих сайтах не подтвердился.
- **YouTube** качает только показанную дорожку.
- **Ashdi и Tortuga** по умолчанию качают и показывают украинские надписи, так что включить их у нас — правильно. Тот же документ они перекачивают при каждой смене ролика «реклама → фильм». Склад узнаёт его как ту же дорожку (`replaced=true`), дублей в меню нет.

## Известные ограничения

- **Ловим только то, что сайт скачал сам.** Английская дорожка Ashdi, не выбранная на странице, в меню не попадает. Плеер страницы под тенью новых языков не качает: зритель выбирает в нашем меню, а не на странице.
- **Язык на Ashdi и Tortuga — «unknown».** В адресе `…_ua.vtt` языка нет, подпись «Українські» знает только конфиг PlayerJS. Читать конфиг — работа адаптеров (14).
- **Подпись «(auto-generated)»** проверена тестами на настоящих формах адресов YouTube. В журнал плеера подпись не пишется, поэтому глазами в меню её ещё никто не видел.
- **Чего не ловим:**
  - документы чужого фрейма (не фрейма видео) и воркеров;
  - `TextTrack` в режиме `disabled`;
  - смену `mode` после объявления: протокол не умеет обновлять «показана».
- **Embed YouTube, открытый напрямую,** не играет (нужна страница-обёртка). На живом сайте это не важно, только для проверок.
