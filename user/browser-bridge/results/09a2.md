# Результат сессии 09a2: переходы страницы и честные концы

## Статус

**DONE.** Стенд зелёный, живая проверка YouTube в Chromium и Firefox пройдена. Рекламу посреди ролика YouTube в этот раз не показал — переход «реклама → фильм» вживую не пойман, его закрывают страницы стенда. 2–3 ноября 2026.

Закрыты все десять дыр аудита 09a (Д-1…Д-10):
1. Страница, снявшая источник перед новым MediaSource (так YouTube делает перед рекламой), больше не выключает передачу: тень ждёт до 5 с, и новое поколение играет у нас.
2. Страница, честно забравшая видео, получает честный конец: в окне «The page took the video back», без доигрывания и без «Source tab closed».
3. Фон, страница и плеер больше не расходятся навсегда: тень раз в секунду подаёт пульс, тишина 10 с — честный конец.
4. Ни один сбой на стороне страницы не гасит окно молча.

## Решения владельца

- **178–179** — см. README (приняты в конце 09a).
- **180. Пульс «тень жива».** Тень раз в секунду на тиках часов плеера говорит фону «жива». Тишина 10 с — честный конец «Stream error». Ловит потерянное сообщение, зависшую страницу и сломанный канал. Отклонён «повтор конца в ответ на команду»: зависшую страницу и сломанный канал он не ловит.
- **181. Подмены свойств видео ставятся сразу на каждой странице**, а не при первой передаче. Страница, заранее запомнившая настоящие `currentTime` и `play`, больше не обходит тень. Вне передачи подмены прозрачны.
- **182. Механизм 09a2 подтверждён до кода** (текст — в README).
- **183. Отказ плеера играть текущее видео** (находка ревью пакета фона) — тоже «Stream error» в окне, а не молчаливое исчезновение. Отклонено «оставить до сессии 11».

## Технические решения (за агентом, владельцу сообщено)

- «Страница забрала видео» передаётся **кодом закрытия WebSocket 4009 `page_took_video_back`**, а не новой причиной `tab_gone`: вкладка не ушла, и сервер сеанса по `tab_gone` включает доигрывание. Добавлен внутри 1.0, как решение 128.
- Сбой на стороне страницы — экстеншен закрывает связь **4003** после дописывания очереди. Плеер различает 4003 своё (`cause=protocol_violation`) и страницы (`cause=page_stream_error`), зрителю текст один.
- Допуск пустого источника — **5 с от первого снятия**: повторное `srcObject = null` его не продлевает. Сторож работает на тиках часов (таймеры скрытой вкладки спят) и на каждом тике заново смотрит на источник: `setAttribute('src', …)` на пустом элементе браузер не сопровождает событием `emptied`.
- Атрибут `src` читается оригинальным `getAttribute`: геттер `src` для `""` отдаёт адрес документа.
- Тень принимает часы нового источника, только когда плеер их признал: тик у цели или любой тик после тика «жду». Страховка — 15 с. Неподтверждённый `ended` не принимается никогда.

## Живая проверка (3 ноября 2026, YouTube)

Механика: основной компьютер, свежая релизная сборка плеера (её будит шина). Chromium — одноразовый профиль, файл посредника в самом профиле, `--load-extension`. Firefox — `web-ext run` с временным профилем. Порт отладки не открывался. Передачу запускала служебная страница экстеншена: команда `hand_off_tab` вставлялась в её консоль своим эмулятором клавиатуры `/dev/uinput`. Прыжки, пауза и закрытие окна — по MPRIS `org.mpris.MediaPlayer2.fastiplayer.browser`. Положение видео страницы после возврата читалось консолью самой страницы.

| Что | Chromium 156 | Firefox 158 |
|---|---|---|
| Передача посреди просмотра | да (ролик 5 мин, потом ролик 1 ч 23 мин) | да (1 ч 23 мин; второй раз — с самого начала) |
| Прыжки вперёд и назад | 12 + 22, все садятся в цель | 12, все садятся в цель |
| Пауза и play | да | да |
| Ровность | минута 4K60 у нас: 60 кадров/с, откатов позиции 0 | откатов позиции 0 |
| Закрытие окна → страница на паузе в T | T = 3526,3 с → страница 3526,25 с, на паузе, звук не заглушён | T = 3654,0 с → страница 3654,02 с, на паузе |
| Реклама посреди ролика | YouTube не показал | реклама перед фильмом была один раз, но передача прошла уже после неё (накладка проверки) |

**Находка → сессия 16.** Короткий ролик дошёл у нас до конца, и YouTube сам включил следующий. Вкладка YouTube была скрыта, а в скрытой вкладке браузер притормаживает таймеры страницы. Источник стоял пустым дольше 5 с, и через ~6 с после конца ролика окно честно сказало «The page took the video back» и закрылось. Следующий ролик заиграл в браузере. Это не дыра 09a2, а случай решения 59 / сессии 16 («следующая серия в том же окне»). Поправка — в файле 16.

Накладки проверки (не продукт):
- в Firefox вкладки переключаются Alt+цифра, а не Ctrl+цифра;
- UUID страницы экстеншена из pref `extensions.webextensions.uuids` у `web-ext` не применился — настоящий читался из `prefs.js` временного профиля;
- Ctrl+Shift+J в Chromium закрывает уже открытую консоль.

## Известные ограничения

- Источник из дочерних `<source>` без атрибута `src` выглядит как «пусто» и снимается по допуску — 09b.
- Клик зрителя при доигрывании, когда есть ждущее новое поколение (ложный `tab_gone` посреди смены `MediaSource`, после 09a2 почти невозможен), становится целью поколения без сообщения.
- Настоящая перемотка полки при оборванном скачивании по-прежнему садится за конец; до неё больше не доходят ни клик, ни скраб, ни MPRIS.
- Переход «реклама посреди ролика → фильм» вживую не пойман (YouTube рекламу не показал); доказан страницами стенда `mse-generation-swap-srcobject-null` / `-reload` / `-delayed`.
- Отказ плеера играть видео в журнале плеера помечен `cause=page_stream_error`: закрывает связь экстеншен.
