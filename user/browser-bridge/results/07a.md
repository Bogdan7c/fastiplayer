### Ещё факты

- **ID экстеншена Chrome берётся только из подписи `.crx`**, поле `key` манифеста на него не влияет. `.crx`, подписанный другим ключом, браузер отвергает: «Expected ID … but ID was …». Закрытый ключ разработки не хранится (решение 154), поэтому своя раздача `.crx` означала бы новый ключ-секрет и новый ID.
- **Chromium ставит экстеншен по подсказке только при запуске.** Запущенный браузер новую подсказку не замечает: плеер должен попросить перезапустить браузер.
- **Если человек удалил экстеншен в браузере, Chromium запоминает отказ** (`external_uninstalls`) и по подсказке больше не ставит, даже новую версию. Плеер это видит и предлагает страницу магазина.
- **Убрал подсказку — браузер удалит экстеншен** при следующем запуске.
- **Firefox из пакета Arch:** `extensions.autoDisableScopes = 11`, поэтому подложенные экстеншены приходят выключенными. Единственная найденная дыра — системная папка `/usr/lib/mozilla/extensions` (нужен пароль) не проверяет подпись. Мы на неё не опираемся.
- **Подпись Mozilla без публичной страницы** («unlisted») автоматическая, до 24 часов, нужен аккаунт AMO.
- **Edge на Windows** принимает ссылку и на Edge Add-ons, и на Chrome Web Store. Публикация в Edge Add-ons бесплатна, проверка до 7 рабочих дней.
- **Chrome Web Store:** проверка обычно несколько дней, иногда до нескольких недель. Права на все сайты (`<all_urls>`) отправляют экстеншен на расширенную проверку.

## Решения владельца (2.11.2026; в README — 165–168)

1. **Оба магазина остаются (165).** Отказ от магазинов невозможен без потерь:
   - Chrome на Windows ставит снаружи только экстеншены из Chrome Web Store;
   - в Chrome из Flatpak — только через «управляется организацией» с паролем;
   - свой `.crx` в Chromium висит с плашкой «может быть опасен, удалите».

   Публикация — сессия 24, как в плане.
2. **Пароль администратора плеер не просит никогда (166).** Везде, где тихо нельзя, есть путь без пароля ценой одного клика в браузере. Он одинаков с будущей Windows.
3. **Установщик делается сейчас, настоящие ID магазинов — в сессии 24 (167).** До публикации кнопка честно пишет «Available after publication». Живая проверка — на экстеншенах-дублёрах из настоящих магазинов.
4. **Механизм подтверждён до кода (168):**
   - **тихий путь** для Chromium-семейства, которое читает папку профиля: плеер кладёт файл-подсказку «поставь экстеншен с этим ID из Chrome Web Store», браузер ставит его при следующем запуске;
   - **один клик** для Google Chrome (пакет и Flatpak) и Firefox: плеер открывает страницу экстеншена в магазине прямо в этом браузере, человек жмёт «Add»;
   - **статус** — только чтение профилей браузера, ничего в них не пишется;
   - **Remove** удаляет только свою подсказку.

### Правила, которые держит код

- **Плеер ничего не пишет в профиль браузера, кроме своей подсказки.** Чтение профилей — только чтение, тест сверяет дерево профиля до и после.
- **Чужое не трогается.** Если файл с нашим именем не наш или это не обычный файл, плеер его не перезаписывает и не удаляет, а предлагает страницу магазина.
- **Один битый профиль не ломает браузер.** «Не читается» — только если не прочитался ни один профиль.
- **Пароль не нужен нигде.** Браузер запускается отцепленным от плеера, без чужого ввода-вывода, процесс подбирается фоновым потоком.
- **Не-Linux** — `UnsupportedPlatform`. Это шов под Windows: там вместо подсказки будет запись в реестр `HKCU\Software\Google\Chrome\Extensions\<ID>` со ссылкой на магазин, плюс та же страница магазина.

**Независимое ревью** (отдельный агент, без моих выводов) нашло, всё исправлено с тестами:
- один битый профиль блокировал установку во весь браузер;
- статус «перезапустите браузер» мог висеть вечно без запасного пути;
- установка перезаписывала чужую подсказку;
- сбой `flatpak` выдавался за «браузер не установлен»;
- FIFO на месте файла мог подвесить фоновый поток;
- неточный разбор `profiles.ini`.

Принятые риски записаны в коде:
- симлинк на папку `External Extensions` при записи проходится, как это делает и сам Chromium;
- окно между проверкой и удалением подсказки — действующее лицо только тот же пользователь.

**Живая проверка** (невидимый экран, частные HOME и профили; профили владельца не тронуты). Дублёры — Plasma Integration из Chrome Web Store и Multi-Account Containers с AMO.

| Сценарий | Итог |
|---|---|
| Chromium: обзор → `install` → подсказка `{"external_update_url": …}` → «WaitingForBrowserRestart» → запуск Chromium | через ~30 с экстеншен из магазина стоит и включён (`location 6`, `from_webstore`), плашки Safety Check нет, обзор → `Installed` |
| Chromium: человек удалил экстеншен в `chrome://extensions` | Chromium записал отказ, обзор → `RemovedInBrowser`, `install` открыл страницу CWS, подсказка не писалась |
| Chrome из Flatpak: `install` | плеер выполнил `flatpak run com.google.Chrome https://chromewebstore.google.com/detail/<ID>`, открылась страница с кнопкой «Установить»; после клика экстеншен стоит, обзор → `Installed`, повторный `install` → `AlreadyInstalled` |

**Дефект, найденный живой проверкой, и его корень.** Разведка показала: убрал подсказку — браузер удаляет экстеншен. Но это проверялось на своём `.crx` (`location 2`). Экстеншен, поставленный по подсказке из магазина (`location 6`), Chromium 156 **не удаляет**, когда подсказку убрали. Поэтому кнопка «Remove» превратилась в «Cancel»:
- она отменяет только установку, которая ещё не случилась;
- поставленный экстеншен убирает человек в браузере;
- после установки кнопки отмены нет — она ничего бы не сделала.

## Известные ограничения

- **Настоящих ID магазинов нет** — до сессии 24 строка пишет «available after publication». Экстеншен разработки (ID ключа разработки) уже распознаётся как установленный.
- **Вживую проверены только Chromium (тихий путь), Chrome из Flatpak и Firefox (страница магазина).** Brave, Vivaldi и Edge с тихим путём — по документации и исходникам. Если такой браузер подсказку не примет, человек увидит «restart … to finish installing» и запасную кнопку «Install in browser».
- **Тихий путь срабатывает только при запуске браузера:** плеер просит перезапустить браузер.
- **Пакетный Google Chrome вживую не проверялся** — его на машине нет. Путь «страница магазина» тот же, что у Flatpak.
- **Windows** — только шов и факты, кода нет.
- **ungoogled-chromium** не ходит в Chrome Web Store: плеер честно пишет «install it manually».
