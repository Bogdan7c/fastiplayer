# Результат сессии 13b1: субтитры страницы — протокол и плеер

**Статус:** DONE 9 ноября 2026. Коммит — следующий за `294b459e`.

## Решения владельца

- **270.** Механизм 13b подтверждён до кода:
  - три способа ловли субтитров на странице;
  - память до передачи;
  - протокол 1.5: заголовок плюс байты документа;
  - склад дорожек на весь сеанс;
  - во время рекламы субтитры не рисуются.
- **271.** «Скачала = включено»: последний документ, который скачал плеер сайта, считается включённым на странице.
- **272.** Выключенные `<track>` скачивает фон экстеншена.
- **273.** json3 читается `serde_json`.
- **274.** 13b разделена на 13b1 (протокол и плеер) и 13b2 (экстеншен, стенд, живая проверка).

## Что сделано

**Протокол 1.5** (Rust и TS на общих фикстурах):
- **Заголовок `subtitle_track_offered`:** номер дорожки, язык, подпись, подсказка формата, откуда документ, «был ли включён на странице», размер до 8 МиБ.
- **Байты документа** идут двоичной рамкой нового вида 3. Документ готов, когда пришёл весь объявленный размер. Тот же номер дорожки заменяет документ.
- **Сторож протокола** не пускает:
  - больше 64 дорожек;
  - куски не по порядку;
  - лишние байты;
  - рамку для чужой или уже готовой дорожки;
  - всё это при согласованной версии 1.4.
- **Общий потолок на сеанс** — 32 МиБ всех документов. Его держит плеер, а экстеншен в 13b2 обязан уважать.
- **Фикстуры:** 315 случаев (было 262) и 18 последовательностей сторожа.
- **В TS** есть готовый «разрезатель» документа на заголовок и куски без копий — для 13b2.

**json3 YouTube** (`subtitle-formats`):
- **Только новый читатель.** json3 — это тот же srv3, записанный в JSON, поэтому читатель кладёт данные в готовую модель srv3. Окна, бегущие строки автосубтитров и появление слов работают из общего кода.
- **Сверка с настоящим YouTube.** Ручные и автосубтитры одного публичного ролика скачаны в json3 и в srv3, события совпадают полностью: 315 из 315 и 335 из 335.

**Плеер:**
- **Сборщик документа** проверяет всё сам: страница — враг. Мусор и превышение лимитов — отказ одной дорожки, остальные живут.
- **Склад дорожек страницы** живёт весь сеанс и переживает смены поколения (реклама посреди фильма, новый `MediaSource`). Каждое новое медиа получает весь склад заново.
- **Меню CC:** дорожки страницы с подписью страницы, иначе с именем языка.
- **Разбор нашими парсерами.** Содержимое важнее подсказки формата, кодировка определяется по языку. `.srt` в cp1251 читается правильно.
- **Дорожка, включённая на странице,** включается и у нас, последняя побеждает. Иначе работает наш автовыбор по языку.
- **Выбор зрителя главнее и живёт весь сеанс.** Найдено при сверке исполнителя главным агентом: по первой версии зритель выключал субтитры, приходила реклама, и после неё они включались снова. Теперь ручной выбор или выключение держится и через рекламу, а новый сеанс начинает заново.
- **Пока на экране плашка рекламы,** субтитры не рисуются.
- **Журнал:**
  - строка `Page subtitle track ready` с номером, языком, форматом, числом реплик и тем, выбрана ли дорожка;
  - поле `subtitle_overlay_frames=` в сводке окна — сколько кадров ушло в рендер со слоем субтитров.

## Доказательства

- **Протокол:** `cargo test -p browser-bridge-protocol -p browser-bridge-session` — зелёные, правило сторожа на каждый случай договора.
- **Экстеншен:** `npm run check` — 2587 тестов, typecheck, сборка.
- **json3:** 15 тестов. Главный — равенство событий json3 и srv3 того же содержания. Разовая сверка на настоящих файлах YouTube описана выше; сами файлы в репозиторий не кладутся.
- **Плеер:** `cargo test -p app-egui` — 3497 и 107 сквозных процессных, 0 падений. Ключевые тесты:
  - **GPU-пиксели** (настоящий рендер): документ страницы — светлые пиксели во время реплики и нет после; во время рекламы пикселей нет.
  - **Сквозной процесс** под невидимым kwin: документ по настоящему сокету → дорожка готова и выбрана, 154 кадра со слоем субтитров; с плашкой рекламы — 0 кадров со слоем при 150 показанных.
  - **Смена поколения** не теряет дорожки. Выбор зрителя держится через два новых поколения.
- **Проверка ломкой** (каждая правка откатывалась):
  - убрано включение по `showing` — упали оба GPU-теста;
  - отключено скрытие в рекламе — упали тесты рекламы;
  - склад сбрасывается на каждом поколении — упал тест на смену поколения;
  - снята связка с плашкой рекламы — упал процессный тест (169 кадров со слоем);
  - выбор зрителя игнорируется — упал тест «остаётся выключено в следующем поколении».
- **Общий прогон:** guardrails, rustfmt, strict Clippy по workspace (`-D warnings`) — зелёные; тесты `browser-bridge-protocol`, `browser-bridge-session`, `subtitle-formats`, `browser-bridge-bench`, `media-source-open` — 1533, 0 падений.

## Известные ограничения

- **В меню только то, что дошло до плеера.** Пока экстеншен (13b2) ничего не шлёт, на живых сайтах субтитров страницы нет.
- **Разбор ленивый,** как у веб-дорожек. Мусор обнаруживается, когда дорожку выбирают или показывают.
- **Память может ненадолго превысить 32 МиБ.** Пока качается замена документа, старый остаётся на складе: это не больше двух потолков.
- **Памяти выбора между видео нет** — это сессия 14. Очистки дорожек при следующей серии нет — сессия 16.
- **Безоконный тестовый путь** субтитры страницы не показывает.
