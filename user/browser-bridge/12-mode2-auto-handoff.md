# Сессия 12: режим 2 — автозапуск (веха M2)

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 12 плана `user/browser-bridge/`: режим 2 — автоматическая передача, когда человек сам нажал play, звук включён и ролик длиннее порога (по умолчанию 60 с); правила сайтов «Always / Never / Ask»; готовый стоп-лист плюс свой; запрос прав при включении режима; политики плеера «заменить / в очередь» (по умолчанию «в очередь») и «окно как в прошлый раз». Затем веха M2. Сначала прочитай `user/browser-bridge/README.md`, `results/11.md`.

## Зачем

Решения 9, 10, 13–15, 31. Это то самое «человеку не надо вручную включать плеер».

## Что сделать

1. **Включение режима** в попапе или настройках: запрос «доступ ко всем сайтам» или «только к этому сайту» (`permissions.request`). Отказ → режим 2 не включается, понятное объяснение.
2. **Триггер:** событие `play` на элементе, связанном с главным кандидатом + жест пользователя (`navigator.userActivation` или клик перед play) + не `muted` + длительность ≥ порога (известна из элемента или манифеста; неизвестна → ждать до N с, решить). Порог настраивается.
3. **Правила сайтов:** «Always / Never / Ask» для домена; «Ask» — маленькое предложение на заглушке. Готовый стоп-лист — данные (видеозвонки, соцсети с автоплеем в ленте, банки; **без российских сайтов**), владелец утверждает список. Свой список — в настройках.
4. **Политики плеера** (config в `[browser_bridge]`, мигрирует по правилам):
   - «уже играет»: `replace` / `queue`, **по умолчанию `queue`** (решение 14). При `replace` позиция старого сохраняется, его вкладка размораживается на паузе;
   - окно: как в прошлый раз (фуллскрин или окно), забирает фокус (решение 13; на Wayland — через билет активации, как UX13; проверить, что даёт браузер);
   - инкогнито (04) — уважается.
5. **Защита от петель:** вкладка после «Return» не передаёт тот же ролик снова, пока человек сам не нажмёт play заново. Несколько вкладок подряд → по политике очереди, без гонок.

## Тесты

- Стенд, оба браузера: фильм с жестом и звуком → передача и **кадр в рендере**; баннер без звука, превью по наведению, преролл, ролик 30 с → **нет** передачи; «Never» → нет; «Ask» → предложение; стоп-лист работает; повтор после «Return» без нового play → нет.
- Политики: «в очередь» при играющем плеере → строка в очереди, текущее не прервано; `replace` → новое играет, позиция старого сохранена.
- Права: без разрешения режим не включается и ничего не наблюдает.
