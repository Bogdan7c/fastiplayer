# Сессия 12: режим 2 — автозапуск (веха M2)

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 12 плана `user/browser-bridge/`: режим 2 — автоматическая передача, когда человек сам нажал play, звук включён и ролик длиннее порога (по умолчанию 60 с); правила сайтов «Always / Never / Ask»; готовый стоп-лист плюс свой; окно «как в прошлый раз». Затем веха M2. Сначала прочитай `user/browser-bridge/README.md`, `results/11.md`.

## Зачем

Решения 9, 10, 13, 15, 47, 50. Это то самое «человеку не надо вручную включать плеер».

## Что сделать

1. **Включение режима** — переключатель в попапе или настройках, глобально или для сайта. Права уже есть с установки (решение 47), перехват стоит на странице с `document_start`.
2. **Триггер:** `play` на главном элементе + жест пользователя (`navigator.userActivation` или клик перед play) + не `muted` + длительность ≥ порога (известна из элемента или `MediaSource.duration`; неизвестна или live → передаём сразу, решение 50). Порог настраивается. Браузер не должен успеть показать видео: элемент становится виртуальным сразу на `play`.
3. **Правила сайтов:** «Always / Never / Ask» для домена; «Ask» — маленькое предложение на заглушке. Готовый стоп-лист — данные (видеозвонки, соцсети с автоплеем в ленте, банки; **без российских сайтов**), владелец утверждает список. Свой список — в настройках.
4. **Окно:** как в прошлый раз, берёт фокус (решение 13, исполняет 04).
5. **Защита от петель:** вкладка после «Return» не передаёт тот же ролик снова, пока человек сам не нажмёт play заново. Несколько вкладок подряд → последняя заменяет (решение 40), без гонок.

## Тесты

- Стенд, оба браузера: фильм с жестом и звуком → передача и **кадр в рендере**, браузер не декодировал ни кадра; баннер без звука, превью по наведению, преролл, ролик 30 с → **нет** передачи; «Never» → нет; «Ask» → предложение; стоп-лист работает; повтор после «Return» без нового play → нет.
- Три вкладки подряд в режиме 2 → играет последняя, две первые на паузе на своих секундах.
- Live и ролик с неизвестной длиной при play → передача сразу (решение 50).

## Веха M2 — живая проверка

- KDE Wayland, Chrome (Flatpak) и Firefox, эталонные сайты: автозапуск, заглушка, возврат, замена, ложные срабатывания (полчаса обычного сёрфинга по новостям и соцсетям с включённым режимом 2 — сколько ложных запусков).
- Владелец пробует сам — его вердикт в отчёте.
