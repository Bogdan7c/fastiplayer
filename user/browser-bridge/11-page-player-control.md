# Сессия 11: заглушка, возврат на страницу, замена вкладки

Приложи этот файл и скопируй абзац ниже в сообщение.

> Выполни сессию 11 плана `user/browser-bridge/`: заглушка «Playing in Fastiplayer [Return]» поверх видео страницы, возврат (по кнопке, при закрытии окна плеера, при замене сеанса из другой вкладки) — настоящий элемент получает видео обратно на той же секунде, где сайт позволяет, и дальше играет (кнопка «Return») или стоит на паузе (закрыли плеер, замена из другой вкладки) — решение 51. Сначала прочитай `user/browser-bridge/README.md`, `results/00c.md` (способы возврата), `results/09.md`, `results/10.md`.

## Зачем

Решения 11, 12, 40, 51, 52. Человек должен в любой момент вернуться к странице без поломанного плеера сайта.

## Что сделать

1. **Заглушка** (Shadow DOM) на месте видео: «Playing in Fastiplayer», «Return», не мешает остальной странице. Всегда, в обоих режимах (решение 52).
2. **Возврат на секунде N** способом из 00c (переподключить источник, перезапуск плеера страницы, API плеера, адаптер сайта 14). Где сайт не даёт — просто вернуть элемент и показать подсказку, что позиция не восстановлена.
3. **Шкалы не совпадают:** вшитая реклама, live с перемоткой, ролик со смещённым началом — наша секунда ≠ секунда страницы. Возврат считает в шкале страницы (её `currentTime` до передачи + сдвиг, который видел виртуальный элемент), а не в нашей. Для live — «к живому краю».
4. **Замена сеанса (решение 40):** старая вкладка получает «вернуть на T, пауза» — тот же путь.
5. **Плеер страницы сломался во время сеанса** (ошибка, перезагрузка) → сеанс заканчивается как «вкладка ушла» (решение 42), заглушка снимается.

## Тесты

- Стенд, оба браузера: «Return» → страница **играет** с N ± 1 с, плеер окно закрыл; закрытие окна плеера → страница **на паузе** на N; замена из второй вкладки → первая на паузе на своей секунде.
- Стенд с вшитой рекламой и live → правильное место или честный возврат без перемотки.
- «Return» одновременно с закрытием плеера → одно действие, страница не дёргается дважды.
- После возврата страница полностью рабочая: перемотка, качество, следующая серия на её собственном плеере.
