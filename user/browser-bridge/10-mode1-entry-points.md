## Зачем

## Что сделать

1. **Кнопка на панели:** клик → главное видео вкладки уходит в браузерный режим (`OpenSession` + поток). Перехват стоит на странице с `document_start` (решение 47), поэтому начало потока не пропущено.
   - Поздний вход остаётся только для вкладок, открытых до установки или обновления экстеншена: начало потока пропущено, плеер страницы перезапускается на текущей секунде способом из 00c (или адаптером, или перезагрузкой страницы с позицией). Человеку — без лишних кликов.
2. **Попап:** список найденного (заголовок, размер, метка «ad?» / «DRM» / «not supported yet»), выбор, «Open», состояние связи с плеером, ссылка на настройки.
3. **Контекстное меню на `<video>`:** если сайт забирает правый клик — пункт на странице вокруг.
4. **Правый клик по ссылке (решение 45):** фоновая вкладка → дождаться видео (сайт запускает сам или адаптер жмёт play) → передать. Таймаут и понятное сообщение, если видео не появилось. Фоновая вкладка закрывается вместе с сеансом.
5. **Кнопка поверх видео:** небольшая, появляется при наведении, не ломает вёрстку (Shadow DOM, свой слой). **По умолчанию выключена** (решение 53), включается в настройках.
6. **Настройки** (options): какие входы включены, язык — английский.
7. **Ответ плеера** виден человеку: «Opened in Fastiplayer», понятная ошибка (нет плеера, DRM, сайт не поддержан).

## Тесты

- Автотест стенда (08), Chromium + Firefox: каждый вход × страницы стенда (MSE fMP4 и WebM, `<video src>`, iframe, ссылка) → **кадр в рендере**.
- Кнопка нажата после начала проигрывания на странице → играет с текущей секунды без пропуска начала потока; вкладка, открытая до установки экстеншена, → поздний вход тоже играет.
- Ссылка → фоновая вкладка → видео в плеере; закрытие плеера закрывает фоновую вкладку.
