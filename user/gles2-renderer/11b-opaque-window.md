# Подсессия 11b: окно без скругления углов

Найдено в сессии 11 (`results/11.md`, находка 4). Отчёт — [`results/11b.md`](results/11b.md).

## Проблема

Окно Fastiplayer создавалось с альфа-каналом ради скруглённых углов. У основной плоскости дисплея Intel Ironlake нет
формата с альфой, поэтому KWin копировал наш кадр каждый кадр, даже в фуллскрине:
- треть GPU на программном 1080p60;
- +2,5–3 п.п. CPU KWin;
- аппаратный декод на 720p60 и 1080p30 терял кадры.

## Решение владельца (27.10.2026, решение 57 README)

Скругление углов окна удаляется целиком, в обоих рендерах. Окно — обычное непрозрачное, настройки радиуса нет,
конфиг мигрирует v25 → v26.

## Граница и проверки

Окно получает непрозрачность при создании (`app_shell/main_window_attributes.rs`). Рендеры больше не принимают
предпочтение альфы и не рисуют маску углов:
- wgpu выбирает только непрозрачный `CompositeAlphaMode`;
- GLES2 выбирает EGL-конфиг без альфы.

Тесты:
- миграция v25 → v26;
- атрибуты окна;
- выбор режима альфы и конфига;
- непрозрачные углы кадра.

Живая проверка на T410 в обоих режимах окна.
