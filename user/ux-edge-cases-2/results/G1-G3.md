# G1-G3: ложный тост перемотки, текст ошибки строки плейлиста, перекрытие «Повторить»

Статус: **PASS** (тесты и живая проверка; случай «играет» для G2 проверен только тестами).

## G1. Ложный тост «Перемотка для этого видео недоступна» на http-mp4
- Корень: клик по таймлайну это `BeginScrub → PreviewScrub → EndScrub`. Preview (live-scrub) идёт через собственный demuxer плеера, а у progressive HTTP финальный seek уходит worker-у (seek port), и demuxer синхронный seek не умеет (`SeekUnavailable: progressive HTTP source не поддерживает byte seek`). Отказ preview публиковался как `RecoverableError` в двух местах (`scrub_driver::seek_demux_to_decode_point` и общий fallback «SeekLanding не смог стартовать…» в `seek_start.rs`), хотя финальный seek успешен. Найдено временным backtrace в `record_recoverable_error` (убран).
- Решение: preview необязателен, итог жеста даёт финальный seek. Для `LiveScrub` отказ «seek недоступен» и общий fallback не публикуются (остаётся debug-лог); для `SeekLanding` (seek пользователя) и неперематываемого источника (admission до preview) отказ виден как раньше. Политика в новом `player-core/src/session/scrub_preview_policy.rs`.
- Тесты `session/tests/progressive_scrub_preview.rs`: клик по progressive-источнику (demuxer без sync seek + fake worker port): нет `RecoverableError`, `last_error` пуст, worker получил запрос на цель, после receipt позиция перемещена; неперематываемый источник: `SeekUnavailable` по-прежнему виден. Без правки первый тест падает.

## G2. Текст ошибки строки плейлиста
- Источник: `ui/playlist/status/presentation.rs::navigation_message`. Текст теперь зависит от `PreviousPlayback` (из `PlaybackState` плеера в кадре, не из памяти очереди — она не знает про Failed/Stopped): «Предыдущий трек продолжает играть» / «остался на паузе» / ничего. Везде: «Автопереход остановлен: нажмите «Следующий», «Предыдущий» или «Повторить»», без Next/Previous и «курсора». Состояние входит в identity строки, поэтому текст не залипает.
- Тесты: три состояния → текст (нет английского/«курсор»), маппинг всех `PlaybackState`, identity различается, строка собирается из модели.

## G3. «Повторить» под панелью телеметрии
- Корень (он же старое «текст обрезается слева»): `ui.set_max_width(560)` расширяет ширину, если центральная область уже 560 pt; к тому же в `ui.horizontal` переносимая подпись съедает всю ширину и выталкивает кнопки за край. Исправлено в `ui/notifications.rs`: `set_max_width(available.min(560))` и `horizontal_wrapped`.
- Тест (`state/notifications/render_tests.rs`): панель телеметрии + центр, ширины 400/640/1280: «Повторить» и × целиком внутри центральной области и clip-области, не заходят под панель, клик по «Повторить» даёт `Retry`. Мутации (вернуть `set_max_width(560)` / `horizontal`) валят тест. Toast-ы не менялись (проверено: не нужно).
