# A13-4: packed audio HLS (`.aac` ADTS, `.mp3`, ID3 PRIV)

Статус: PASS (VOD и live, AAC в ADTS и MPEG audio MP3; AC-3/E-AC-3 packed честно отвергаются).

## Решение владельца
Поддержать packed audio HLS (сегменты `.aac`/`.mp3` с ID3 PRIV `com.apple.streaming.transportStreamTimestamp`, RFC 8216 §3.4): частый формат интернет-радио, VOD и live.

## Архитектура (до кода)
- Вместо нового контейнера + factory + своего seek-индекса packed-сегмент **нормализуется в одно-программный audio-only MPEG-TS на границе источника сегментов** (`HlsEpochSegmentSource`). После этого весь HLS-стек (probe контейнера, VOD seek-index, live-якоря `EveryAudioPacket` из A13-3, discontinuity, ребейз таймстемпов по origin эпохи) работает без изменений, потому что уже доказан на TS. Symphonia и новые зависимости не нужны: кадры ADTS/MP3 уже разбирает `mpeg-ts-demux`, декодеры AAC/MP3 уже подключены.
- Кто определяет контейнер: содержимое, а не расширение URI. Первые 3 байта: `ID3` / sync-слово `0xFFEx` / `0x0B77`. TS (`0x47`) и fMP4 (размер box-а) не совпадают с этими признаками, поэтому их путь не меняется.
- Владение: новый модуль `web-media-hls/src/packed_audio/` знает только форму packed-сегмента и TS-обёртку; сеть, ключи, seek и live остаются у источника и демуксеров. Точка подключения: `source/packed_ingest.rs`, вызывается из `source/streaming.rs` (открытый ресурс: sniff, packed буферизуется целиком; AES: нормализация после расшифровки).
- PTS: первый кадр сегмента = ID3 PRIV (33-битный счётчик 90 кГц); PTS следующих кадров накапливает TS-демуксер по числу сэмплов. Нет PRIV: начало сегмента на таймлайне манифеста (сумма `EXTINF`), нет и его: 0. Между сегментами непрерывность даёт следующий PRIV либо `EXTINF`; границы эпох (`EXT-X-DISCONTINUITY`) ребейзятся по origin эпохи.
- Инварианты: `HlsRequiredContainer` и профили не менялись; ordered-segments (fMP4) путь не затронут; ошибка packed-сегмента = typed `PackedAudioError` -> `hls-packed-audio-invalid`, а не молчаливый пропуск.

## Риски
- Весь packed-сегмент читается в память и оборачивается в один PES (лимит парсера 16 МиБ); для аудио-сегментов это килобайты-мегабайты.
- PTS внутри сегмента накапливается с усечением длительности кадра до такта 90 кГц (дрейф доли мс на сегмент), на стыке сегмента ставится истинный PRIV.
- SAMPLE-AES и AC-3/E-AC-3 packed не поддержаны; в логе MP3 после перемотки/старта live бывают предупреждения декодера `invalid main_data_begin` (bit reservoir начинается в предыдущем кадре, это штатно).
