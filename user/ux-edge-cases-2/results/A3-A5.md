# A3-A5: мёртвый Space, минимум высоты окна, пробелы вокруг URL

**Статус: PASS.** Три мелочи, три коммита (A3, A4, A5 + этот отчёт).

## A3. Мёртвая ветка `KeyCode::Space` в `handle_hotkeys`

- **Недостижимость подтверждена.** Единственный вызов `handle_hotkeys` — ветка `ShellHotkeyAction::Legacy(key_code)` в `app_shell/event_loop.rs`. Список `Legacy` в `app_shell/hotkeys.rs` (F, M, J/L, стрелки, PageUp/PageDown) Space не содержит: Space идёт как `Transport(TogglePlayback)`.
- **Сделано.** Ветка удалена; вместе с ней удалён ставший неиспользуемым `AppState::toggle_playback` (единственный потребитель — эта ветка). Доккомментарий `handle_hotkeys` поясняет, куда ушёл Space. Baseline размера `ui_runtime.rs` уменьшен.

## A4. Окно сжималось до 1 px по высоте

- **Почему 1.0.** Из `git log -S`: значение пришло в коммите «кнопки повтора и смешивания» вместе с минимумом ширины 400 (порядок transport controls); высота `1.0` была лишь «ничего не ограничивать», а не режим (компактного/audio-only режима нет). Размер окна в config не хранится (всегда 1280x720 при создании), поэтому конфликта «сохранённый размер меньше минимума» нет; fullscreen минимумом не ограничивается.
- **Решение.** Новый модуль `app_shell/window_limits.rs`: минимум = высота titlebar по умолчанию (40) + нижняя панель (резерв 160) + полоса видео (32) = 232 логических точки; ширина 400 как раньше. Нижняя панель измерена тестом на настоящем `render_bottom_controls` при ширине 400: 117 обычно, 159 со строкой статуса очереди «Отменить ожидание».
- **Оговорка.** Titlebar настраивается до 96; резерв сделан под значение по умолчанию (иначе компактное окно запрещено всем). При большом titlebar панели могут частично перекрывать видео, но не друг друга.

## A5. Пробелы/переводы строк вокруг URL

- **Карта входов.** Поле «Добавить URL» (`append_playlist_url`), drag-and-drop текста (`external_open/uri.rs`) и `resolved_url_collection` уже обрезали сами; CLI-аргумент первого запуска (`startup_media/initial_arguments.rs`), M3U-импорт, переоткрытие сохранённых ссылок и проверка при пересылке во второй экземпляр — нет.
- **Корень и фикс.** Общий слой — `classify_startup_url` (`url_service_adapter.rs`): теперь он делает `trim()` (Unicode White_Space: `\n`, `\r`, `\t`, NBSP, U+3000). Пробелы только в пределах классификации; локальные пути с пробелами в имени не затронуты (NotUrl падает в путь с исходным текстом).
- **Не реализовано (не решено владельцем).** Несколько URL в одной строке: сейчас строка целиком уходит в классификатор как один URL, внутренние пробелы не режутся, результат — `NotUrl` или `InvalidSyntax` в зависимости от парсера. В drag-and-drop текста, напротив, каждая строка берётся отдельно как отдельная ссылка.
- Не обрезаются невидимые символы вне White_Space (U+200B, BOM U+FEFF).
