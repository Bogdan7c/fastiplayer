# Сессия 03: MPEG-2 видео в MPEG-TS

> Выполни сессию 03 плана `user/mpeg2/`. Сначала прочитай `user/mpeg2/README.md`, `results/00.md`–`results/02.md`, этот файл.

## Что сделать

1. PMT: `stream_type` 0x02 (и 0x01) → видеодорожка `Mpeg2` с размерами, SAR и частотой кадров из sequence header. В 01 это была дорожка «не играется», теперь — обычная.
2. **Сборка кадра.** Один пакет плеера = одна картинка (picture) с предшествующими заголовками (sequence, GOP), границы — по start-code-ам ISO/IEC 13818-2.
   - Сборщик NAL для H.264/H.265 не трогать: нужен отдельный сборщик по образцу.
   - Новый вариант `VideoPacketFraming`, если нужен. Решение — с обоснованием в отчёте.
3. **Время.** PTS/DTS из PES; у кадров без PTS — расчёт по `temporal_reference` и частоте. Порядок B-кадров учитывается.
4. **Ключевой кадр для перемотки** — I-picture после sequence header (closed/open GOP).

## Тесты

- Фикстуры 00:
  - число пакетов = число картинок;
  - PTS совпадают с ffprobe (эталон записан в фикстуре);
  - ключевые кадры на своих местах.
- Пакет PES, разрезанный TS-пакетами посреди start-code-а → та же сборка.
- Склеенные TS и разрыв счётчика непрерывности ведут себя как у H.264 (бэклог AC-3 п. 18).
- Сквозной «до кадра» — в сессии 04. Здесь — до пакета декодера с правильными границами.
