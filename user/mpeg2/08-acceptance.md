# Сессия 08: приёмка MPEG-2

> Выполни сессию 08 плана `user/mpeg2/`. Сначала прочитай `user/mpeg2/README.md` и все `results/`.

## Что сделать

1. **Живой шмон** на основном компьютере, T410 (GLES2, Xfce) и T480s (GNOME). Стенд как в финальной приёмке 03e: изолированные XDG, сверка отпечатка файлов владельца, uinput, фикстуры с выжженным номером, запись монитора синка. Проверить:
   - воспроизведение, перемотку, drag, смену скорости, конец файла, очередь;
   - смешанную очередь: MPEG-2 TS → H.264 MP4 → только звук;
   - все контейнеры из объёма;
   - чересстрочное и прогрессивное видео, telecine, SAR 16:9;
   - отказ 4:2:2 с понятным сообщением.
2. **Сравнение с VLC и mpv**: CPU, GPU, плавность (кадров на выходе), качество деинтерлейса глазами владельца. Минутная совместная проверка «владелец смотрит — агент снимает».
3. Найденные дефекты: тяжёлые чинить в этой сессии, остальные — в бэклог с решением владельца.
4. Общий бэклог п. 16 — закрыть со ссылкой на этот план. README проекта — строка про MPEG-2 (подача фичи честная, со скриншотом).
