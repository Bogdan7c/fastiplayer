## Предыстория (факты аудита, сверить с кодом)

1. Ни `set_cursor_visible`, ни idle/autohide нет. В фуллскрине titlebar и нижняя панель рисуются всегда; `is_fullscreen` влияет только на иконку (`ui_runtime.rs:~328`) и corner mask (`window_corner_policy.rs`).
2. Двойной клик по titlebar → `ToggleMaximize` (`window_chrome.rs:~256`) — активен и в фуллскрине.
3. Двойного клика по видео (фуллскрин) и клика по видео (play/pause) нет.
4. `toggle_fullscreen` молча ничего не делает, если `current_monitor()` = `None` (`ui_runtime.rs:~668`) — проверить на Wayland; при отказе — уведомление (сессия 04, если готова).
5. При скрытии панелей нужно учитывать: открыт сайдбар/popup/меню, идёт drag таймлайна, курсор над панелью → не скрывать.

## Задание

### Стоп: согласование с владельцем (после короткого исследования)
- задержка скрытия (рекомендация — 2,5 с, настраиваемо), скрывать ли в оконном режиме (рекомендация — нет, только курсор над видео);
- одиночный клик по видео = play/pause? (рекомендация — нет: конфликтует с двойным кликом, даёт лишнюю паузу);
- анимация появления/скрытия с учётом `reduced_motion`.

### Часть B. Реализация
- Владелец видимости с явными причинами «держать видимым» (pointer над chrome, popup открыт, drag, пауза — по решению), таймер от frame time.
- Движение мыши/клавиша показывают chrome; скрытие не теряет фокус и не сбрасывает hover-состояния.
- Двойной клик по видео → тот же toggle, что и кнопка; titlebar double-click в фуллскрине — по решению (рекомендация — выключить, titlebar скрыт).

## Тесты
- fake time: в фуллскрине без ввода chrome скрыт через N, курсор скрыт; движение мыши → видно;
- открыт сайдбар/popup или идёт drag таймлайна → не скрывается;
- оконный режим → поведение по решению;
- двойной клик по видео → состояние фуллскрина переключено (через действие окна в fake window);
- `reduced_motion` → без анимации.

## Ручная приёмка
Фуллскрин, не трогать мышь 3 с → чистое видео без курсора. Двинуть мышь → панели. Двойной клик по видео → выход из фуллскрина.
