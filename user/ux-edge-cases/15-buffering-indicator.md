## Задание

### Стоп: согласование с владельцем (после короткого исследования)
- вид: спиннер в центре / маленький спиннер + «Буферизация…» (рекомендация — второе, полупрозрачно, не перекрывает субтитры/кадр целиком);
- задержка появления (рекомендация — 400–500 мс, константа с объяснением или config);
- показывать ли индикатор во время долгого seek (рекомендация — да, той же задержкой).

### Реализация
- Индикатор — состояние владельца overlay, вход — snapshot player-а (без новых полей player-core, если их не утвердили).
- Не показывать поверх фатальной ошибки; уважать `reduced_motion` (статичная иконка вместо вращения).

## Тесты
- snapshot Buffering дольше задержки → индикатор виден; короче → не появлялся;
- выход из Buffering → индикатор исчез в том же кадре;
- Failed + Buffering → показывается ошибка, не спиннер;
- `reduced_motion` → нет анимации (нет запросов repaint ради анимации).

## Ручная приёмка
Сетевое видео, ограничить скорость (например `trickle` или отключить Wi-Fi на пару секунд) → виден индикатор; восстановление → исчез.
