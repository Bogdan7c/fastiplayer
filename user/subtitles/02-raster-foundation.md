## Границы

**Зависит от:** 01 (PASS).

**Memories:** memory `subtitle-core` из сессии 01, `mem:core`, `mem:conventions`.

**Разрешено:** новый crate `crates/subtitle-raster`; нейтральный выходной тип `SubtitleOverlay` (картинки + координаты); база шрифтов (встроенный Noto Sans, системные через `fontdb`, интерфейс для вложенных — без реализации извлечения из MKV); шейпинг (`harfrust`), BiDi (`unicode-bidi`), перенос строк, растеризация контуров в маску покрытия, обводка, тень, плашка; кэш глифов и растеризованных реплик с лимитами из параметров; инструмент генерации эталонов libass (`scripts/`, вне сборки).

**Запрещено:** GPU, `app-egui`, `player-core`; ASS-теги (только стиль по умолчанию); копирование кода FreeType/HarfBuzz.

## Задание

### Часть A. Исследование и архитектура
1. Как libass устроен на уровне модулей: `ass_render`, `ass_font`, `ass_shaper`, `ass_rasterizer`, `ass_bitmap`, `ass_cache`. Что переносим сейчас (шрифт → шейпинг → раскладка → растеризация → композиция в `ASS_Image`-подобный список), что — в слоях 08–10.
2. Выходной контракт `SubtitleOverlay` (предложение, по образцу `ASS_Image`): список `SubtitleBitmap { позиция и размер в пикселях холста, stride, альфа-маска 8 бит, цвет RGBA }` + размер холста + номер изменения (`changed`-счётчик: «картинка та же, перезагружать не нужно» / «сдвинулась» / «новая»). Обосновать альтернативу «готовая RGBA-картинка» и выбрать.
3. Растеризатор: порт `ass_rasterizer.c` (собственный, по полосам и тайлам) против готового Rust-crate (`zeno`, `tiny-skia`) — сравнить качество, лицензию, совместимость с эталонами libass.
4. Встроенный Noto Sans: какое начертание/подмножество (Regular + Bold, кириллица + латиница + греческий + знаки), как вшивается (`include_bytes!` или файл рядом с бинарником), лицензия OFL — файл лицензии в репозиторий.

### Стоп: согласование с владельцем
Выбор растеризатора; формат выхода; размер встроенного шрифта (сколько МБ добавит к бинарнику).

### Часть B. Реализация
- Стиль «как YouTube» по умолчанию: белый текст, плашка ~75% чёрного, отступы и скругление как у YouTube; альтернативный стиль «обводка + тень».
- Масштаб от высоты видео (размер шрифта задаётся долей высоты кадра, как libass с `PlayResY`).
- Fallback шрифтов по глифам (эмодзи/CJK → системный шрифт, где есть глиф), без падений при отсутствии.
- Кэши ограничены по памяти (лимиты — параметры, дефолты потом уйдут в конфиг в 04).

## Тесты
- реплика «Привет, как дела?» → `SubtitleOverlay` с непустыми картинками внутри холста, текст по центру снизу, плашка шире текста на заданные отступы;
- эталоны libass (простой текст, обводка, тень, два ряда, кириллица, арабский RTL) — совпадение с допуском;
- отсутствует системный шрифт для глифа → встроенный используется, пустых «тофу»-квадратов в эталонном наборе нет;
- повторная растеризация той же реплики попадает в кэш (счётчик), не меняя результат;
- переполнение лимита кэша → вытеснение, память в пределах лимита.
