## Границы

## Задание

### Часть A. Исследование и архитектура
1. Context7: `encoding_rs`, `chardetng` (или аналог на чистом Rust), crate для языковых тегов (BCP-47) — выбрать и обосновать.
2. Модель `subtitle-core` (предложение):
   - `SubtitleTrackId`, `SubtitleTrackDescriptor` (источник: встроенный / файл рядом / web; язык; название; флаги default/forced/«авто»; формат);
   - `SubtitleEvent` (начало, конец, слой, содержимое: размеченный текст со стилями-спанами / ссылка на ASS-событие / картинка);
   - `SubtitleTimeline` — индекс, отвечающий на «какие события активны в момент T» за O(log n + k), с поддержкой перекрывающихся реплик и дописывания событий по мере демукса (встроенные дорожки);
   - `SubtitleSyncOffset` — newtype сдвига синхронизации.
3. Нейтральная модель стилизованного текста (жирный, курсив, подчёркивание, цвет, ruby/направление — только что нужно VTT), которую потом используют srv3/TTML/mov_text.

### Стоп: согласование с владельцем
Показать модель простым языком: что такое дорожка, реплика, как ищется «что показывать сейчас». Решить, какие кодировки поддерживаем явно (рекомендация: UTF-8/16 с BOM, иначе автоопределение с приоритетом cp1251 для кириллицы, с уведомлением «прочитано как …»).

### Часть B. Реализация
- SRT: нумерация необязательна, кривые таймкоды (`,`/`.`, лишние пробелы), HTML-подобные теги `<i> <b> <u> <font color>`, `{\an8}`-позиционирование (частое в SRT), пустые реплики.
- WebVTT: заголовок, `NOTE`, `STYLE`, `REGION`, cue settings (`line`, `position`, `size`, `align`), теги `<c> <v> <lang> <ruby>`, временные метки внутри реплики (караоке-стиль YouTube).
- Ошибки разбора — типизированные; битая реплика пропускается с подсчётом, а не роняет весь файл.
- Лимиты (размер файла, число реплик) — параметры, приходящие от вызывающего, а не константы.

## Тесты
- реплика из SRT возвращается индексом ровно в интервале `[start, end)` и не возвращается вне его;
- перекрывающиеся реплики возвращаются обе в порядке слоя/появления;
- SRT в cp1251 без BOM → корректная кириллица; UTF-16 с BOM → корректно;
- битая реплика в середине → остальные разобраны, счётчик пропущенных = 1;
- VTT cue settings и теги → ожидаемая модель стилей;
- дописывание событий в timeline после построения → видны при запросе;
- guardrails: попытка добавить wgpu в `subtitle-core` ловится скриптом.

## Ручная приёмка
Нет GUI-части. Владельцу — короткий отчёт с примером: файл → список реплик в момент T.
