## Границы

**Зависит от:** 06 (PASS).

**Memories:** `subtitle-core`, `subtitle-raster`, встроенные дорожки из 06.

**Разрешено:** порт из libass (`ass.c`, `ass_parse.c`, `ass_render.c`, `ass_font.c`, `ass_shaper.c`, `ass_rasterizer.c` — по необходимости): секции `[Script Info]` (PlayResX/Y, ScaledBorderAndShadow, WrapStyle, YCbCr Matrix), `[V4+ Styles]`/`[V4 Styles]`, `[Events]`, встроенный ASS (заголовок из `codec_private` + события из пакетов) и файлы `.ass/.ssa`; теги: `\b \i \u \s \fn \fs \c \1c-\4c \alpha \1a-\4a \bord \xbord \ybord \shad \xshad \yshad \an \a \pos \r \q \N \n \h \fe`; выравнивание, отступы, перенос по WrapStyle; обводка и тень по libass; разрешение коллизий (реплики не налезают); слои (`Layer`); масштабирование PlayRes → кадр с учётом соотношения сторон (как libass `storage size`).

**Запрещено:** теги слоёв 2–3 (09–10) — неизвестный тег игнорируется без ошибки и попадает в счётчик «не поддержано» для матрицы.

## Задание

### Часть A. План порта
1. Карта функций libass → модули Rust; что переносится как есть по поведению, что заменяется Rust-аналогом (`skrifa` вместо FreeType: метрики, hinting off, embolden/italic synthesis).
2. Набор эталонов: 20–40 коротких ASS-файлов на каждый тег/комбинацию + 2–3 фрагмента реальных фансабов со свободной лицензией или самодельных; скрипт генерации эталонов из 02.
3. Допуск сравнения (например, PSNR/доля различающихся пикселей) — обосновать.

### Стоп: согласование с владельцем
План простым языком и пример «наш рендер vs libass» на 2–3 картинках.

### Часть B. Реализация
По плану; растеризация ASS-событий — с кэшем по событию и тексту/стилю, только при изменении.

## Тесты
- эталонный набор слоя 1 совпадает с libass в пределах допуска;
- **функциональный**: MKV с встроенной ASS-дорожкой → надпись `\pos(…)` **в кадре** в нужной точке, основной текст внизу; две одновременные реплики не перекрываются;
- PlayRes 384×288 vs 1920×1080 → одинаковые пропорции на кадре;
- неизвестный тег → игнорируется, остальной текст рисуется;
- битая строка `[Events]` → пропущена с подсчётом.

## Ручная приёмка
Реальный аниме-эпизод с ASS (диалоги + надписи) рядом с mpv/libass: визуально сопоставимо.
