## Тесты
- перетаскивание образца на N точек → сохранённое положение изменилось на соответствующую долю высоты; после выхода реальная реплика **в кадре** стоит на новом месте (readback);
- Esc → стиль как до входа; «Сбросить» → значения по умолчанию;
- двойной клик и колесо в режиме не меняют fullscreen/громкость;
- ASS без флажка — цвета автора сохраняются, масштаб применяется; с флажком — мой стиль;
- панель управления выезжает → нижняя граница субтитра выше верхней границы панели; уехала → вернулся на место;
- смена размера окна/фуллскрин → положение в долях сохраняется.

## Ручная приёмка (KDE Plasma, Wayland и X11)
Полный цикл настройки вида мышкой, перезапуск — стиль сохранён; фуллскрин с автоскрытием — субтитры поднимаются/опускаются плавно; широкоформатный фильм — субтитры на полосе.
