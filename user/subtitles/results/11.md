# Результат сессии 11: PGS внутри MKV

## Статус

**PASS** по автоматическим проверкам и живой приёмке агентом (KDE Plasma Wayland и X11/XWayland). Закоммичено и запушено по решению владельца.

## Решения владельца (18 октября 2026)

1. **Картинка на GPU — полноцветная (RGBA)**, а не нарезка на трафареты по цветам: второй атлас и второй маленький шейдер в том же проходе. Обычные субтитры не затронуты, GLES2 умеет RGBA8.
2. **Масштаб пользователя к PGS не применяется.** Нижние картинки (диалог) поднимаются над панелью и слушаются вертикального сдвига, но не уходят с кадра; надписи сверху стоят на месте.
3. **Forced «как Blu-ray-плеер»**: субтитры выключены и forced-дорожки нет — PGS-дорожка предпочитаемого языка показывает только картинки с флагом forced.
4. **Память — отдельный механизм «окно вокруг момента»**: показываемая дорожка до 32 МБ (выбрасывается самое далёкое от текущего момента), остальные PGS — последние 60 с; оба числа в настройках. Хранится сжатая форма, раскраска — только при показе.
5. **Две правки общих границ**: «укоротить конец реплики» в шкале субтитров (чтобы картинка не мигала, когда становится известен её конец) и «номер прохода чтения» в player-core (чтобы после перемотки не висел устаревший субтитр).

Исполнитель решил сам: цвет BT.601 для кадра автора до 576 строк, BT.709 выше; набор, ссылающийся на потерянный объект или палитру, гасит экран, а не оставляет старую картинку; слишком большая текстовая маска на GPU теперь пропускается одна, а не роняет весь кадр субтитров. После живой приёмки: кадр автора вписывается в картинку видео **с сохранением пропорций** (как mpv) — иначе в рипах со срезанными полосами буквы сплющивались.

## Источники формата

Чистая комната: код FFmpeg (`pgssubdec.c`, LGPL) и BDSup2Sub не открывались.
- описание формата SUP/PGS в блоге thescorpius.com (2017, по патенту) — сегменты, RLE, поправки читателей;
- спецификация Matroska для `S_HDMV/PGS` (matroska.org, subtitles и codec_specs) — сегмент в блоке, время блока, необязательная длительность;
- патент US20090185789A1 — эпохи, окна, типы композиций;
- обсуждение в рассылке ffmpeg-devel (2016) — только факт из спецификации BD: палитра в матрице видео (601 для SD, 709 для HD), limited range.
Проверено на реальных файлах: блок MKV = голые сегменты набора, без длительности.

## Что сделано

- **`subtitle-core`**: `SubtitleContent::Picture` (`picture.rs`); `SubtitleTimeline::shorten_event_end`, `revision()`, журнал укорочений.
- **Новый crate `subtitle-pgs`** (нейтральный, зависит только от `subtitle-core` и `thiserror`): сегменты PCS/WDS/PDS/ODS/END, RLE, YCbCr → RGB, эпохи и окна, обрезка, флаг forced; хранилище композиций с пошаговыми изменениями и памятью по роли дорожки; граница размера кадра по формату (до 4096×2304). Тестовый кодировщик потоков — за фичей `test-support`.
- **`subtitle-raster`**: картинки в контракте overlay (`BitmapPixelFormat::PremultipliedRgba`, `SubtitleBitmapKind::Picture`), вписывание с сохранением пропорций, box-фильтр, кэш в общем бюджете.
- **`render-wgpu-shell`**: слой картинок Rgba8Unorm, ленивое создание, рисование сериями в порядке списка.
- **`player-core`**: `SubtitleReadRun` на каждом пакете субтитров и в снимке плеера; растёт при каждом прыжке демуксера и при выбросе пакета из переполненной трубы.
- **`app-egui`**: PGS — обычная выбираемая встроенная дорожка «PGS, embedded»; состояние PGS-дорожек (`owner_embedded/pgs_*`), дельта укорочения в поток-рисовальщик без мигания, политика размещения картинок, forced-режим (своя шкала forced-картинок).
- **Конфиг v22** `[subtitles]`: `pgs_displayed_track_cache_mb` (32, 1..=1024), `pgs_background_track_window_s` (60, 0..=3600); миграция v21 → v22 значения не переписывает.
- Фикстура `crates/symphonia-demux/tests/fixtures/subtitles/pgs-basic.mkv` (~10 КБ, генерируется `generate.sh`), матрица `docs/subtitles/compatibility.md`.

## Новые зависимости

Внешних нет. Внутренние: `subtitle-raster` → `subtitle-pgs`; dev-зависимости `symphonia-demux`, `subtitle-raster`, `render-wgpu-shell` → `subtitle-pgs` (`test-support`).

## Открытые риски

- PGS внутри MPEG-TS/M2TS и `.sup`-файлы рядом с видео не поддержаны (бэклог); VobSub/DVB — бэклог.
- Перемотка вперёд в середину картинки: она появится со следующего набора (как у текстовых встроенных).
- Разные версии палитры одного id заменяют её целиком; частичные обновления палитры на реальных дисках не проверены.
- Проверено на двух реальных дисковых дорожках; forced-флаг — только на сгенерированной фикстуре (в образцах его нет).
- `config/src/schema/subtitles.rs` — 780 строк: следующее поле субтитров выносить в модуль.
