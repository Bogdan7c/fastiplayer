## Чек-лист аудита (минимум; каждое — проверить кодом, тестом или вживую)

**Файлы и форматы**
- кодировки: UTF-8 с/без BOM, UTF-16 LE/BE, cp1251, KOI8-R, cp1252, смешанные переводы строк, `\0` в файле;
- пустой файл, файл из одних пробелов, огромный файл (лимит), очень длинная строка, тысячи реплик в одну секунду;
- реплики с нулевой и отрицательной длительностью, неотсортированные, перекрывающиеся, за пределами длительности видео, начинающиеся до 0;
- SRT с `{\an8}`, HTML-мусором, незакрытыми тегами; VTT без заголовка; ASS без `[Script Info]`, без PlayRes, с неизвестными секциями, с несуществующим стилем, `\r` на неизвестный стиль;
- RTL (арабский, иврит), CJK, эмодзи, комбинируемые символы, вертикальный текст (VTT `vertical`), отсутствие глифа во всех шрифтах;
- вложенный шрифт битый/огромный/дублирует системный; два шрифта с одним именем.

**Время и воспроизведение**
- seek во время реплики, вперёд/назад, многократный быстрый seek, scrub по таймлайну (живой скраб);
- пауза/возобновление, скорость 0.25×–4×, EOF и повтор, автопереход по очереди;
- сдвиг синхронизации большой (±60 с), отрицательный за начало;
- смена дорожки в момент реплики; выключение во время анимированного ASS;
- пересборка media после применения настроек, восстановление после приостановки, пересоздание рендерера — субтитры и выбор сохраняются.

**Источники**
- файл рядом удалён/переименован во время показа; брошенный файл недоступен для чтения; путь не в UTF-8;
- YouTube: истёк подписанный URL, 429, нет сети, ролик без субтитров, live с автосубтитрами;
- HLS/DASH: смена варианта качества, разрыв (`DISCONTINUITY`), live-окно, сегмент субтитров длиннее видео-сегмента.

**Экран и UI**
- изменение размера окна, фуллскрин, смена масштаба экрана (HiDPI 100%/150%/200%), перенос окна между мониторами;
- повёрнутое видео (`display_orientation`), вертикальное видео, очень маленькое окно, letterbox и pillarbox;
- узкий ряд кнопок: CC не налезает на соседей; меню CC у края экрана; клавиатура и Esc во всех меню;
- режим редактирования: Esc, потеря фокуса окна, начало воспроизведения, смена media во время редактирования.

**Ресурсы**
- память: кэши глифов и картинок в пределах лимитов на длинном фильме и тяжёлом ASS; утечки при многократной смене media;
- CPU: воспроизведение с субтитрами vs без (простые и тяжёлый ASS) — замер и сравнение с mpv;
- GPU: размер текстуры субтитров у предела устройства (огромная PGS-картинка/4K).
- первая реплика с системным шрифтом CJK (~20 МБ `.ttc`) готовится ~12–14 мс на потоке UI — один пропущенный кадр за запуск (находка сессии 03). Решение владельца 15 октября 2026: прогрев нужных шрифтов в фоне, но продумать, как не бить по ресурсам (память, диск, лишние лица для дорожек, которые не включат);
- время старта контейнера: pts кадра — «сырое» время контейнера; у MPEG-TS/M2TS с ненулевым стартом файлы рядом разъедутся (находка сессии 03, поправка — в одной точке `SubtitleSyncOffset`/lookup).
