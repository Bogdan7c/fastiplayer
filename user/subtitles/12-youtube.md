## Тесты
- JSON-фикстура → дорожки с правильными языками и пометками;
- srv3-фикстура → реплики, позиция, подсветка слов в модели; **функциональный** путь через fake-HTTP: выбор дорожки → текст **в кадре**;
- srv3 недоступен → VTT; оба недоступны → понятное уведомление, видео играет;
- ролик без субтитров → кнопки CC нет;
- дубляж: выбор другого языка аудио → переоткрытие на той же позиции, звучит выбранный язык (fake-кандидаты);
- URL субтитров не попадает в логи (проверка редактирования).

## Ручная приёмка
Ролик с ручными субтитрами, ролик только с автосубтитрами (подсветка слов), автоперевод на русский, ролик с дубляжом.
