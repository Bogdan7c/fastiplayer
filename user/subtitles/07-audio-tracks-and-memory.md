## Задание

### Часть A. Архитектура
1. Как опознать «то же видео» (fingerprint локатора, как resume) и как опознать «ту же дорожку» после переоткрытия (id может поменяться → язык + название + кодек + номер среди однотипных).
2. Где хранить: отдельный версионированный файл рядом с resume (рекомендация) или расширение DTO очереди — сравнить; лимит числа записей и вытеснение старых.
3. Приоритет: память видео > автовыбор по языкам > флаги файла.

### Стоп: согласование с владельцем
Вариант хранения простым языком; место кнопки аудио (макет).

### Часть B. Реализация
По согласованному; повреждённый файл памяти → игнорируется с записью в лог и пересоздаётся, воспроизведение не страдает.

## Тесты
- **функциональный**: выбрать вторую аудиодорожку и субтитры `en`, сдвиг +0.5 с, закрыть, открыть снова → звучит вторая дорожка, в кадре `en` со сдвигом;
- дорожка из памяти исчезла (файл рядом удалён) → автовыбор, без ошибки;
- битый файл памяти → чистый старт, предупреждение в логе;
- лимит записей → самые старые вытеснены;
- переход по очереди к другому видео → его собственная память, не соседняя.

## Ручная приёмка
Фильм с двумя озвучками и субтитрами: выбор, перезапуск плеера, выбор восстановлен; очередь из двух фильмов.
