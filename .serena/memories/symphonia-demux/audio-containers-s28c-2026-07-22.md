# S28C current audio-container proof (2026-07-22)

- Hermetic generated fixtures prove existing Ogg/Opus, CAF/PCM S16LE, WAVE/PCM S16LE, AIFF/PCM S16BE, native FLAC, and distinct MPEG Layer I/II/III paths. No codec family, parser family, direct-media route, or public API was added.
- Proof spans local seekable input, real loopback progressive HTTP Range (206), and non-Range (200) streaming through the S21/S22 boundaries. It asserts signature sniff without extension, conflicting hint precedence, track codec/rate/channels, exact codec-private presence/absence, packet PTS/DTS/duration/data, duration authority, seek/replay, typed non-seekable rejection with state preservation, clean EOS, malformed input, cancellation, and chained Ogg `TracksChanged`.
- S20/S21C parameterized tests prove exact family intersection for Opus, PCM, FLAC, MP1, MP2, and MP3: available exact family is playable; absent family returns typed `AudioUnavailable` before I/O or decoder construction.
- `SymphoniaDemuxer::seek_with_request` now enforces its neutral `DemuxSeekability::NotSeekable` boundary before touching backend state. This keeps non-Range streams non-seekable even where a concrete reader could attempt forward-only seek.
- MPEG signature detection rejects reserved version and layer bits while accepting legal Layer I/II/III headers.
- CAF progressive support uses the exact-version local replacement `crates/symphonia-format-caf-patch` for `symphonia-format-caf 0.6.0`. Seekable sources retain the upstream full chunk scan and seek-back. Forward-only sources stop initial scan at the data payload; declared fixed and variable packets are exact-read so truncation remains an error rather than a short packet/clean EOS.
- Forward-only CAF requires stream-friendly ordering: `desc` and codec-required configuration chunks must precede `data`. Metadata after `data` is unavailable without whole-media buffering and is outside this progressive contract.
- Proof artifact: `docs/audio-containers-s28c.md`. Fixture IDs are `symphonia/s28c-{ogg-opus,caf-pcm,wave-pcm,aiff-pcm,native-flac,mpeg-layer-1,mpeg-layer-2,mpeg-layer-3}`.
