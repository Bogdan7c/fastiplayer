# S28B Matroska/WebM proof (2026-07-22)

- S28B закрывает hermetic container proof для finite local/progressive Matroska/WebM и finite serialized `Initialization -> Media*` rows. Human evidence matrix: `docs/matroska-webm-s28b.md`; focused corpus: `crates/symphonia-demux/src/factory/tests/matroska.rs`; Range/non-Range evidence: `crates/web-media-http/tests/progressive_containers.rs`.
- Exact `symphonia-format-mkv 0.6.0` crates.io source теперь заменён standalone patch-ом `crates/symphonia-format-mkv-patch` (archive SHA-256 `fb17713e134f5ad316c2690fa3104590ccc85842cdbcf82c3cd1a845cb08aa74`). Он остаётся единственным владельцем packet/container demux: Cluster, Block, lacing и packet payload разбираются только там; второй packet parser и FFmpeg demux не добавлены.
- Осознанное S28G-исключение: `symphonia-demux::matroska_metadata` является bounded fail-open индексатором уже доступных EBML prefix-ов для `Tracks`/`Colour` и `SeekHead`/`Cues`. Это structural metadata reader, но не второй demuxer; ему запрещено расширяться до Cluster/Block/lacing/packet parsing. Перенос этого индексатора в format patch требует отдельной design/ownership session, а не gate-правки.
- Matroska `CodecState` считается полной заменой исходного `CodecPrivate`: patch сначала валидирует Block/lacing, обновляет Symphonia track codec parameters, затем возвращает `ResetRequired` строго до первого зависимого packet-а. `symphonia-demux` отображает это в `TracksChanged`; finite ordered wrapper синхронно обновляет event и последующий public `tracks()` snapshot, сохраняя zero-duration-as-unknown normalization.
- Container-owned EBML truncation больше не маскируется generic `UnexpectedEof -> EndOfStream`: exact document boundary остаётся clean EOF, partial header, declared payload beyond known document end и physical EOF внутри declared parent у forward-only source являются structural parse errors. Generic fallback других Symphonia format readers не менялся.
- `SymphoniaDemuxFactory` рекламирует `OrderedSegments` exact для `iso-bmff`, `matroska` и `webm`; open проверяет capability выбранной registration, а не список container IDs. Cluster-first ordered media sniff нужен для точного MediaBeforeInitialization lifecycle error. Ordered input остаётся finite и non-seekable; repeated init/live/discontinuity/manifest fetch принадлежат S31+.
- Hermetic proof покрывает EBML signature sniff без extension, local, HTTP Range/non-Range, Init+multiple Cluster rows, cancellation, cues/no-cues и текущий DecodePointBefore retry, none/Xiph/fixed/EBML lacing, VP8/VP9/AV1 identities, Opus/Vorbis private data, exact packet bytes/PTS/duration, media duration, seek и malformed/truncated distinctions.
- Ограничение: sequential CodecState transition поддержан; random seek через dynamic CodecState boundary не обещается до отдельного authoritative CueCodecState restore contract.
- Verification: Rust 1.96 focused tests for demux-api/symphonia-demux/web-media-http/codec-core/audio, app capability projection test, strict relevant Clippy, direct patch tests, dependency-patch integration/inventory, cargo-deny licenses/bans/sources, machete, fmt, diff, toolchain and refactor guardrails.

Связанные memories: `mem:symphonia-demux/core`, `mem:symphonia-demux/matroska-decode-point-before-cues`, `mem:dependency-patches/core`, `mem:demux-api/core`.
