# «Общая доска» настроек (browser-bridge 04c, 2026-10-31; решения 135–140 плана `user/browser-bridge/`)

Все копии плеера (обычное окно, процессы `--browser-session`) пишут ОДИН `config.toml` и синхронны на лету. Отчёт: `user/browser-bridge/results/04c.md`.

## Запись (config + fastiplayer-settings)
- `fastiplayer-config::store/shared_file*`: замок `config.toml.lock` (`ConfigPaths::config_write_lock_file`, `config_write_lock_path_for`) — flock `File::try_lock` с ожиданием до срока (`DEFAULT_SHARED_CONFIG_LOCK_WAIT` 2 с), 0600, O_NOFOLLOW|O_CLOEXEC, наш uid (единственный `unsafe` — `geteuid`, `deny(unsafe_code)`), сверка inode; замок НЕ удаляется. Каталог без права создавать файлы и замка нет → `ConfigWriteGuard::DirectoryAcceptsNoNewFiles` (без замка, запись сама вернёт ошибку).
- `update_shared_config_at(path, lock_wait, MissingConfigFileSeed{Defaults|WriterDocument(&AppConfig)}, merge)` → `SharedConfigUpdate{Written, WrittenDurabilityUnconfirmed, LockBusy, LockUnavailable, DiskConfigUnusable, DiskConfigNewer, MergeRejected, MergedConfigInvalid, MergedConfigNotSerializable, WriteFailed}`; `read_shared_config_at` → `SharedConfigRead{Parsed, Missing, Unreadable, Newer}` (без замка, без побочных эффектов). Общий разбор — `store/disk_read.rs`. `load_or_recover_at` делает `.bak`/defaults/уборку temp ПОД замком; замок не взят → `ConfigSessionOnlyReason::ConfigLockUnavailable`.
- `ConfigSessionOnlyReason::lifts_when_file_becomes_usable()` (снимаются: BrokenConfigLeftToRegularPlayer, BackupFailed, DefaultConfigNotWritten, ConfigLockUnavailable, ConfigFileUnreadable, ConfigPathIsNotFile; НЕ снимаются NewerSchemaVersion, ConfigDirectoryUnknown) + `ConfigSaveTarget::resume_writing_after_usable_file()`. `BrowserSessionReadOnly` удалён.
- `fastiplayer-settings::shared_persist*` (`AppConfigStore::persist`, конструктор `from_loaded_config`): на перечитанный документ — только `changed_settings` по id. Неудачная запись (занят/битый/новее/замок/запись/конфликт валидации слитого) НЕ откатывает: `PersistOutcome::SkippedSessionOnly` + текст в `durability_warning`; различать ТОЛЬКО через `settings_file_persist_outcome` → `{Saved, SavedDurabilityUnconfirmed, NotSavedYet{notice}, SessionOnly, NothingToSave}`. Ошибка сериализации (`MergedConfigNotSerializable`) — ошибка транзакции с откатом.
- Несохранённые id — `shared_persist/unsaved.rs` `SharedFileKnowledge`: база = значение в ПОСЛЕДНЕМ ВИДЕННОМ документе диска (старт `LoadedConfig::config_seen_on_disk`, своя запись, `AppConfigStore::note_disk_config_seen` после каждого `Parsed` доски). Дописывание: диск == память → уже; диск == база → пишем своё; иначе сосед записал позже → его значение. `NeverSeen` → база = первый нормальный документ. `save_unsaved_changes(committed) -> UnsavedChangesSave`.

## Слежение и приём (settings-core + app-egui)
- `app-egui/src/config_file_watch*`: нейтральный шов + Linux inotify (libc, поток на `poll(-1)` + eventfd остановки), каталог config (IN_CLOSE_WRITE|MOVED_TO|CREATE|DELETE|MOVED_FROM по имени файла; `.lock`/temp игнор), нет каталога → подписка на предка; после каждой подписки — сигнал «сверься»; ошибка ОС → одно предупреждение, без слежения. Пробуждение — `AppWakeOwner::ConfigFile`. Не-Linux — `UnsupportedPlatform`.
- `settings-core::begin_adopt_external_settings / poll_external_adoption / cancel_external_adoption` (`controller/pending_apply/external_adoption.rs`): конвейер Apply без persist (делегату persist не нужен по типам), общий слот транзакции `TransactionOrigin{UserApply, ExternalAdoption}`; draft: нетронутое поле подтягивается, тронутое пользователем остаётся.
- `fastiplayer-settings::peer_adoption` — ЕДИНСТВЕННЫЙ источник «что принимать на лету» (решение 137): запоминаемое = механизм `RememberedStateOnly` (`browser_session.window.*`) + audio.volume, audio.muted, subtitles.enabled, ui.sidebar.width_points. `adoptable_peer_changes`.
- `settings_runtime/shared_board*` (шаг `advance_shared_settings_board` в `frame_prepare/runtime_settings_persistence.rs`): свой Apply запланирован/в полёте → чужое ждёт; во время принятия Apply пользователя остаётся `Scheduled` (`stepwise_apply.rs`); `RuntimeBlocked` → повтор через 250 мс; отказ — одно уведомление, отпечаток файла + отказанные пары (id, value) в `shared_board/refused.rs` (несвязанная запись соседа тост не повторяет); `Unreadable/Newer` — одно уведомление на проблему. `has_pending_apply()` включает работу доски. Lifecycle-flush обоих окон зовёт `cancel_external_adoption` после `cancel_pending_apply`. Плашки «не пишется» снимаются `withdraw_settings_file_write_notices` (`state/notifications/settings_file_writes.rs`).
- Профиль рендера от соседа принимается с «Applies after restart / Restart now», без тоста.
