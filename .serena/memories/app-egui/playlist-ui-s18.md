# Playlist read-only UI — Session 18

- `ui/playlist/` — read-only renderer; `ui/sidebar.rs` остаётся единственным Panel/width/animation host. Renderer принимает только immutable `PlaylistViewModel` и не имеет controller/action/file-open API.
- `PlaylistViewModel` — дешёвая value-обёртка над `Arc<PlaylistViewSnapshot>` плюс заранее собранные O(1)/bounded loading/probe/save/navigation/startup summaries. Не клонировать `PlaylistDiscoveryJobsReadModel` per frame: progress читается отдельным Copy boundary `manual_probe_progress`.
- Revision-stable snapshot хранит `Arc<[PlaylistViewRow]>`, shared `Arc<str>` title/fallback и один раз при structural publication строит `Arc<HashMap<PlaylistItemId, usize>>`. До `ScrollArea::show_rows` нельзя обходить/клонировать full queue; callback использует только requested range.
- egui pinned 0.34.2: fixed `ROW_HEIGHT=34`, `ScrollArea::show_rows(ui, row_height_sans_spacing, total_rows, callback)`, persistent `id_salt("playlist_rows_scroll")`, stable row IDs из Item ID. `ScrollAreaOutput.state.offset.y` и `vertical_scroll_offset` используются для anchor restore.
- `PlaylistUiState` владеет только viewport anchor: top-visible Item ID + intra-row offset + observed structural revision. На structural revision row index восстанавливает тот же Item ID/offset; active/pending-only changes ничего не scroll-ят и не меняют selection/focus. Нельзя auto-scroll к active.
- Во время sidebar content animation disabled outgoing/incoming copies получают временный `PlaylistUiState` и отбрасываемый output. Только authoritative visible copy может менять anchor и публиковать metadata demand hint.
- `PlaylistUiOutput` дедуплицирует и ограничивает visible IDs до 256. Frame оборачивает их в `PlaylistVisibleItemsHint` с exact `PlaylistRuntimeBinding`, повторно проверяет binding и вызывает существующий `request_visible_metadata_refresh`; UI не открывает files.
- Row geometry фиксирована: index/kind/title/duration/badge slot; title truncate. active/pending/error/selected независимы. D49 previous error + current retry показываются одновременно в том же badge slot и различаются accessibility. D55 failed navigation не имеет pending spinner, сообщает об остановленном automatic transition и продолжении cursor через Next/Previous/retry.
- Safe text берётся только из cached display title/fallback и `PlaylistItemRuntimeError::safe_summary`; raw locator/debug state не попадает в tooltip, accessibility, count или status.
- Отдельные read-only states: loading != empty, active tombstone, structural-disabled, probe progress/completion/warning, save saving/D69 retry warning/block/fault, D55 navigation wait/failure и D70 row unavailable. Никаких modal/actions в Session 18.
