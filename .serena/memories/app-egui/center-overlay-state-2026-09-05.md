# Central overlay: start hint is Idle-only

- `state/ui_runtime.rs::AppState::render_center_overlay` receives existing `PlaybackState` from the frame's immutable `PlayerSnapshot`, rather than `is_playing: bool`. Player state/lifecycle remain owned by player-core; no commands, config schema or public API changed.
- Start hint `Open a file or URL to start` is painted only in Idle. Paused, Playing, Opening, Buffering, Seeking, Scrubbing, Draining, Ended, Stopped and Failed do not paint it. Non-Playing must never be used as a proxy for no media.
- Since UX session 04 (2026-10-05) the overlay takes `&NotificationsFrame` + `&mut NotificationUiOutput` instead of `error_message`/`pending_message`. Priority: queue replacement confirmation > import preview > center notice (open progress > media failure with ×) > Idle hint. Toasts are always painted in the bottom-right corner of the central panel (`ui::notifications::render_toast_stack`). `player_snapshot.last_error` is no longer read here: fatal = `PlaybackState::Failed` only. Owner and lifecycle: `mem:app-egui/notifications`.
- Since UX session 15 (2026-10-08) the center has a lowest-priority buffering spinner (between center notice and Idle hint): `NotificationsFrame::shows_buffering_indicator()` → `ui::buffering_indicator::render_buffering_indicator(ui, motion)` → `ArtworkPainter::buffering_spinner` (`ui-artwork-egui/src/buffering_spinner.rs`). Owner decisions: spinner only (no text), Buffering + Seeking, 500 ms appear delay (const `BUFFERING_INDICATOR_APPEAR_DELAY`). Owner of the decision: `state/notifications/buffering.rs` (`PlaybackWaitingWatch` inside `NotificationCenter`), details in `mem:app-egui/notifications`. `render_center_overlay` signature unchanged.
- Renderer returns typed confirmation/import actions only after actual input; notification dismissals go through `NotificationUiOutput` and are applied after the egui pass (`apply_notification_actions`).
- Functional tests in `state/center_overlay_tests.rs` run the real egui renderer for three frames (a new egui `Area` only measures on its first frame) and inspect painted text shapes for all states and overlay priority, plus an end-to-end real-player seek rejection → toast → empty after 5 s. Run `cargo test -p app-egui --locked center_overlay`.
- `ui_runtime.rs` is a legacy oversized file (baseline 826 after session 04): new overlay logic goes to `ui/notifications.rs` / owner modules, not here.
