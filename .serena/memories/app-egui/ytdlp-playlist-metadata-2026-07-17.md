# Generic yt-dlp playlist metadata enrichment (2026-07-17)

- `service-ytdlp` владеет read-only boundary `resolve_yt_dlp_playlist_metadata_with_config() -> YtDlpPlaylistMetadata`. Он запускает системный `yt-dlp` с прежним metadata-only argument contract (`--quiet --no-warnings --simulate --dump-single-json --no-playlist`), не открывает media bytes и возвращает только normalized непустой title + bounded duration.
- Системный `yt-dlp` продолжает читать собственные config/cookies: `--ignore-config` не добавлен. Process cancellation/timeout/non-zero/invalid response разделены в `YtDlpServiceError`; child kill+wait не оставляет zombie, stderr и raw locator не попадают в app-visible result.
- Metadata boundary принимает любой валидный HTTP(S) `YtDlpMediaLocator`, но отклоняет collection topology через service-owned admission policy. Playback compatibility и metadata enrichment остаются разными side-effect boundaries.
- Уже подготовленный `YtDlpStreamingMedia::playlist_metadata()` переиспользует title/duration того же extraction snapshot без второго I/O. App media preparation заполняет только отсутствующие demux title/duration; demux metadata остаётся primary.
- `app-egui::playlist_runtime::discovery::yt_dlp_metadata` — process-lifetime owner над `bounded-work-executor`: максимум 2 worker-а, executor queue 16, app pending 256, retry delay 30 s. Terminal notifier использует `AppWakePort`; UI thread не блокируется и не poll-ит process/network.
- Service registry выдаёт `PlaylistUrlMetadataSource::YtDlp` для всех generic yt-dlp URL; app не проверяет hosts и не парсит raw secret URL. Результат применяется только при совпадении exact Item ID + exact locator. Duplicate URL независимы, stale locator/удалённая строка не воскресают, cache merge не стирает artists/album/sequence и не влияет на playback/order/current.
- Queue replacement/Clear/shutdown отменяют pending/active enrichment. Running child получает cancellation. Ошибки используют redacted safe label и bounded retry, без process-per-frame loop.
- Focused coverage находится в `crates/app-egui/src/playlist_runtime/discovery/yt_dlp_metadata/tests.rs`, `playlist_runtime/actions.rs` и service metadata/process tests. Hermetic tests не требуют сети.
- Актуальная service/privacy/config архитектура: `mem:media-services/core`, `mem:media-services/secret-safe-locators-s10b`, `mem:config/schema-v6-ytdlp-migration-2026-07-17`.
