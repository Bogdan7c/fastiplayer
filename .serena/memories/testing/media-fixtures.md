- Default `cargo +1.96.0 test --workspace --locked` must not read `test-assets/` or any real media file. Do not add media files, fixture packs, downloads, `include_bytes!` copies of real media, or a required filename inventory to Git. Keep `.gitignore:test-assets/`.
- Hermetic demux/service tests use `FakeFormatReader`, fake dual streams, structured Matroska EBML/cue bytes, a generated in-memory PCM WAV, and a small structured WebM byte stream. They verify behavior without owner-local assets.
- Hardware decode regression exception: `crates/video-vaapi/tests/av1_mp4_seek_regression.rs` (scenario `av1-mp4-vaapi-global-motion`) runs a real AV1 MP4 through the production VA-API decoder thread; `symphonia-demux` is a video-vaapi dev-dependency only for this.
- Codec/container-specific real regressions live as ignored tests under `crates/symphonia-demux/tests/` and take `fastiplayer_MEDIA_PATH`; they never derive a path beneath `test-assets/`. The test support detects container signatures and reports actual public tracks/codecs.
- Run exactly one local real-media scenario with `scripts/media-regression.sh --scenario <name> --path <file>`. `--list-scenarios` documents required file properties. The runner never searches paths or assumes names; it reports selected absolute path, detected container, track codecs, scenario, and `PASSED`/`FAILED`. With no selection it prints `NOT RUN: missing selection` and exits 0; an explicitly selected scenario missing its path prints the same status and exits nonzero.
- `scripts/playback-smoke.sh` remains optional release-only UI acceptance. It now needs explicit `--mode` plus `--vp9`, `--av1`, and/or `--h264` paths according to the selected mode; it does not guess local paths. No selection is `NOT RUN: missing selection`/0; a requested media mode missing required paths is the same status/nonzero.
- Real manual matrix retains: H.264 avcC/keyframes/B-frame PTS-DTS/signed ctts/startup/cues; H.265 hvcC/MOV sync sample/Matroska cues; VP9 decode point; audio decode-seek/seekable and unseekable EOF replay/Matroska late seeks/WavPack unsupported; direct HTTP Range; YouTube Range/fallback/live. See `docs/manual-media-regressions.md` and runner help.
