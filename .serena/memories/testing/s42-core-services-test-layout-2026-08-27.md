# S42 dedicated unit-test layout (2026-08-27)

- Исходные dedicated-test relocation blocks были behavior-neutral: production API, runtime behavior, test names и assertions не менялись. Wave2 отдельно добавила два подтверждённых private production boundaries — `process.rs` → `process/recovery.rs` и `request_material.rs` → `request_material/normalization.rs` — при сохранении существующих external/internal API paths.
- `crates/capability-core/src/selection.rs` declares `#[cfg(test)] mod tests;`; its unit tests live in `crates/capability-core/src/selection/tests.rs`.
- `crates/hds-manifest-core/src/bootstrap.rs` declares `#[cfg(test)] mod tests;`; its unit tests live in `crates/hds-manifest-core/src/bootstrap/tests.rs`.
- `crates/service-direct-media/src/lib.rs` declares `#[cfg(test)] mod tests;`; its unit tests live in `crates/service-direct-media/src/tests.rs`.
- `crates/source-core/src/http.rs` declares `#[cfg(test)] mod tests;`; its main HTTP range unit tests live in `crates/source-core/src/http/tests.rs`; the existing sibling `range_redirect_tests` and `error_mapping_tests` modules remain unchanged.
- App-egui second short wave follows the same layout: `media_open/coordinator.rs` -> `media_open/coordinator/tests.rs`, `startup_media.rs` -> `startup_media/tests.rs`, and `video_pipeline_selector.rs` -> `video_pipeline_selector/tests.rs`.
- Existing nested app test modules remain at the same logical paths: `media_open::coordinator::tests::same_lineage_tests` still loads `media_open/coordinator/tests/same_lineage_tests.rs`, and `video_pipeline_selector::tests::av1` still loads `video_pipeline_selector/tests/av1.rs`.
- The external modules remain private descendants of their production parents, so existing `use super::*` access to private parent items is preserved under Rust privacy rules.

- Service-ytdlp second short wave externalized `src/process.rs` inline tests and test-only fixtures to `src/process/tests.rs`; test names/assertions and functional coverage remain unchanged apart from rustfmt normalization after removing one nesting level.

Parent production owners are now 492 and 528 lines; child production owners are 245 and 332 lines.
