# Runtime Playback Smoke Acceptance

- Optional local acceptance runner remains `scripts/playback-smoke.sh`; it is not itself a full hosted-CI playback gate. Session 17 adds `scripts/runtime-acceptance.sh` as the executable manifest for four suites: `hermetic-ci`, `runtime-software`, `vaapi-hardware`, and `playback-matrix`. Human inventory and exact commands live in `docs/runtime-acceptance-manifest.md`.
- Outcome contract is explicit: `PASS` only after real execution; selected suite with a missing fixture/runtime/hardware prerequisite prints `SKIP: <reason>; acceptance not satisfied` and exits 3; no selection or dry-run prints `NOT RUN: <reason>; acceptance not satisfied`. Hermetic acceptance reports the reasons for runtime tests that remain outside that suite.
- Playback modes: `full` runs FFmpeg probes, release build, and the combined host-specific hardware/software regression set; `software-only` runs probes plus FFmpeg software scenarios; `hardware-only` runs VA-API VP9 success and typed AV1 rejection without FFmpeg probes; `probe-only` runs fake/unit probes plus the ignored installed-runtime FFmpeg probe; `legacy-migration` is the separately named config migration smoke.
- Media modes require explicit local paths and never search `test-assets/`: full needs `--vp9`, `--av1`, `--h264`; software-only needs VP9/H.264; hardware-only needs VP9/AV1. Missing selection remains `NOT RUN`; an explicitly requested mode missing required paths is nonzero.
- Every playback scenario config is now generated by `crates/config/examples/smoke_config.rs` from full `AppConfig::default()`, then overrides only `player.start_paused = false` and the scenario `video.preferred_backend`. The helper uses the production atomic writer and production loader, so current smoke writes and parses schema v8 with every current field, including `yt_dlp.hdr_selection = "sdr_only"`; it cannot silently exercise legacy migration.
- Non-GUI contract tests live in `scripts/tests/playback-smoke-self-test.sh`: missing/invalid argument parsing; full, direct probe-only and direct legacy-migration dry-run outcome markers; fake-Cargo success/failure orchestration with exit-code preservation; current schema v8 config generation/parse; manifest NOT RUN/dry-run/SKIP. `scripts/ci-checks.sh format-guardrails` runs `bash -n` for runtime scripts and these self-tests.
- Scenario matrix remains: auto+VP9 Profile 0 expects `vaapi-dmabuf-wgpu`; auto+AV1 expects reselection and `ffmpeg-host-upload-wgpu`; software+H.264 expects FFmpeg host upload; hardware+AV1 expects typed `UnsupportedVideoCodec` without fallback; software+VP9 stress rejects resource exhaustion/starvation markers.
- Positive playback scenarios reject known fatal regressions: InvalidData/OBU/start-code/resource-table/decoder-disconnect/panic/render-resource/app fatal markers. Full playback acceptance must not run unless the owner explicitly supplies local asset paths and the runtime/hardware preflight succeeds.
- First-party ignored runtime inventory at S42: one FFmpeg installed-runtime probe; 17 symphonia-demux local-media regressions (6 H.264, 3 H.265, 1 VP9, 6 audio, 1 inspection); one direct HTTP Range; no ignored `service-ytdlp` network regressions. Fixture scenarios remain individually runnable through `scripts/media-regression.sh --scenario <name> --path <file>`; real web URLs belong only to explicit S42 manual opt-in.

## S42 web-media manual acceptance

- `scripts/final-acceptance.sh` owns automated S42 composition (`scripts/ci-checks.sh all` plus `scripts/coverage.sh check`) and deliberately leaves user URL/fixture acceptance `NOT RUN`.
- `scripts/progressive-web-smoke.sh` accepts only explicit HTTP/HTTPS/FTP/FTPS URLs or local fixture roles. A required S42 row is selected as `--case <safe-id> --url <locator>` or `--case <safe-id> --fixture <path>`; legacy bare `--url` maps to `legacy-url-N` and cannot close the 29-case matrix.
- Real execution fail-closed requires exact system `yt-dlp 2026.07.04`, records profile/source, workspace HEAD plus clean/dirty classification, exact Rustiplayer binary origin/SHA-256 and yt-dlp executable SHA-256, removes raw temporary logs, and saves only redacted evidence. Runner-built binary is associated with the current worktree; explicit external prebuilt is never attributed to workspace HEAD. A real fixture is canonicalized relative to the caller working directory before the runner changes directory; the redactor removes its canonical path, basename, encoded basename, file URI and percent-encoded forms. Report creation uses exclusive `noclobber` create, so a file appearing after preflight is never overwritten. Exit 137/SIGKILL is `FAIL`, while graceful timeout 124 remains manual-reviewable. Missing cases keep matrix status `NOT RUN`; complete selection remains `MANUAL REVIEW REQUIRED`; runtime failure is `FAIL`; no path emits global `PASS`.
- The S42 matrix, privacy boundary and checklist live in `docs/web-media-s42-final-acceptance.md`; exact supported/excluded rows live in `docs/web-media-compatibility-matrix.md`; operational error meanings live in `docs/web-media-operational-errors.md`.
- The only owner-approved hardware-capability delta is exact `VAProfileH264Baseline` → H.264 Baseline 8-bit YUV420/NV12, capability intersection only; broader hardware acceptance is not claimed, and the current hardware manual rerun is `NOT RUN` because the owner has no compatible VA-API device for an opt-in rerun.
- The same shutdown outcome rule applies to `scripts/playback-smoke.sh`: only clean exit 0 and graceful timeout 124 are acceptable scenario statuses. Status 137 means kill-after/SIGKILL and fails the scenario; the shell self-test ratchets that source contract.
