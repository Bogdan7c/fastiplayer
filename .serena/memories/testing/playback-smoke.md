# Runtime Playback Smoke Acceptance

- Optional local acceptance runner remains `scripts/playback-smoke.sh`; it is not itself a hosted-CI playback gate. `scripts/runtime-acceptance.sh` is the executable manifest for four suites: `hermetic-ci`, `runtime-software`, `vaapi-hardware`, and `playback-matrix`. Human inventory and exact commands live in `docs/runtime-acceptance-manifest.md`.
- Outcome contract is explicit: `PASS` only after real execution; selected suite with a missing fixture/runtime/hardware prerequisite prints `SKIP: <reason>; acceptance not satisfied` and exits 3; no selection or dry-run prints `NOT RUN: <reason>; acceptance not satisfied`. Hermetic acceptance reports the reasons for runtime tests that remain outside that suite.
- Current playback modes: `full` runs FFmpeg probes, release build, software regressions and the host-specific VA-API matrix; `software-only` retains H.264 and VP9 FFmpeg scenarios; `hardware-only` runs positive VP9 plus positive AV1 Main SDR/HDR without FFmpeg probes; `probe-only` runs fake/unit probes plus only the exact ignored `ffmpeg_runtime_probe` integration test (`--test ffmpeg_runtime_probe -- --ignored --exact installed_ffmpeg_runtime_probe_reports_available_runtime`); `legacy-migration` is separate.
- Media paths are explicit and never discovered in `test-assets/`: `full` requires `--vp9`, AV1 Main 8-bit SDR `--av1`, AV1 Main 10-bit HDR `--av1-hdr`, and `--h264`; `hardware-only` requires VP9 plus both AV1 files; `software-only` requires VP9/H.264. Missing manifest prerequisites are reasoned SKIP; incomplete direct mode selection remains nonzero NOT RUN.
- Full/hardware preflight is fail-closed: the selected render node defaults to `/dev/dri/renderD128`, `vainfo` is invoked headlessly as `vainfo --display drm --device <node>`, and exact `VAProfileAV1Profile0 : VAEntrypointVLD` is mandatory. `RUSTIPLAYER_SMOKE_VAAPI_RENDER_NODE` supports a deliberate multi-GPU/test override.
- Every playback scenario config is generated by `crates/config/examples/smoke_config.rs` from full `AppConfig::default()`, overriding only `player.start_paused = false` and `video.preferred_backend`. Current smoke writes and production-parses schema v9, including `yt_dlp.hdr_selection = "sdr_only"`; legacy migration cannot be exercised silently.
- Current matrix: auto+VP9 expects `vaapi-dmabuf-wgpu`; hardware+AV1 SDR expects AV1 adapter + NV12 DMA-BUF; hardware+AV1 HDR expects AV1 adapter + P010 DMA-BUF; software+H.264, full-only software+AV1 SDR, and software+VP9 use `ffmpeg-host-upload-wgpu`. Every positive scenario requires exact `video frame submitted to renderer`; the dedicated trace target is enabled without general per-frame trace noise. AV1 hardware additionally rejects FFmpeg fallback and backend reselection. Known InvalidData/OBU/start-code/resource-table/decoder-disconnect/panic/render-resource/app fatal markers are forbidden. On 2026-08-24 both real `hardware-only` and `full` matrices passed on Radeon 780M/Mesa, including AV1 SDR NV12, AV1 HDR P010 and exact renderer submit; see `mem:video-vaapi/av1-hardware-2026-08-24`.
- Non-GUI contract coverage in `scripts/tests/playback-smoke-self-test.sh` includes parser/help, mandatory HDR asset validation, full/hardware dry-run matrix, fake `vainfo` exact-profile SKIP, fake-Cargo exit propagation, current schema v9 generate/parse, manifest outcomes and workflow HDR wiring. `scripts/ci-checks.sh format-guardrails` runs runtime-script `bash -n` and this self-test.
- First-party ignored runtime inventory at S42: one FFmpeg installed-runtime probe; 17 symphonia-demux local-media regressions (6 H.264, 3 H.265, 1 VP9, 6 audio, 1 inspection); one direct HTTP Range; no ignored `service-ytdlp` network regressions. Fixture scenarios remain individually runnable through `scripts/media-regression.sh --scenario <name> --path <file>`; real web URLs belong only to explicit S42 manual opt-in.

## S42 web-media manual acceptance

- `scripts/final-acceptance.sh` owns automated S42 composition (`scripts/ci-checks.sh all` plus `scripts/coverage.sh check`) and deliberately leaves user URL/fixture acceptance `NOT RUN`.
- `scripts/progressive-web-smoke.sh` accepts only explicit HTTP/HTTPS/FTP/FTPS URLs or local fixture roles. A required S42 row is selected as `--case <safe-id> --url <locator>` or `--case <safe-id> --fixture <path>`; legacy bare `--url` maps to `legacy-url-N` and cannot close the 29-case matrix.
- Real execution fail-closed requires exact system `yt-dlp 2026.07.04`, records profile/source, workspace HEAD plus clean/dirty classification, exact Rustiplayer binary origin/SHA-256 and yt-dlp executable SHA-256, removes raw temporary logs, and saves only redacted evidence. Runner-built binary is associated with the current worktree; explicit external prebuilt is never attributed to workspace HEAD. A real fixture is canonicalized relative to the caller working directory before the runner changes directory; the redactor removes its canonical path, basename, encoded basename, file URI and percent-encoded forms. Report creation uses exclusive `noclobber` create, so a file appearing after preflight is never overwritten. Exit 137/SIGKILL is `FAIL`, while graceful timeout 124 remains manual-reviewable. Missing cases keep matrix status `NOT RUN`; complete selection remains `MANUAL REVIEW REQUIRED`; runtime failure is `FAIL`; no path emits global `PASS`.
- The S42 matrix, privacy boundary and checklist live in `docs/web-media-s42-final-acceptance.md`; exact supported/excluded rows live in `docs/web-media-compatibility-matrix.md`; operational error meanings live in `docs/web-media-operational-errors.md`.
- Historical S42 evidence approved only exact `VAProfileH264Baseline` → H.264 Baseline 8-bit YUV420/NV12 capability intersection; its hardware manual rerun was `NOT RUN` at that time. The current AV1 Main SDR/HDR runner matrix is a separate post-S42 feature acceptance and does not rewrite S42 evidence.
- The same shutdown outcome rule applies to `scripts/playback-smoke.sh`: only clean exit 0 and graceful timeout 124 are acceptable scenario statuses. Status 137 means kill-after/SIGKILL and fails the scenario; the shell self-test ratchets that source contract.
