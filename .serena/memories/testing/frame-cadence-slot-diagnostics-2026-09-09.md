Important diagnostic distinction: `texture_lookup=ready` does NOT prove successful handoff-slot acquisition. Existing `RenderLeaseBridgeClient::try_acquire_present_frame` maps both LatestPresentFrameAcquire::Empty and Busy to None, and app can reuse a cached frame whose texture is Ready. Do not attribute all Ready repeats to scheduler timing or all contention to texture lookup.

New `player-core/src/render_lease_bridge/cadence_diagnostics.rs` emits `latest present frame acquisition completed` on existing opt-in `fastiplayer::frame_cadence=trace`, with handoff_lookup acquired/empty/busy and optional acquired PTS/render/decode generations. It borrows the completed result after try_clone_latest releases its guard and after the existing timing sample, adds no lease/history/counter/wait, and preserves existing Option API and release/accounting. Disabled target skips identity extraction. Main bridge adds only module declaration and one call; new logic is in its child module.

`app_instance/cadence_acceptance/gate.rs` strengthens the existing actual AppShell/VA-API/swapchain causal tests: slot outcome must be acquired, and acquired identity must reach Ready preparation and actual surface handoff. Ordinary tests skip these explicit manual cases; run alone as documented in docs/benchmarks/frame-cadence-diagnostics.md. Validation is pending when this memory is introduced; never infer success from the presence of assertions.

Direct regression protocol preserves immediate-before 7dc707ce release and post-fix ca657f2c release separately, with six fixed AB/BA pairs for each of five quiet scenarios. This comparison does not measure the new diagnostic code. Full logs/config/media/binaries/source hashes stay private. Separate diagnostic attempts use identical new slot instrumentation on before/current snapshots; do not pool them with quiet CPU data. Publication markers run after unlock/drop, and concurrent log lines can be out of timestamp order: neither file order nor marker timestamp alone proves the exact instant of slot visibility.
