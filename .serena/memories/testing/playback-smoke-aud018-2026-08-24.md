# AUD-018: truthful direct playback-smoke dry-run outcomes (2026-08-24)

- Independent read-only verification reproduced both false positives: `scripts/playback-smoke.sh --mode probe-only --dry-run` and `--mode legacy-migration --dry-run` exited 0 and wrote production `PASS` to stderr even though `run_step` only printed commands. Real legacy migration exited 0 with 9 tests and the identical PASS; an intentionally failing probe exited 101 without PASS. A fully successful real probe-only wrapper remained unavailable in the headless host because a later WGPU ignored test had no Vulkan adapter, while the exact installed-runtime FFmpeg probe passed independently.
- Root cause: `run_probe_steps` and `run_legacy_migration_smoke` unconditionally printed PASS after `run_step`; dry-run returned success from `run_step` because command printing succeeded.
- `scripts/playback-smoke.sh` now centralizes the workflow marker in `report_acceptance_outcome()`: immutable CLI `dry_run=true` produces only `DRY-RUN: WOULD RUN <acceptance>; no checks were executed`; real control flow reaches `PASS: <acceptance>` only after all preceding `run_step` commands succeeded under `set -e`. Dry-run is not encoded as a nonzero shell status because that would be an execution failure under errexit.
- `scripts/tests/playback-smoke-self-test.sh` covers full/probe-only/legacy direct dry-run through the public CLI, requires planned commands and DRY-RUN/WOULD RUN, and rejects production PASS. A temporary fake Cargo proves two successful process-boundary calls lead to PASS, while exit 17 is preserved, stops after the first call, and emits no PASS.
- During verification, stale smoke schema literals were synchronized with config-owned `CURRENT_SCHEMA_VERSION = 8`; production schema or migration logic did not change.
- Validation: both shell files pass `bash -n`; canonical playback smoke self-test passes; both direct dry-run commands exit 0 with plan-only markers; real legacy migration passes 9/9 and emits PASS; `git diff --check` passes after final cleanup. `scripts/ci-checks.sh format-guardrails` passes runtime syntax and all runtime-script self-tests, then fails only on pre-existing S42 oversized Rust-module baselines outside AUD-018.
