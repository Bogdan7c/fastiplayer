# Субтитры страницы в экстеншене (мост, сессия 13b2, 2026-11-09, решения 270–272, 275, 276)

План: `user/browser-bridge/13b2-page-subtitles-extension.md`, отчёт `results/13b2.md`, итог 13b — `results/13b.md`. Плеерная половина — `mem:subtitles/page-tracks-13b1`.

## Договор (общая граница, `extensions/browser/src/shared/`)
- `page-subtitle-contract.ts`: `PageEvent` получил `subtitle_document {key, naming, format_hint, origin: page_download|text_track_cues, display, bytes}` и `subtitle_track_source {key, naming, display, url, referrer_origin, referrer_policy}`; `PageSubtitleNaming {language|null, label|null, auto_generated}` — сырые значения страницы, к протоколу приводит ФОН. `key` (u32≥1) — ключ дорожки внутри ДОКУМЕНТА (тот же ключ = замена).
- Пограничник `page-subtitle-validation.ts` (зовётся из `parsePageEvent`), общие проверки вынесены в `page-value-checks.ts` (`page-message-validation.ts` реэкспортирует прежние имена). Бюджет событий — вид `"subtitle"` (256/с, `content/page-event-budget.ts`).
- `subtitle-document-sniff.ts`: `sniffSubtitleDocument(bytes)` → `document{web_vtt|srt|ttml|srv3|json3}` / `hls_segment` (WebVTT с `X-TIMESTAMP-MAP` — кусочек HLS, НЕ дорожка: его собирает hls.js в `TextTrack`) / `not_subtitles`. Первые 4 КиБ как ASCII.

## MAIN-мир (`src/page/page-subtitles/`, сборка `installPageSubtitles` в `bridge.ts`)
- Хуки `fetch` (тот же промис странице; наблюдатель снятым `Promise.prototype.then` до возврата; `clone()` синхронно ТОЛЬКО после фильтра; чтение reader-ом с потолком 8 МиБ и `cancel()`) и XHR (слушатель `load` ставится в `open()`, раньше страничных; `""`/`text`, `json` → `JSON.stringify` только при субтитровом адресе, `arraybuffer`; `blob`/`document` нет).
- Фильтр до тела `response-filter.ts` (`decideSubtitleResponse`): 2xx кроме 206, не opaque, типы субтитров читаются всегда; двусмысленные (`text/plain`, JSON, XML, octet-stream, пустой) — только при субтитровом адресе (расширение `.vtt .webvtt .srt .ttml .dfxp` или путь `timedtext|caption|subtitle` или `fmt=json3|srv3|vtt|ttml`); видео/аудио/картинки/шрифты/манифесты — никогда.
- Склад документа `downloaded-store.ts`: 16 МиБ / 32 документа, выселение старых; одинаковое содержимое (длина + FNV-1a + djb2) = тот же ключ и становится свежим; самый свежий `page_download` = `showing` (271).
- Отдача — шов `PageSubtitleSeam` в `HandoffController`: `#beginSubtitles` сразу за реплеем журнала MSE (файл/HLS — за событием источника, воркер — в `replayed`), до старта тени; пойманное позже — сразу; только пока `#active` та же передача; `#release` снимает слушатели. Байты — точная копия с transfer через `ForwardByteMeter` (его отказ = только запись `reportOddity`, передача живёт).
- `<track src>` http(s) переданного видео → `subtitle_track_source` (язык `srclang`, иначе из адреса; Referer как у `file_source`); `blob:`/`data:` и `TextTrack` без `<track>` с mode ≠ disabled → WebVTT из реплик (`web-vtt-builder.ts`), рост — та же key не чаще раза в 5 с по тикам часов плеера (`clockTick`), только `subtitles`/`captions`. `display` фиксируется в момент объявления (протокол не умеет менять).
- Именование `src/adapters/subtitle-naming/` (решение 276): YouTube timedtext (`/api/timedtext`: язык `tlang`, иначе `lang`; `kind=asr` → `auto_generated`), иначе общий `lang`/`language`. Разбор адреса ручной (без глобального `URL`).

## Фон (`src/background/handoff/page-subtitles/`)
- `page-subtitle-relay.ts` (`createPageSubtitleRelay`): владелец субтитров сеанса; `handoff-session.ts` только зовёт `beginDocument({frameId, documentTag})` в `connectToFrame` (по `incomingRef.document`), `accept(event)` из `handleFrameMessage`, `endDocument()` в `stopPageSide`. Шлёт только при `acceptsStream()` и версии ≥ 1.5 (`playerAcceptsPageSubtitles`): заголовок + рамки вида 3 подряд (`splitPageSubtitleDocument`). Исходы `SubtitleSendOutcome` различимы (`sent/player_too_old/stream_closed/too_many_tracks/over_budget/invalid_length`), журнал — `noteForDeveloper` без адресов.
- `track-registry.ts`: номер дорожки на СЕАНС по «фрейм + метка документа + ключ» (не по порту: второе видео того же документа = те же номера), ≤ 64, бюджет 32 МиБ = сумма последних длин (замена считает новую вместо старой, как `assembly.rs`).
- `track-downloader.ts`: закачка `<track src>` целиком ≤ 8 МиБ через `networkForSource` (`session-source-feeds.ts`: заслон локальных адресов внутри, Referer правилом снаружи), `credentials: include`, срок 30 с по планировщику, 3 одновременно, очередь 64, повторная проверка конечного адреса, затем sniff. Исходы: `ready/address_refused/network_error/http_error/too_large/not_subtitles/hls_segment/timed_out/cancelled/queue_full`.
- `track-naming.ts`: тег языка по правилу протокола (неверный → unknown), подпись без управляющих/bidi, ≤ 256 байт по символу; авто без подписи → `"<Язык> (auto-generated)"` через `Intl.DisplayNames(["en"])`.
- Вынесено без изменения поведения ради предела 800: `session-phase.ts` (`SessionPhase`), `outcomeOfRefusedBegin` → `session-outcome-words.ts`.

## Стенд и живая проверка
- Команда `page-subtitles` (`crates/browser-bridge-bench/src/scenarios/page_subtitles.rs` + `judge.rs`), страницы `site/pages/subtitles-{track,fetch,xhr,text-track}.html`, документы `site/subtitles/`, разбор журнала `src/observe/page_subtitle_log.rs`. ВАЖНО для судей: плеер разбирает дорожку лениво — `Page subtitle track ready` пишется только у выбранной/показанной; наличие на складе — по `Page subtitle document received track=…`; строковые поля tracing в кавычках.
- `examples/live_handoff.rs`: `--click-at x,y` (мышь стенда в невидимом kwin перед передачей) и `--screenshots <каталог>`; строки `Page subtitle` печатаются. Embed YouTube напрямую не играет (нужна страница-обёртка с Referer); Ashdi/Tortuga `…/vod/<id>` играют сами по себе, play — в центре.
- Живые факты: YouTube качает только показанный json3 (риск 271 не сработал); Ashdi/Tortuga по умолчанию качают и показывают украинские «форсированные» субтитры (надписи) и перекачивают тот же документ при каждой смене ролика (склад даёт `replaced=true`, дублей нет); язык у них `unknown` (подпись «Українські» знает только конфиг PlayerJS — адаптеры 14).
