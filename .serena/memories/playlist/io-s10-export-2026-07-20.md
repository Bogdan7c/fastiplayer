# S10 — pure M3U8/XSPF export core (2026-07-20)

## Ownership и public boundary
- `playlist-io::export` владеет pure цепочкой `PlaylistExportSnapshot::capture` → `preflight_playlist_export` → `PreparedPlaylistExport::serialize`; filesystem writer, overwrite, permissions, UI и background job остаются S11.
- Snapshot принимает `&PlaylistQueue`, клонирует только selected canonical top-level `PlaylistEntry` scope и больше не хранит queue handle. Full/Selected всегда сохраняют canonical order; caller order selection не влияет на output; subordinate compound part typed rejected; selected compound включает все parts в source order.
- Модули: `export/snapshot.rs` — scope/capture; `export/locator.rs` — target/reversible locator/service policy/secret classification; `export/m3u8.rs` и `export/xspf.rs` — infallible format serializers после preflight; facade/accounting — `export/mod.rs`. Все production файлы ниже 700 строк.

## Locator и secret invariants
- Local export требует absolute native UTF-8 path. Foreign, relative-without-base и non-UTF получают typed secret-safe ineligible; `to_string_lossy` отсутствует.
- M3U8 relative path публикуется только если `target.parent().join(relative) == exact PathBuf`, строка не выглядит comment/directive/URI scheme и не содержит line breaks; иначе используется reversible absolute `file:` URI. XSPF использует `Url::make_relative` только при доказанном inverse `document_url.join(relative) == file_url`, иначе absolute file URI.
- `PlaylistExportLocatorPolicy: Send + Sync` является service/app-owned preflight для exact durable URL и opaque `ServiceDurableReopenPayload`. Он обязан вернуть validated portable HTTP(S) `PortablePlaylistExportUrl` плюс `Public|SensitiveDurableIdentity`; service payload без portable URL rejected. Serializer types не принимают signed stream URL, headers, cookies, candidate/format IDs или другие transport values.
- Prepared plan агрегирует `PlaylistExportSecretClassification` по каждому реально сериализованному track/group-root locator; Debug/Display errors показывают только stable Item/Group ID и closed safe reason.

## Format semantics
- M3U8 всегда UTF-8, начинается `#EXTM3U`, пишет ordered `#EXTINF` + locator, сохраняет duplicates и exact MediaDuration decimal seconds; compound flatten-ится с explicit `CompoundGroupingFlattened { compound_group_count }` warning.
- XSPF пишет v1 namespace/schema, ordered track metadata/location и один playlist-level Rustiplayer extension `urn:rustiplayer:xspf:playlist-extension:1` до `trackList`; group record хранит one-based firstTrack, trackCount и root location, обычный player продолжает видеть flattened tracks.
- Metadata controls безопасно sanitizes; XML text/attributes escape-ятся и ограничены XML 1.0 character production. Locator identity не sanitizes: она либо прошла preflight exact/reversible, либо rejected.
