# S06 — secure XSPF v1 (2026-07-20)

## Ownership и dependencies
- `playlist-io` владеет namespace-aware XSPF v1 schema/model; `bounded-xml-reader` остаётся единственным untrusted XML tokenizer/security boundary.
- Новый dependency edge: `playlist-io -> bounded-xml-reader`; guardrail allowlist обновлён. Ни filesystem/network I/O, ни app/service/player/queue mutation authority не добавлены.
- Старый `M3uDocumentSource` behavior сохранён backward-compatible type alias-ом; canonical owner теперь `PlaylistDocumentSource`, а `XspfDocumentSource` — format-specific alias того же secret-safe local/network document identity.

## Parse contract
- Public entry point: `parse_xspf_document(XspfParseRequest)`; caller обязан передать bytes, document source и `XspfParserLimits`.
- Exact root namespace `http://xspf.org/ns/0/`, `version="1"`, ровно один ordered `trackList`; playlist/track children проверяются по XSPF order и cardinality.
- Streaming state machine не строит DOM. Resource state: `Vec<XspfTrack>`, per-track ordered candidates, `Vec<XspfGroup>`, один `u64` child-cardinality bitset и XML reader counters.
- Inherited `xml:base` применяется на каждом element; initial base — retrieval URI без fragment либо reversible absolute local file URI. URI references reject raw ASCII whitespace/control и malformed percent triplets; Unicode получает percent encoding через `url` serialization.
- Track сохраняет 0..N `XspfLocationCandidate` в document order без app admission/service choice; поддержаны title/creator/album/positive trackNum и millisecond duration hint. Duration не создаёт playback span/end.
- Unknown application extensions bounded-пропускаются и не исполняются. DTD/DOCTYPE, XXE/custom entities, duplicate attributes, undeclared prefixes и XML bombs отсекаются `bounded-xml-reader`; predefined/numeric XML entities остаются legal.

## fastiplayer extension v1
- Application/child namespace: `urn:fastiplayer:xspf:playlist-extension:1`.
- Known extension разрешён только один раз на playlist level до `trackList`.
- Minimal non-duplicating schema: ordered `rp:group*`; каждый group имеет required one-based `firstTrack`, positive `trackCount` и ровно один `rp:location` root candidate. Track-level duplicate group markers отсутствуют.
- После чтения trackList ranges проверяются одним линейным проходом: source order, отсутствие overlap и выходов за flattened tracks. One-part group разрешён.

## Export model
- S06 добавил только `XspfExportLocation::from_durable_locator`: native path -> reversible percent-encoded file URI; foreign/unrepresentable path, malformed durable URL и service payload без owner preflight получают secret-safe typed `XspfExportIneligible`.
- Queue snapshot/scope, compound serialization, secret acknowledgement и file writing остаются S10/S11.
