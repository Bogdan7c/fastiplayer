# S15 yt-dlp topology extraction (2026-07-20)

- `service-ytdlp` теперь владеет public bounded topology boundary: `extract_yt_dlp_topology_with_config` и `extract_yt_dlp_topology_with_budgets`; возвращаются только serializable/value-owned `YtDlpTopology::{Video, Playlist, MultiVideo, Delegation}` и retained `YtDlpTopologyEntry::Unavailable`, без child/thread/process state.
- Реализация разделена по ownership: `src/topology/limits.rs` — named default budgets + typed safe errors; `model.rs` — redacted public values/accessors; `parser.rs` — pure S00 result validation; `process.rs` — exact argv, pipes, timeout/cancel/kill/wait и bounded line reader. `lib.rs` остаётся facade.
- Exact production topology argv: `--quiet --no-warnings --simulate --dump-json --dump-single-json --flat-playlist --lazy-playlist <exact-locator>`. `--dump-json` даёт lazy child lines; последняя `--dump-single-json` line является authoritative root. `n_entries` никогда не authoritative. Hermetic profile prepends `--ignore-config --no-plugin-dirs`; production сохраняет trusted system config/cookies/plugins.
- Rustiplayer-owned argv не содержит download/write/exec/postprocessor/mark-watched options. Trusted config/plugin side effects и mutable user cookie jar остаются вне app guarantee. Profile/report и exact compatibility test обновлены в `crates/service-ytdlp/compatibility/2026.07.04/`.
- Budgets enforced до/во время allocation: aggregate stdout/stderr, JSON line, line/entry count, JSON syntax depth, topology depth, bounded identity/metadata/locator fields. Overflow, cancellation и timeout kill + wait child; stderr/raw JSON/argv locator не попадают в errors/Debug.
- Missing `_type` трактуется как video. Video требует non-empty id/title и direct URL либо non-empty formats description. `multi_video` валидирует те же root video fields плюс entries. `url` хранит `ResolvedResultOnly`, `url_transparent` — `TransparentWrapperPriority`; explicit merge method покрыт test-ом. Flat delegated targets остаются typed delegation nodes, top-level delegation, уже resolved upstream CLI, повторно не исполняется service-ом.
- Nested collections bounded active-stack cycle/depth. Null/restricted/missing-target/missing-identity child сохраняется typed unavailable row, не fake playable item. Ephemeral format/signed URLs не сохраняются в topology model.
