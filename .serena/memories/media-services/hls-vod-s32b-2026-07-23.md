## Composition/demux boundaries

- `HlsVodOpenRequest` получает injected `Arc<DemuxRegistry>`; `web-media-hls` normally зависит только от neutral `demux-api`, а concrete `mpeg-ts-demux` и `symphonia-demux` остаются composition-owned (dev dependencies только для hermetic fixtures).
- `DemuxRegistry::open_required_container` content-sniff-ом доказывает exact caller-required container и typed возвращает `UnexpectedContainer`; generic `open` semantics не менялись.
- `HlsComponentContainerIntent` требует explicit per-component TS/fMP4 evidence. Наличие MAP никогда не угадывает container: fMP4 требует MAP, TS+MAP поддержан и content-proven.
- Each discontinuity/MAP-change epoch открывает новый ordered demuxer, публикует `TracksChanged` и remap-ит stable public track IDs/timestamps в монотонную global VOD timeline. Symphonia не заставляют игнорировать discontinuity; TS existing ordered semantics reuse.
- Separate audio/video проходит existing `CompositeAvDemuxer` с caller-owned lead policy. Required component failure remains fatal before initial track publication.

## Adaptive resource boundary

- `web-media-adaptive::AdaptiveHttpContext::fetch_resource_blocking` — provider-neutral generation-fenced blocking-worker API for manifest/media/init/key resource, reusing S31 HTTP session, retries, redirects, cookies, cancellation and bounds.
- `AdaptiveResourceQueryApplication::{ApplyScopedReplacement, MergeScopedAddition, BypassScopedQuery}` distinguishes existing provider replacement, pinned HLS merge on every authorized redirect hop, and exact hls_aes URI bypass.
- Same-origin redirect reapplies scoped merged query; cross-origin monotonically strips headers/query secrets. MAP uses media-segment scope; normal keys use key scope with service-projected segment fallback; external `hls_aes.uri` bypasses key query.
- `service-ytdlp::YtDlpHlsRequestMaterial::project_scoped_queries` is the single projection into `SecretRequestContextBuilder`; HLS runtime does not retain a duplicate query string set.

## Planning/crypto/runtime invariants

- Manifest/profile/selection/container/range invariants are checked before deferred runtime publication.
- Explicit range uses checked offset/length; implicit range requires prior range of same composed resource; overflow and missing base typed rejected.
- Each epoch source lazily fetches bounded MAP/media/key resources on the progressive demux worker, never player-owner.
- Key cache is epoch-local/current-source scoped: same declaration across MAP/segments fetched once, rotation replaces, NONE clears, stale generation/epoch cannot reuse. Key/plaintext zeroize.
- Inline key suppresses fetch; external key must be exactly 16 bytes; invalid key/padding/container/required component failure occurs before first public `TracksChanged`. S32C must wait for this event before player mutation.
- Subtitle renditions stay descriptors-only; no fetch/decode/playback.
