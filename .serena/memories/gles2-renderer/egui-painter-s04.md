## Устройство (`crates/gles2-egui/src/`)
- `draw_gl.rs` — второй (после `context::safety`) модуль с `#[allow(unsafe_code)]`: `DrawGl` (из `ActiveFrame` или `Gles2Context::gl()`), обёртки GL художника и маски; проверяет длину пикселей RGBA8 и i32 до драйвера. `IndexedDraw` собирается только загрузчиком после `Mesh::is_valid` (индексы в пределах вершин). Без расширения VAO `glBindVertexArrayOES` НЕ вызывать даже для отвязки (функции может не быть).
- `painter/` — `EguiPainter`: `apply_textures` (set первым шагом; `UiTextureUpload::{InSync, OutOfSync{texture_id}}`; правило `place_image_delta` = wgpu `can_apply_image_delta`; NPOT + Repeat → CLAMP + счётчик; > MAX_TEXTURE_SIZE → пропуск + счётчик) → `retained_availability(UiScreen)` (размер + ppp побитово; `RetainedUiUnavailable::{NothingRetained, ScreenMismatch}`) → `prepare_fresh(&ActiveFrame, screen, Vec<ClippedPrimitive>)` (один VBO + один IBO, orphaning `glBufferData(NULL)`; u32 с `OES_element_index_uint` — индексы сдвинуты на first vertex, атрибуты один раз; иначе `split_to_u16` батчи с перепривязкой атрибутов на смещение; `Callback` пропускается со счётчиком) → `paint_retained` (blend ONE/ONE_MINUS_SRC_ALPHA + ONE_MINUS_DST_ALPHA/ONE, scissor `round(ppp·clip)` с переворотом Y, GL_DITHER выключен, состояние возвращается) → `free_textures(TexturesDelta)` (очищает delta всегда; без GL — откладывает). Опции: `UiDithering`, `IndexWidthPreference::{BestAvailable, U16Batches}`, `VertexArrayPreference::{UseWhenAvailable, ExplicitAttributes}`. `ContextId` (новое у `Gles2Context::id()` / `ActiveFrame::context_id()`) — чужой контекст → `PainterError::ForeignContext`. `destroy(&context)`; Drop без него — warn.
- `corner_mask/` — `CornerMaskRenderer::draw(&ActiveFrame, CornerRadius, ppp, CornerAlphaEncoding::{Premultiplied, Postmultiplied})`: формула `window_corner_mask.wgsl`, но 4 угловых квадрата стороной ceil(r)+1 без перекрытий (`axis_corners`), в вершине — расстояние до краёв своего угла (не координата), highp где есть. Геометрия грузится только при смене размера/радиуса. `CornerRadius::from_points` (NaN/отрицательный → квадрат).
- `composition.rs` — `FrameCompositor::render(&mut Gles2Context, UiFrameRequest{screen, content: UiContent::{Fresh, ReusePrevious}, background, layers: &mut dyn FrameLayers, corner_radius})`: textures → проверки (`Dropped(UiTexturesOutOfSync|RetainedUiUnavailable|UiTexturesNotApplied)`) → begin_frame (`Skipped`) → prepare → clear (Opaque-цель: альфа 1) → `FrameLayers::draw_underlay` (видео, 05) → `draw_overlays` (субтитры, 08) → egui → маска (только `PremultipliedTransparent`) → present → free. `UiFrameTimings` с именами `RenderFrameStageTimings`. `NoFrameLayers`.
- `Gles2Context::offscreen_with_alpha(size, OffscreenAlpha::{Opaque, PremultipliedLayer})` — offscreen как прозрачный слой (стенд маски).

## Тесты
- `cargo test -p gles2-egui --locked`: unit (scissor, delta placement, sampling, upload u32/u16, геометрия маски против формулы wgpu, шейдер) + `tests/egui_painter.rs` 9, `tests/corner_mask.rs` 4 (каждый пиксель против полноэкранной формулы, 3 размера/масштаба), `tests/frame_composition.rs` 4, `tests/headless.rs` 8; общий стенд `tests/support/mod.rs`. Зелёные на 780M, llvmpipe и T410 (crocus ES 2.0).
- Паритет: `cargo test -p render-wgpu-shell --locked gles2_parity` — 4 кадра (окно egui с тенью, текст 3 размеров, иконки ui-artwork-egui, clip, частичная правка атласа, линейная своя текстура, кадр после free, повтор) × 2 (320×200@1, 301×187@1.5): max Δ 1, ~0,4 % пикселей отличаются; граница ±2 и ≤1 % различающихся (без дизеринга — 46 %, с неперевёрнутым Y — 50–68 %). Мерить на одном драйвере (RADV vs llvmpipe — Δ3 в тенях).
- Анти-вакуум проверен вручную: сломанный переворот scissor роняет clip-тест и паритет.

## Грабли
- radeonsi `mediump` = настоящий fp16: `length()` ≈ 11,5 ошибается на ~1/255 → маска в highp.
- Mesa отдаёт ОДИН `EGLDisplay` на платформу всем пользователям EGL процесса; `eglTerminate` одного (наш реестр или GL-бэкенд wgpu) гасит другого (wgpu-hal паникует на `make_current().unwrap()`), `EGL_KHR_display_reference` в Mesa нет. Поэтому GPU-тесты `render-wgpu-shell` берут `shell::gpu_context::vulkan_instance()` (только Vulkan, как production). Бэклог README: режим «не завершать display» для встраивания в чужие EGL-приложения.
- egui 0.36: панели — `egui::Panel::{top,bottom,left}(id).show(ui, ..)`, проход — `Context::run_ui`; `TexturesDelta` в debug паникует при drop непустой (шаблоны в тестах чистить).

## Замер (пример `examples/egui_window.rs --bench [--immediate] [--transparent]`)
- 780M и T410, Wayland и XWayland, прозрачное окно: с vsync ровно 60 к/с (T410 p95 интервала 16,9 мс). T410: полный проход = egui 0,44 мс + буферы 0,08 + рисование 0,05; повтор = рисование 0,05 мс (6 draw-call-ов, 0 байт); маска 0,012 мс. Без vsync интервал 1,7 мс у обоих (упор в swap/GPU). Плеер в режиме GLES2 появится только в 09, поэтому `run_pass.py` до/после в 04 неприменим.
