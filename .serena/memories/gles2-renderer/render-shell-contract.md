# Контракт «приложение ↔ рендер» `render-shell-api` (gles2-renderer сессия 01, 2026-10-24)

Отчёт: `user/gles2-renderer/results/01.md` (таблица «метод ↔ где в app-egui ↔ кто реализует»). Сессия 02 переводит на него `app-egui` и wgpu; эта память — для неё и для 09.

## Что это
- Crate `crates/render-shell-api`: `trait RenderShell` (object-safe, app держит `Box<dyn RenderShell>`) + `trait VideoFrameImport` (склад кадров рендера) + нейтральный словарь кадра и каталога. Зависит только от `egui` (типы мешей/текстур), `render-core`, `subtitle-raster`, `video-backend-api`, `video-core`, `video-frame-contract`, `video-present-core`. Guardrail: allowlist `RENDER_SHELL_API_ALLOWED_DEPENDENCIES` в `scripts/check-refactor-guardrails.py`; `render-shell-api` и будущие `render-gles2-shell`/`gles2-egui`/`gles2-video` запрещены контрактам, low-level, player-core, декодерам, media-source-open; GLES2-crate-ы запрещены и render-wgpu-*.
- Каталог рендеров (решение владельца 01) — модуль `app-egui::render_backend`, не crate; контракт даёт только `RendererFamily {WgpuVulkan, Gles2}` (`stable_id`, `backend_kind`), `RendererProbe`, `RendererUnusableReason`, `RequiredRendererFeature`, `RendererCreateError{stage,message}`. Поведение `Unsupported` в Auto не меняется (решение владельца 01).

## Ключевые инварианты (держатся типами)
- Билет `AcquiredSurfaceFrame` = паспорт `RendererInstanceId` + `Box<dyn Any>` с настоящим буфером рендера; открыть — `into_buffer::<T>(own_id)`; чужой → `RenderFrameFailure{kind: ForeignSurfaceFrame}`. Drop неиспользованного = drop буфера (wgpu discard). 1 аллокация на кадр.
- `RenderableFrameKey` = паспорт + ОДИН `Arc<dyn KeyContents>` с КЛОНОМ `VideoFrameLease` и ресурсами рендера (аренда внутри Arc, а не рядом: иначе `Ready` весил 392 байта — clippy large_enum_variant; ключ = 24 байта, 1 аллокация на кадр). Пока жив клон ключа — кадр не возвращается декодеру. Рендер НЕ хранит ключи после `render_frame` (иначе кадр не освободится — ловит conformance). Кэши импорта рендера — по идентичности буфера, не по ключам. Чужой ключ → `ForeignVideoFrame`.
- `materialize(&lease) -> FrameMaterialization{outcome, resource_pool_lock_wait}`; порядок: контракт не объявлен → `Unsupported(ContractNotDeclared)`; нет импорта → `NoVideoBackendBound`; затем provider: `Ready(key)`/`Busy`/`Missing`/`Error(ProviderFatal|ImportFailed)`; путь/раскладка не того импорта → `Unsupported(TransferPathNotHandledByActiveImport|LayoutNotHandledByActiveImport)`; `DmaBufDescriptorRejected(..)` для runtime-фолбэка на SW. Отчёт sample в аренду (ровно 1 раз) и Busy-фолбэк «прошлый кадр» остаются в app.
- Подключение декодера: `prepare_video_import(StartedVideoBackend, VideoImportPlan{path, DecoderSurfacePoolSlots})` → `PreparedVideoImport{backend (обёрнутый, для плеера), pending: PendingVideoImport (Send, drop = отмена)}` → `install_video_import(pending)` (чужой рендер → `PreparedByAnotherRenderer`). Пересоздание в семействе: `export_video_import_for_recreation()` → `prepare_recreated_video_import(handoff)` (чужое семейство → `HandoffFromAnotherFamily`) → `install_video_import` перепривязывает отложенные освобождения. `release_after_device_lost() -> ReleasedFrameCount` — ровно один раз, далее освобождения мгновенные.
- `RenderFrameFailure` получил `kind: RenderFrameFailureKind {VideoRender, ForeignSurfaceFrame, ForeignVideoFrame}`; `new(msg)` = `VideoRender` (старая семантика). `RendererGpuDrainError` нейтральный: `DeviceLost(RendererDeviceLost)`, `Timeout`, `WaitRejected`, `DeviceLostStatePoisoned`. `RenderHotPathStats { resource_bindings_created/reused, uniform_writes(_skipped) }`.

## Тесты и conformance
- `cargo test -p render-shell-api --locked` (26): fake-рендер `src/tests/fake_shell.rs` («GPU» = очередь отложенных освобождений, сбрасывается в `wait_for_gpu_idle`; привязка переживает пересоздание), fake-декодер `src/tests/fake_decoder.rs`.
- Conformance (`feature = "conformance"`, модуль `render_shell_api::conformance`): `RenderShellConformanceHarness {create_renderer, screen, unsupported_frame, supported_video_source}` + 6 проверок (`run_render_shell_conformance`): чужой билет; ReusePrevious без/с удержанным UI; Unsupported≠Error; NoVideoBackendBound; освобождение ровно 1 раз и не раньше отпускания аренды+ключа; device lost ровно 1 раз. Анти-вакуум: 6 fake-дефектов, каждый ловится своей проверкой (`RetainsKeys` — обеими проверками освобождения).
- Не ловится conformance: «не раньше, чем GPU дочитал» — у каждого рендера свой тест (wgpu udmabuf-тест, GLES2 — fence в сессии 07).
