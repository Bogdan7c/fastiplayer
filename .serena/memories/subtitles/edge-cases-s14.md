# Субтитры, сессия 14: edge cases (2026-10-19)

План/отчёт: `user/subtitles/14-edge-cases.md`, `user/subtitles/results/14.md`; бэклог найденного-но-не-исправленного — README плана, раздел «Найдено в сессии 14».

## Новые инварианты и границы
- **Форматы (subtitle-formats/core):** SRT/WebVTT — NUL удаляется после декодирования (`encoding::strip_nul_characters`); ASS обрезается по NUL как libass, но с `ParseIssueKind::TruncatedAtNul`. Разметка SRT/VTT линейна (однопроходный поиск `>`/`<`; флаг «`}` дальше нет»; в VTT стиль/голос/язык считаются при открытии элемента — `OpenElement.style_in_scope`). Дедуп `from_events`/`extend` — корзины хеша (`timeline/duplicates.rs`, инвариант: равные события => равный ключ). Тесты: `subtitle-formats/tests/{dirty_input_nul,huge_cue_markup}.rs`, `subtitle-core/src/timeline/bulk_duplicate_tests.rs`.
- **Перенос CJK (subtitle-raster):** `EventStyle.break_opportunities: BreakOpportunities {SpacesOnly (все ASS — побитово libass), SpacesAndCjk (to_event_style: SRT/VTT/srv3/TTML/mov_text/web)}`; правила `layout/break_rules.rs` (упрощённый UAX#14 ID + кинсоку + метки/ZWJ/nbsp/skip/bidi, без зависимостей); wrap.rs — «разрыв после кластера i», rebalance двигает CJK-границу по символу. Тесты `layout/{break_rules/tests.rs,cjk_wrap_tests.rs}`, `renderer/tests/cjk_wrap.rs`.
- **Прогрев шрифтов:** `SubtitleRasterizer::warm_up_fonts(sample, language) -> FontWarmUp` (`renderer/warm_up.rs`: только не встроенные лица, бюджет `shaper_faces/2`, кэши реплик/глифов/кадра не трогает). Поток: `WorkerCommand::WarmUpFonts`, `render_worker/font_warm_up.rs` `PendingFontWarmUp` (последний побеждает; сброс на Forget своей / Replace чужой дорожки / смену шрифтов), выполняется только в простое (картинки раньше). UI: `presentation/font_warm_up.rs` `FontWarmUpGate` (символы > U+024F из первых 32 реплик, ≤64; один раз на source).
- **Поток-рисовальщик (дополнение к `mem:subtitles/render-thread-s09`):** `reset_media` сначала `release_mirrored_tracks()` (у потока нет цели без зеркала — корень флейка language-теста); `PresentationStats.rasterizer_calls` = принятые UI картинки (всё нарисованное — `worker_diagnostics().raster`); шаг кадров не учится в seek/scrub и `ClockTracker::note_discontinuity()` при смене `read_run`; новая цель seek/scrub => `SubtitleRasterizer::forget_layout_history()` (память раздвигания ASS сброшена, результат в цели детерминирован — осознанное отличие от libass; уже подготовленные наперёд картинки остаются). Тестовый журнал команд `take_sent_command_log`/`SentCommandKind`.
- **Лента стрим-субтитров (`mem:subtitles/stream-feed-s13`):** сетевые сбои (`is_transient`) не помечают сегмент handled и не идут в серию: повтор 0,5→8 с (`feed/outage.rs`) в пределах `StreamSubtitleFeedConfig.outage_budget` = `network.reconnect_wait_ms` (заполняет `StreamLimits::from_config`, живая смена — `SubtitleOwner::apply_network_reconnect_wait`); исчерпание => один `TrackUnavailable`. Первый индекс тоже повторяется. Канал закрыт без штатного выхода => один `TrackUnavailable(WorkerLost)`. В фикстурах «постоянный» сбой — `NotFound`, не `Network`. Тесты `stream_subtitles/tests/feed_outage.rs`.
- **Файлы рядом/брошенные (app-egui):** формат по содержимому (`file_loader/format_detection.rs`, только SRT/VTT/ASS, расширение запасное); только обычный файл (`file_loader/regular_file.rs`, O_NONBLOCK + проверка дескриптора, иначе `ReadFailed{InvalidInput}`); файл без реплик => `SubtitleLoadFailure::NoCuesFound`; причина для UI — `SubtitleFileProblem {CannotOpen, TooLarge, CannotParse, Other}` (`menu_view.rs`), `SubtitleUnavailableReason::LoadFailed(SubtitleFileProblem)`; toast только для файлов пользователя (`user_file_failures.rs`, трекер `MediaSubtitles::user_files`, доставка `AppState::show_user_file_failures` из `poll_subtitle_jobs`, тексты `subtitle_message::file_failure_toast`). Тесты `tests/{content_format,special_files,file_failure_toasts}.rs`.
- **Старт контейнера:** `media_core::MediaContainerMetadata.presentation_start: Option<Duration>`; MPEG-TS публикует минимум PTS эпохи StreamStart по всем PID (`mpeg-ts-demux/src/presentation_start.rs`, только `RebasedByDemuxer`, не HLS) через `media_metadata()`; player-core не менялся. App: `container_start.rs` (`TimelineOrigin`, `ContainerStart`) + `owner_container_start.rs` `note_container_start` из `pump_embedded_subtitles`; только `TrackDescription::Sidecar` локального файла; `ActiveSubtitleTrack::lookup_time_for` = sync_offset(pts − origin); origin НЕ в `SubtitleSyncOffset`/память/toast. Позиция UI по-прежнему сырая. Тесты `mpeg-ts-demux/tests/presentation_start.rs`, `app-egui .../tests/container_start.rs`.
- **Масштаб экрана:** shell не вызывает `set_pixels_per_point` — масштаб ведёт egui-winit (`app_shell/scale_factor.rs`).
- Меню ♪ — `vertical_scroll_area` (счётчик в `egui_behavior` тесте = 9). Геометрия `from_submission` — `tests/submitted_frame_geometry.rs`.

## Известные нестабильности
GPU-тесты app-egui под `--test-threads=64` (stream_gpu live_history, stream_dash_gpu, stream_hls_vertical) и `startup_import` 2 с — падают и до сессии 14.
