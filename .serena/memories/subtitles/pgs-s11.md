# Субтитры, сессия 11 (2026-10-18): PGS внутри MKV

План/отчёт: `user/subtitles/11-pgs.md`, `user/subtitles/results/11.md`. Матрица: `docs/subtitles/compatibility.md` («PGS (session 11)»). Встроенные дорожки — `mem:subtitles/embedded-tracks-s06`; поток-рисовальщик — `mem:subtitles/render-thread-s09`; GPU-проход — `mem:subtitles/on-screen-s03`.

## Решения владельца
Полноцветная RGBA-картинка (второй атлас + шейдер в ТОМ ЖЕ проходе, не трафареты по цветам); пользовательский масштаб НЕ применяется, только подъём над панелью + вертикальный сдвиг пользователя для нижних картинок (Main), внутри картинки видео; forced «как Blu-ray»; память — отдельный механизм (показываемая дорожка: бюджет 32 МБ, остальные PGS: последние 60 с, оба в конфиге); граница «укоротить конец реплики» в subtitle-core + номер прохода чтения в player-core (обе одобрены). Чистая комната: код FFmpeg/BDSup2Sub не открывался; источники — блог thescorpius (2017), спецификация Matroska `S_HDMV/PGS`, патент US20090185789A1.

## Нейтральные crate-ы
- `subtitle-core/src/picture.rs`: `SubtitleContent::Picture(SubtitlePictureCue{reference_size, origin, visible_region, Arc<IndexedPicture>(PictureEncoding::HdmvRle), Arc<PicturePalette>, PictureForcedFlag})`. Шкала: `SubtitleTimeline::shorten_event_end(id, new_end) -> ShortenOutcome|ShortenError` (только укорочение, id стабильны, `MaxEndTree::set_end`), `revision()`, журнал `shortenings_since(rev)` (1024, иначе `ShorteningHistoryLost`). Дедупликация сравнивает и `end` — повторно прочитанную композицию фильтрует приложение.
- `crates/subtitle-pgs` (deps subtitle-core, thiserror; guardrail `SUBTITLE_PGS_ALLOWED_DEPENDENCIES`, machete-список в `scripts/ci-checks.sh`): `split_block` (MKV-блок = голые сегменты; ffmpeg кладёт один набор в блок, без BlockDuration; терпит префикс `PG`+PTS+DTS 10 байт), `parse_pcs/wds/pds/ods`, `color` (BT.601 при высоте автора ≤ 576, иначе BT.709, limited range), `rle`, `decode_picture_rgba` (premultiplied, лимит пикселей от вызывающего), `PgsTrackDecoder` (эпохи; несобираемая композиция => «очистка», а не залипание), `PgsCompositionStore` (`insert -> StoreChange::{Duplicate, AppendedAtTail(TailAppend{composition, events, predecessor_closed}), RequiresRebuild}`, `note_discontinuity` роняет ОТКРЫТУЮ композицию, `enforce_retention(PgsRetention::{Shown{budget_bytes}, Background{trailing_window}})`, `events_by_composition`, `OPEN_END`). Тестовый кодировщик `stream_builder` — только за фичей `test-support` (пример `write_test_sup` требует её).
- `subtitle-raster`: `CueContent::Picture`, `RenderableCue::picture`; `picture/` — `PictureFit` (ОДИН масштаб min(cw/rw, ch/rh) + центрирование, как mpv: рипы со срезанными полосами не сплющиваются), края round-half-up в целых, box-scale в premultiplied; группа: верх картинки на/ниже половины кадра автора => Main, иначе Fixed. Контракт `overlay/picture.rs`: `BitmapPixelFormat::{Coverage, PremultipliedRgba}`, `SubtitleBitmapKind::Picture`, `rgba_pixels()`, `stride()` в байтах, цвет = множитель `color.a`; для RGBA `coverage()` пусто. Кэш картинок — общий `cue_bitmaps_bytes`.
- `render-wgpu-shell/src/subtitle_overlay/`: `layer.rs` (`BitmapLayer`: атлас+пайплайн+буфер; Coverage R8 / Picture Rgba8Unorm не sRGB, создаётся лениво), `runs.rs` (порядок списка, один draw на серию одного вида), `fs_picture` = texel*color.a. Для GLES2: RGBA8 + тот же blend ONE/ONE_MINUS_SRC_ALPHA. Слишком большая маска теперь пропускается одна (раньше весь overlay).

## player-core
`SubtitleReadRun` на каждом `SubtitleFeedPacket` (`subtitle_feed/read_run.rs`, счётчик в `SubtitleFeedSender`, сквозной по media); растёт в `subtitle_feed_bridge::seek_demuxer_noting_read_jump` (seek_start, scrub_driver) и на квитанции worker-seek (`prepared_demux_seek.rs`). `next()` pub (тесты приложения). Номер МОНОТОННЫЙ: потребитель сравнивает порядково (больше известного = разрыв для ВСЕХ PGS-дорожек media, меньше = хвост трубы до seek, пакет отбрасывается и считается `stale_run_packets`). Текущий номер в `PlayerSnapshot::subtitle_read_run` (источник `SubtitleFeedSender::current_read_run`); app: `PlaybackObservation.read_run` -> `SubtitleOwner::observe_pgs_read_run` -> `EmbeddedPgsTracks::observe_read_run/admit_packet_read_run` (первый увиденный номер = точка отсчёта) — сброс без ожидания пакетов. Переполнение трубы (`DroppedFull`) двигает проход: потеря пакета = дыра. Формат: PCS > 4096x2304 (`MAX_REFERENCE_WIDTH/HEIGHT` в `pcs.rs`) отвергается (`oversized_reference_frames`), объект больше кадра — `objects_larger_than_reference_frame`; хвост PDS не кратный 5 байтам терпится (`palettes_with_partial_trailing_entry`). Store: вытеснение по бюджету сортирует кандидатов один раз и фиксирует конец открытого предшественника (`remove_without_stretching_predecessor`).

## app-egui
- `embedded_track.rs` `EmbeddedPacketPath::{Text(fmt), Pgs}`; `owner_embedded/{pgs_owner,pgs_tracks}.rs` (+ `pgs_tracks/forced_view.rs`); `limits/pgs.rs`; `presentation/retention_anchor.rs`. Пакет -> смена read_run => reset декодера + note_discontinuity -> store.insert -> пачка -> `settle_pgs_track`: retention, затем ОДИН перенос (append + shorten по карте композиция->id) или пересборка с новым `CueSourceId`. «Сейчас» для памяти = `PlaybackObservation.position` (+сдвиг), не кадр субтитров (при выкл. субтитрах кадров нет). Гистерезис бюджета 1/8.
- Зеркало потока: `TrackCommand::Update{shortenings, appended}`, `ValidityInterval::after_shortening` (Narrowed — картинка до нового конца остаётся, без мигания), применяется в PreparedQueue/PublishedRecord/ingest; журнал потерян => Replace.
- Размещение: `LayerPlacementPolicy::MainGroupUserOffsetInsidePicture` (`layer_placement/picture_group.rs`); сигнал — overlay содержит `SubtitleBitmapKind::Picture` (`owner_placement/picture_positioning.rs`); ASS-правило раньше.
- Forced: `DisplayChoice{track_id, mode: DisplayMode::{AllCues, ForcedPicturesOnly}}`, `displayed_track()`; `AutoSelection.forced_objects_fallback` (только PGS, только без forced-дорожки); у дорожки вторая шкала `ForcedPicturesView` со своим `CueSourceId`. CC при этом «выкл».
- Конфиг v22: `pgs_displayed_track_cache_mb` (32, 1..=1024), `pgs_background_track_window_s` (60, 0..=3600); константы `config/src/schema/subtitles_pgs.rs`; `schema/subtitles.rs` = 780 строк (следующее поле — выносить).
