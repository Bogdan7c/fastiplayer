# Субтитры, сессия 04 (2026-10-15): выбор дорожек, автовыбор, конфиг v13 — точка входа

План/отчёт: `user/subtitles/04-cc-button-and-controls.md`, `user/subtitles/results/04.md`. UI (CC, меню, хоткеи, toast) — `mem:subtitles/ui-s04-part3`; бросок файлов — `mem:subtitles/ui-s04-part4`. Цепочка на экране — `mem:subtitles/on-screen-s03`.

## Решения владельца
По умолчанию субтитры ВЫКЛ (`subtitles.enabled=false`), включение запоминается (C/CC/бросок файла). Если вкл: первая дорожка языка из `preferred_languages` (пусто = язык системы), иначе первая имеющаяся; forced показываются всегда (и при выкл). Узкое окно: Full ≥ 498 pt, Compact (правый клик = меню) 470–497, Hidden < 470. Видео без дорожек — CC нет, подключение только броском. Пустой плеер + бросок → "Open a video first, then add subtitles.". Видео+.srt вместе → прицепить к этому видео.

## Владельцы и границы
- Дорожки из файлов принадлежат `SubtitleOwner` (app-egui `state/subtitles/`): `track_list` (id = `subtitle_core::SubtitleTrackId`, стабилен в пределах media), ленивое чтение только выбранной (+forced), `auto_select.rs` (чистая функция, канонические языки `rus`=`ru`), `sync_offset.rs` (шаг 100 мс, предел ±600 с, сброс при смене media), `menu_view.rs` (`SubtitleMenuView` для UI), `control_actions.rs` (вся логика C/V/Z/X/меню → `ControlActionFeedback`). Смена выбора/сдвига/видимости/стиля → ровно одна перерастеризация.
- `player-core` про файлы не знает: `SelectSubtitleTrack(Some(id))` валидирует id по дорожкам установленного media (`session/subtitle_selection.rs`), неизвестный → `PlayerErrorKind::InvalidCommand` через recoverable error, снимок/событие не меняются; restore неизвестного id пропускается (debug-лог), установка не падает. С сессии 06 `TrackKind::Subtitle` есть, встроенные дорожки принимаются (`mem:subtitles/embedded-tracks-s06`); выбор встроенных дорожек при этом тоже принадлежит `SubtitleOwner` (в player-core не пересылается).
- `subtitle-sidecar::describe_subtitle_file` / `is_subtitle_file_extension`, `SidecarLocation::ChosenByUser` (подпись "added"). Язык выбранного файла — из хвоста имени через `. _ пробел [ ] ( )` (первый токен = название), ТОЛЬКО из таблицы известных языков (`english_display_name().is_some()`), иначе `The_Big_Lie` дал бы «lie». Подпись без языка = имя файла (не "Track N"; "Track N" — только у дорожки без файла).
- `subtitle-core::language_table` (42 языка: 639-1, 639-2/B,T, англ. имя).

## Конфиг v13 `[subtitles]`
`fastiplayer_config::SubtitlesConfig`: enabled, preferred_languages (+`preferred_language_codes()`), decoration box/outline, text_size_percent, text_color/background_color `#RRGGBB` (фон по умолчанию `#080808` = `youtube_like()`), background_opacity_percent (75), лимиты (max_file_size_mb, max_cues_per_file, sidecar_max_entries_per_folder, sidecar_max_candidates, render_cache_mb, font_lookup_cache_chars, max_chars_per_cue, max_cues_on_screen). В `state/subtitles/limits.rs` константами остались только внутренние инварианты (64 issues, глубина 2, 16 shaper faces, canvas 8192, бюджет 8 мс). Маршрут `subtitles.apply` — no-op в `route_apply.rs` сознательно: применение в `AppState::sync_committed_config_snapshot` → `SubtitleOwner::apply_config` (после успешной транзакции, чтобы откат не оставлял стиль): стиль сразу, лимиты со следующей загрузки, enabled/языки со следующего media.

## Приёмка вживую (как гонять)
Изолировать конфиг: `XDG_CONFIG_HOME=<scratch>/cfg` (+STATE/DATA/CACHE) — иначе приложение мигрирует реальный config владельца. Плеер продолжает прошлое видео (resume), для «пустого плеера» — свежий XDG_CONFIG_HOME с одним config.toml. Ввод: uinput-клавиатура + абсолютный uinput-указатель (EV_ABS 0..1919/0..1079 + BTN_LEFT/RIGHT, libinput считает его absolute pointer), drag & drop — окно PySide6 с `QDrag` file:// URL, KWin-скрипт `workspace.windowList()` для позиции окон, скриншоты `spectacle -b -n -f`. Раскладка системы русская: текст вводить через `wl-copy` + Ctrl+V. `pkill -f drag_source` убивает и собственный shell — использовать шаблон `'^python3 -I .*drag_source'`.
