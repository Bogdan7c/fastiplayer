# Субтитры, сессия 12c: web-дорожки (YouTube) в SubtitleOwner и меню CC

Связано: `mem:subtitles/core` (srv3, reveal), `mem:subtitles/controls-s04`, `mem:subtitles/audio-tracks-memory-s07`, `mem:app-egui/notifications`. Решения владельца: `user/subtitles/results/12.md`.

## Границы
- `media-source-open::web_subtitle_fetch` (12a) отдаёт `WebSubtitleFetchHandle` + безопасные `WebSubtitleTrack`. SubtitleOwner зависит НЕ от него, а от трейта `WebSubtitleDownloader` (`state/subtitles/web_download.rs`: `download(&WebSubtitleTrackId, max_bytes: NonZeroUsize, &CancellationToken) -> Result<DownloadedWebSubtitle{bytes,format}, WebSubtitleFetchError>`); адаптер `impl for WebSubtitleFetchHandle` там же. Тесты подставляют `FakeWebDownloader` (`tests/web_support.rs`).
- `web_track.rs`: `WebTrackInfo{id,display_name}`, `WebSubtitleSource{tracks, downloader}` (`from_intent(&WebMediaSourceIntent)`, пусто -> None -> NotLocal), `WebTrackDescription` (порядок меню: ручные, ASR, автопереводы; внутри — предпочитаемые языки по порядку, затем по алфавиту имени). `SubtitleMediaSource::Web(WebSubtitleSource)`; `TrackDescription::Web`.
- Задача загрузки: `SidecarJobTask::LoadWebTrack{track, downloader, cancellation: CancellationToken}` -> `web_load_job.rs::run_web_track_load` (скачать -> `parse_text_timeline` Srv3/WebVtt Generic -> шрифты) -> `SidecarJobOutcome::WebTrackLoaded`. `SidecarJob::cancel/Drop` переворачивают и токен (`network_cancellation`). Лимит байт = `subtitles.max_file_size_mb`.
- Сбой: `SubtitleLoadFailure::DownloadFailed(WebSubtitleFetchError)` = ВРЕМЕННЫЙ (`is_retryable_download`): дорожка остаётся выбираемой (`TrackEntry::is_selectable/availability`), повтор ТОЛЬКО через `select_track` (`prepare_retry_after_failed_download`), автоповторов нет. Парсинг-ошибки постоянные. Уведомления: `SubtitleOwner::take_download_failures()` (по одному на попытку; отменённые/устаревшие не попадают) -> `app_state_api::deliver_download_failures` -> `TransientReplaceKey::SubtitleDownload`; тексты — `subtitle_message::subtitle_download_failure_message`.
- Автовыбор: `TrackOrigin::{WebManual, WebAutoGenerated}` (ручная важнее ASR); автоперевод `is_renderable=false` для автовыбора — НИКОГДА автоматически. Клавиша V: `takes_part_in_track_cycling` пропускает автопереводы.
- Меню: `SubtitleFileOrigin::Web(SubtitleKind)`, `SubtitleTrackLabel.fallback_name`, `is_auto_translation()`; подписи `English` / `English (auto)` / `Russian (auto, translated)` (`subtitle_message::web_track_text`). UI: `subtitle_control/menu.rs` (основной список в ScrollArea) + `translation_menu.rs` (`SubMenuButton` «Auto-translate ⏵», `CloseOnClickOutside`, клик по строке закрывает всё меню). Прокрутка — только через `vertical_scroll_area()` (тест-сканер ждёт 8 вхождений).
- Память: `playlist-state` `RememberedSubtitleChoice::Web(RememberedWebSubtitle{language, kind})`; схема `track-memory.json` поднята до 2 (читаем 1 и 2; v1-файл с `web` отвергается). Старый бинарник (схема 1) видит «файл новее» -> не трогает файл, работает с пустой памятью (иначе счёл бы весь файл повреждённым и унёс в карантин). Восстановление: `PendingRememberedChoice::Web` решается синхронно в `begin_media_restoring` (`find_web_track`), не меняет глобальное «включено».

## Подписи двойников (follow-up)
Одинаковое название языка (`zh-CN`/`zh-TW`, `pt-BR`/`pt-PT`) различает чистый модуль `state/language_label_disambiguation.rs` (`distinguish_language_names`): без двойника — короткое имя, с двойниками — подробное имя yt-dlp (если начинается с базового и длиннее), иначе «Имя (тег)». Меню субтитров: `ordered_for_menu` -> `WebTrackDescription.distinguishing_name` -> `SubtitleTrackLabel.distinguishing_name` (приоритетнее таблицы в `web_track_text`); группы по виду. Меню «♪» использует ту же функцию (`web_audio_languages`). Тесты: `tests/web_labels.rs`.

## Известно
Сбой разбора (ParseFailed) web-дорожки не даёт toast (серая строка в меню); отменённая загрузка возвращает дорожку в NotLoaded.
