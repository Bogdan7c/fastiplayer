## player-core: настоящее переключение звука
- `SelectAudioTrack(id)` → `session/audio_track_switch.rs` `switch_selected_audio_track -> AudioTrackSwitchOutcome{AlreadySelected, Switched(AudioTrackSwitchResume{SeekToCurrentPosition, ContinueForwardWithoutSeek, JoinInFlightSeek})}`. Не аудио / неизвестный id / нет media → `InvalidCommand` (recoverable), ничего не меняется; тот же id → no-op без события. Сброс — `PlaybackPipeline::replace_selected_audio_track` (`pipeline/audio_track_switch.rs`: decoder, output+clock, pending packets, passthrough; новый deferred config по метаданным дорожки). Позиция — внутренний `seek(SeekRequest::accurate(current))` (как после backend swap), виден короткий `Seeking`/`SeekRequested`. Non-seekable → без seek, якорь clock.
- Попутный фикс: `SeekRuntimeState::in_flight_seek_resume_intent()` (SeekLanding или intent активного commit) в `seek_start.rs::seek` — второй seek поверх audio-only seek больше не превращает Paused в Playing.
- Restore при установке (`InstalledTrackRestore::Select`) идёт тем же путём (для не-default дорожки два seek-а: переключения и позиции — корректно, избыточно).

## playlist-state `track_memory/`
`TrackMemoryStore` (`inspect(capacity) -> TrackMemoryInspection{Missing, Loaded, CorruptNeedsQuarantine, NewerSchemaSaveBlocked, ProtectedSaveBlocked}`, `allows_saving_immediately()`, `apply_quarantine`, `write`; нечитаемый мусор → `CorruptNeedsQuarantine(UnreadableEnvelope)`, файл больше лимита → protected), `TrackMemory` (LRU по монотонному `last_used`; `remember_audio/subtitles/sync_offset`, `touch`, `set_capacity`; тот же value → `Unchanged` без обновления recency), `TrackMemoryWriter` (latest-only поток, копия паттерна resume worker-а), `VideoKey::for_locator(_segment)` (SHA-256, домен `fastiplayer/track-memory/locator/v1`, сегмент = окно CUE/compound), `RememberedSubtitleChoice{Off, Embedded(hint), File(path)}`, `RememberedTrackHint{language, title, codec_id, ordinal_among_kind}` + `find_matching_track -> TrackHintMatch{Exact, Approximate, NotFound}` (точно → язык+название+кодек (ближайший ordinal) → язык+кодек; без языка — только точно; другой язык никогда). Общий кодер отпечатка `locator_fingerprint.rs` (resume байт-в-байт тот же, golden-тест). Схема v1, лимит файла 16 МиБ.
Конфиг v16: `playlist.track_memory_max_entries` (1000, 10..=10000, live через `sync_committed_config_snapshot`), `ConfigPaths::track_memory_file()`.

## Ограничения и находки вне объёма
Одно web-видео через разные виды ссылок — разные ключи. Найдено на приёмке (есть и в базовом коммите, не регрессия): MKV, собранный ffmpeg из видео Sintel (и фикстура `two-audio-tracks.mkv` в GUI), с декодируемым звуком застревает в Buffering на 00:00 — «Audio stream started» не наступает; эталон `test-assets/H264/720p_high_bframes_aac.mkv` с FLAC/Opus играет. AAC, закодированный свежим ffmpeg в MKV, — UnsupportedAudioCodec (эталонный AAC-in-MKV работает). Обе причины найдены и исправлены 2026-10-16 отдельными коммитами: (1) взаимная блокировка audio read-ahead ↔ DPB видео на старте — `mem:player-core/autoplay-preroll` (config v17 `audio.startup_read_ahead_cap_ms`); (2) AAC 5.1 через PCE (`channel_config=0`) — `mem:dependency-patches/core`. Зависание фикстуры VP8 64x64@10fps — ещё две причины, тоже исправлены (короткий файл дочитан раньше первого кадра; окно decode-ahead при низком fps), см. `mem:player-core/autoplay-preroll`.
