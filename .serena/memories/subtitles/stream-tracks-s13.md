# Дорожки потока (HLS-рендиции) в приложении (сессия 13, пакет P5, L4)

Лента и транспорт — `mem:subtitles/stream-feed-s13` (L3); web-дорожки YouTube — `mem:subtitles/web-tracks-s12`; встроенные — `mem:subtitles/embedded-tracks-s06`.

## Модули `app-egui/src/state/subtitles/`
- `stream_track.rs`: `StreamTrackDescription` (язык, название, forced/default/autoselect; `label()`, `to_remembered()`, `matches_remembered()`), `subtitle_source_of_web_intent(intent) -> SubtitleMediaSource` (web + stream → `Web | Stream | WebAndStream{web,stream} | NotLocal`; `subtitle_source_of` в `state/subtitles.rs` остался тонким).
- `stream_position.rs`: `StreamPlaybackObservation::from_snapshot` (позиция = цель seek/scrub, иначе текущая; `StreamTimelineKind::{Vod,Live}` по `TimelineMode`), `StreamPositionTracker` → `PositionUpdate::{Unchanged,Advance,Jump}` (прыжок: новая цель seek, завершение seek, назад, вперёд >10 с).
- `owner_stream.rs`: `StreamTracks` (в `MediaSubtitles.streams`: источник, свой wake-порт, ячейка позиции, работающая лента, `unavailable`, уведомления, счётчики) и методы владельца: `install_remote_sources` (web+stream в список, решает поиск запомненного файла), `sync_stream_feed` (лента = показываемая дорожка потока при `DisplayMode::AllCues`; вызывается из `ensure_display_track_loading` и в начале drain), `observe_stream_playback` (каждый кадр UI), `drain_stream_feed` / `poll_stream_feed` (при wake: сначала `clear_pending_for_drain` СВОЕГО порта), `evict_stream_history`, `take_stream_notices`.
- `limits/stream.rs`: `StreamLimits{feed: StreamSubtitleFeedConfig, live_retention}` из `[subtitles.stream]`; `message_capacity` = константа 64.
- Вне модуля: `TrackDescription::Stream`, `SubtitleFileOrigin::Stream` (подпись `English (stream)`, `Russian — forced (stream)`, название рендиции в кавычках, только если оно не равно названию языка; без языка название — основное имя), `TrackOrigin::Stream` (после Embedded), `ActiveSubtitleTrack::{count_ended_before, rebuild_without_ended_before}`, `PendingRememberedChoice::Stream`, `StreamSubtitleNotice::TrackUnavailable`, `AppWakePort::with_independent_edge` (отдельный wake-флаг на том же канале событий).

## Решения и инварианты
- Дорожка потока создаётся `Ready` с пустым таймлайном (как встроенная); лента запускается ТОЛЬКО для показываемой дорожки (выбранная при Shown либо forced-fallback при Hidden), отменяется при снятии/смене дорожки, выключении, смене media, `clear_media`. Лента принадлежит `MediaSubtitles` → сообщения старого media прийти не могут (очередь умирает с лентой).
- Автовыбор: `is_default = DEFAULT`, `is_renderable` только если `AUTOSELECT || DEFAULT` (AUTOSELECT=NO — лишь ручной выбор), forced как у встроенных (`forced_fallback` по предпочитаемому языку).
- В ячейку позиции ленты пишется ВРЕМЯ ПОИСКА (позиция плеера − сдвиг, не меньше 0; реплики на шкале плеера, кадр ищет по времени поиска); смена сдвига (Z/X, сброс, память) или seek — `jump_to`. История live (`evict_stream_history`) считается от позиции поиска (с учётом сдвига).
- Вытеснение: только `TimelineMode::Live` и только показываемая дорожка; пересборка (`restart_with_source` + `extend`) под новым `CueSourceId`, когда закончившихся реплик ≥16 и не меньше оставшихся (память ≤ 2× истории); проверка по ходу — не чаще раз в 5 с позиции; после приёма пачки — сразу. У потолка `max_cues_per_track` на live `make_room_on_live_track` (вызывается из `append_stream_events`) без гистерезиса вытесняет все реплики, закончившиеся раньше времени поиска (пересборка), и только потом дописывает; живые/будущие не трогаются, остаток сверх потолка отбрасывается и считается в `cues_over_capacity`. У VOD вытеснения нет (лента не присылает обработанные сегменты повторно), потолок — `embedded_limits.max_cues_per_track`.
- Сбой: `SegmentSkipped` → только tracing (без адреса); `TrackUnavailable` (один раз за ленту) → дорожка в `unavailable`, лента сброшена, ОДНО уведомление `STREAM_SUBTITLES_UNAVAILABLE_MESSAGE` ("Subtitles for this stream are unavailable right now.") через собственный ключ `TransientReplaceKey::StreamSubtitles` (не вытесняет toast сбоя web-скачивания `SubtitleDownload` и наоборот); дорожка остаётся выбираемой, повторный выбор (`select_track` → `StreamTracks::note_user_selected`) запускает новую ленту; автоповторов нет. Ошибка запуска потока ленты трактуется так же.
- Wake: лента будит UI через `with_independent_edge()` порта Subtitles; общий флаг порта очищают чужие drain-ы (задачи/рисовальщик), из-за чего пробуждение ленты могло теряться на паузе. Пампы: `pump_embedded_subtitles` и `subtitle_overlay_for_submitted_frame` тоже зовут `drain_stream_feed`.
- Память: `RememberedSubtitleChoice::Stream(RememberedStreamSubtitle{language: Option, name, forced})`, `track-memory.json` схема 3 (читаем 1..3; файл v<3 со `stream` отвергается как повреждённый; файл схемы 4+ — «новее», не трогаем), восстановление — точное совпадение язык+название+forced (`find_stream_track`), нет совпадения → автовыбор.
- Конфиг v23: вложенная таблица `[subtitles.stream]` (`config/src/schema/subtitles_stream.rs`, `validation/subtitles_stream.rs`; ids `subtitles.stream.{ahead_s 60, behind_s 30, max_segment_kb 1024, max_pending_segments 8, failure_threshold 3, live_retention_s 600}`; retention ≥ behind), `subtitles.apply`, золотой `tests/fixtures/current_schema_v23.toml`; миграция v22→v23 только поднимает версию. Лимиты лежат в таблице, потому что `schema/subtitles.rs` уже 787 строк.

## Тесты
`tests/stream_support.rs` (подставной `FakeStreamTransport`: калитка, сбой, счётчики, отмена), `stream_tracks.rs` (меню, автовыбор, жизненный цикл ленты, сбои/повтор, seek-окно), `stream_live_memory.rs` (история live, VOD, применение конфига, память), `stream_gpu.rs` (пиксели: нет до сегмента/есть/нет после, повтор после сбоя, пересборка live), `stream_hls_vertical.rs` (настоящий loopback HLS из `media_open/web/tests/stream_subtitles_vertical.rs` → `prepare_native` → intent → владелец → GPU; реплика ровно на времени плеера, не на LOCAL и не на сыром времени TS). playlist-state: `track_memory/tests/stream_choice.rs`. config: `store/tests/subtitles_stream_settings.rs`. Проверки: `cargo test -p app-egui -p fastiplayer-config -p playlist-state -p media-source-open -p fastiplayer-settings --locked`, clippy `-D warnings` all-targets, `cargo test -p app-egui --no-default-features --locked --no-run`, guardrails.
Не покрыто E2E: часы настоящего плеера (воркер/декодер) — владельцу сообщаются позиции, время первого пакета берётся из настоящего демуксера того же открытия.
