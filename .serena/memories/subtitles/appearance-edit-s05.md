# Субтитры, сессия 05 (2026-10-15): стиль пользователя, режим правки на видео, размещение слоя

План/отчёт: `user/subtitles/05-style-edit-mode.md`, `user/subtitles/results/05.md`. Цепочка на экране — `mem:subtitles/on-screen-s03`; кнопка CC/конфиг v13 — `mem:subtitles/controls-s04`.

## Решения владельца
Правка вживую (пауза и воспроизведение, вход НЕ ставит паузу). В рамке настоящая реплика, иначе образец "This is how subtitles will look". Подъём над панелью — только если мешает (зазор 8 pt). Положение в любую сторону, по горизонтали не выходит за картинку, вниз может на полосу. ASS: флажок `ass_force_user_style` в конфиге уже есть, действует с сессии 08 (правило решения 11 перенесено в `08-ass-layer-1.md`). Done/неявный выход (закрытие media, повторное открытие настроек, выход из приложения) = сохранить; Esc/Cancel = вернуть как было.

## Владельцы и границы
- Конфиг v14 `[subtitles]`: `position_horizontal_percent` (0..100, 50 = центр), `position_vertical_percent` (−40..95; 6 = пресетный `bottom_margin` 0.06 → нулевой сдвиг, тест связывает числа), `ass_force_user_style`.
- `UserSubtitleStyle` (`app-egui state/subtitles/user_style.rs`) — единственный источник стиля: `from_config`, `to_appearance()` (позиция НЕ входит в растеризацию), `vertical/horizontal_offset_fraction`, `commit_requests()`. Хранится в `SubtitleSettings.style`.
- Размещение: весь слой двигается на GPU. `subtitle-raster` `SubtitleOverlay::content_bounds() -> Option<CanvasRect>`; `render-wgpu-shell` `SubtitleOverlayFrame.layer_offset: SubtitleLayerOffset` (только uniform, атлас не грузится; контракт GLES2: угол = round(picture + offset), scissor = видео-viewport, полосы рисуемы). Чистая `state/subtitles/layer_placement.rs::place_layer` (целые px: сдвиг из долей → clamp в картинку по X / в viewport по Y → подъём над `BottomControlsObstruction` → верх viewport важнее). Препятствие кормит `ui_runtime` из `EdgeSlideOutput.visible_rect` нижней панели (`controls_obstruction.rs`, `CONTROLS_CLEARANCE_POINTS`). На паузе кадр пересабмитится (`ReusedPreviousFrame`), поэтому подъём анимируется без перерастеризации.
- Сессия правки: `SubtitleOwner` + `owner_appearance_edit.rs` (`begin_appearance_edit`, `apply_appearance_edit(AppearanceEdit::{MoveBy, ScaleTextBy, Set*})`, `reset_appearance_draft` (флажок ASS сохраняется), `finish_appearance_edit(Save|Cancel)`, `appearance_edit_view`). Черновик живой: позиция — только сдвиг, размер/цвет — одна перерастеризация. `precise` хранит дробные доли (мелкие шаги мыши не теряются). Образец — `sample_cue.rs` (`CueSourceId` = u64::MAX); шрифты для образца без дорожки — `owner_fonts_bootstrap.rs` (`SidecarJobTask::BuildFontsOnly`). Gate в режиме: media id + render generation, дорожка не нужна; настоящая реплика приоритетнее.
- Сохранение: outbox владельца → `frame_prepare.rs` → `SettingsRuntime::commit_subtitle_style` → `settings-core` `SettingsController::commit_runtime_settings` (батч в ОДНОЙ транзакции, `RuntimeCommitOutcome::{NothingRequested, Transaction}`; одиночный `commit_runtime_setting` делегирует туда). `replace_appearance` идемпотентен → подтверждающий `apply_config` не перерастеризует. Сбой → toast "Could not save subtitle style." и сохранённый стиль. Коммит конфига во время сессии обновляет `before`, черновик не трогает. Выход/suspend — `app_shell/runtime_settings_flush.rs`.
- UI: вход — `settings_ui/section_extras.rs` (кнопка во вкладке subtitles, `SettingsUiAction::EditSubtitleAppearanceOnVideo`, неактивна без видео / с грязным draft). `ui/video_area_input.rs` `VideoAreaMode::{Playback, SubtitleAppearanceEdit}` — в режиме `video_surface_input` не вызывается (нет фуллскрина по двойному клику и громкости колесом). `ui/subtitle_appearance_edit/` (surface: Area Order::Middle, drag рамки = MoveBy, угол = отношение расстояний до центра, колесо 1.1^(scroll/40); panel сверху по центру видео; виджеты сдают фокус, чтобы Esc дошёл до shell). Рамка/хэндлы — `ui-artwork-egui/src/subtitle_edit_frame.rs`. `EscapeTarget::SubtitleAppearanceEdit` сразу после popup; `ChromeHoldReason::SubtitleAppearanceEdit`.

## Захват рамки (дефект приёмки, решение владельца «рамка всегда за мышью»)
`surface.rs` на `drag_started` шлёт `SubtitleAppearanceEditAction::StartMove` → `SubtitleOwner::start_appearance_layer_move()`: позиция черновика = ВИДИМОЕ место (`last_placed_layer_offset` / картинка → `position_percent_for_offset_fractions`). Без этого сохранённая позиция под панелью/за краем «съедала» начало переноса. Цена: «на полосе под панелью» ставится одним переносом + Done; повторный захват при видимой панели возвращает слой над панелью.

## Известные ограничения
Слой двигается целиком (авторски размещённая VTT-реплика тоже). Угол при ресайзе не остаётся точно под курсором (рост от нижней опоры).
