# Субтитры страницы браузера в плеере (мост, сессия 13b1, 2026-11-09, решения 270–274)

План: `user/browser-bridge/13b1-page-subtitles-player.md`, отчёт `results/13b1.md`. Экстеншен-часть — 13b2.

## Протокол 1.5 (`browser-bridge-protocol`)
- `PageSessionMessage::SubtitleTrackOffered { track: PageSubtitleTrackId(u32≥1), language: PageSubtitleLanguage{Unknown{}|Known{tag: SubtitleLanguageTag}}, label: PageSubtitleLabel{None{}|Text{text}}, format_hint: SubtitleFormatHint{WebVtt,Srt,Ttml,Srv3,Json3,Unknown}, origin: PageSubtitleOrigin{PageDownload,TrackElement,TextTrackCues}, page_display: PageSubtitleDisplay{Showing,NotShowing}, byte_length: PageSubtitleByteLength(1..=8 МиБ) }` — `session/page_subtitles.rs`, scope Unbound (вне поколений). Необязательные значения — помеченные объекты, а не отсутствие поля (конвенция протокола).
- Рамка вида 3 `DataFrameHeader::PageSubtitleBytes{track, offset}`; `DataFrameHeader::introduced_in()`. Сторож `stream_gate/page_subtitles.rs` (`admit_page_subtitle_bytes`): ≤ 64 дорожек (`MAX_PAGE_SUBTITLE_TRACKS`), куски подряд с 0, не больше byte_length, готов = ровно byte_length (без «finished»), повтор `track` заменяет, пока страница «ушла» (1.4) — `PageIsAway`. Фикстуры: manifest + отдельный `fixtures/page-subtitle-gate.json` (последовательности сторожа). `MAX_PAGE_SUBTITLE_SESSION_BYTES` = 32 МиБ — бюджет плеера (держит сборщик), экстеншен обязан уважать.
- TS: `extensions/browser/src/protocol/session/page-subtitles.ts`, `page-subtitle-sender.ts` (`splitPageSubtitleDocument` — заголовок + куски-подмассивы ≤ 1 МиБ без копий).
- Сервер `browser-bridge-session`: `ChunkSource::PageSubtitle(PageSubtitleChunk)`; app-egui: `SessionInput::PageSubtitleBytes(SessionRef, OwnedPageSubtitleChunk)` (`stream_queue.rs`).

## json3 (`subtitle-formats/src/json3/`)
Читатель JSON (`serde_json`, в allowlist guardrail) → существующая сырая модель srv3 `RawDocument` → общий конвейер srv3 (`srv3::build_parsed_document`). Пера/стили/позиции — массивы, индекс = id; `rcRows`/`ccCols` в `wpWinPositions`; события с `id` без `segs` = окна `<w>`. Вложенность > 16 → `Json3TooComplex`. Проверено на настоящем YouTube: json3 и srv3 одного ролика дают одинаковые события (315/315 ручные, 335/335 авто).

## Плеер (`app-egui`)
- Цепочка: транслятор (`browser_session/translator/page_subtitles.rs`, только делегирует) → сборщик `browser_session/page_subtitles/assembly.rs` (`PageSubtitleAssembly`: своя защита, отказ одной дорожки, бюджет сеанса по объявленной длине при предложении; живёт в `InstanceState` транслятора) → `IntakeNotice::PageSubtitleReady` (`Keep`) → `SessionMedia` (`session_media/page_subtitles.rs`, только `is_current`) → склад `page_subtitles/shelf.rs` `PageSubtitleShelf` (жизнь = сеанс, `start_new_session` в `on_session_opened`, поколения не трогают; замена на месте, номер поступления) → `CoreStep.page_subtitles` → `window/app.rs::run_pass` → `BrowserWindowInstance::apply_page_subtitles` → `AppState::offer_page_subtitle_shelf` → `SubtitleOwner::attach_page_tracks` (`state/subtitles/owner_page.rs`). Общие типы — `crates/app-egui/src/page_subtitles.rs` (без протокола; Debug не печатает байты и подписи).
- Каждый проход окна склад предлагается текущему медиа; `MediaPageTracks` (в `MediaSubtitles`) помнит приложенные поступления → новое поколение получает весь склад заново; склад чужого сеанса к медиа с дорожками другого склада не цепляется.
- Дорожка: `TrackDescription::Page`, `TrackOrigin::Page` (после Stream, до WebManual), `SubtitleFileOrigin::Page`; разбор лениво (как web) задачей `ParsePageTrack` (`page_load_job.rs`): содержимое побеждает подсказку, `unknown` без опознания → `UnrecognizedFormat`; кодировка `encoding_hint_for(language)`, лимиты `LoadLimits`.
- Выбор: `showing` выбирает и включает (только для медиа, конфиг не трогает), последний `showing` побеждает. Выбор зрителя за СЕАНС — `page_viewer_choice.rs` `PageViewerChoice` (по `PageSubtitleShelfId`, вне `MediaSubtitles`): после ручного выбора/выключения `showing` страницы ничего не включает и смена поколения выбор не сбрасывает; новый сеанс забывает.
- Реклама: `PageAdPresence` из `AppState::note_ad_plate`, слой не рисуется (`placed_overlay_for_frame`).
- Журнал: `Page subtitle document received …`, `Page subtitle track ready` (track, language, format, cues, selected), `Page subtitle track failed`, поле `subtitle_overlay_frames=` в `Browser playback summary` (считает отправки в рендер, может быть больше `presented_frames`).
- Тесты: сборщик `page_subtitles/assembly_tests.rs`, склад, `translator/tests/page_subtitles.rs`, `session_media/tests/page_subtitles.rs`, `state/subtitles/page_load_job_tests.rs`, владелец `state/subtitles/tests/page_tracks.rs`, GPU `tests/page_gpu.rs`, процесс `tests/browser_session_process/page_subtitles.rs` (kwin: selected=true и кадры со слоем; с рекламой 0).
- Ограничения: памяти выбора между видео нет (14); безоконный тестовый путь субтитры страницы игнорирует; очистка дорожек при следующей серии — 16.
