# Субтитры, сессия 06 (2026-10-16): встроенные дорожки MKV/MP4, вложенные шрифты, метки дорожек

План/отчёт: `user/subtitles/06-embedded-tracks.md`, `user/subtitles/results/06.md`. Цепочка на экране — `mem:subtitles/on-screen-s03`; выбор/меню — `mem:subtitles/controls-s04`.

## Решения владельца
В приложение идут пакеты ВСЕХ субтитровых дорожек (кэш каждой, мгновенное переключение, seek назад из кэша). Неподдерживаемые (PGS/VobSub/DVB/…) — в меню серыми "not supported yet". Автовыбор: при равном языке sidecar важнее встроенной. Вложения MKV больше лимита НЕ читаются в память (additive-правка патча); лимиты в конфиге (20 МБ / 100 МБ).

## Путь данных
MKV/MP4 → `symphonia-demux` (`TrackKind::Subtitle`, codec_id из `media_core::subtitle_codec`, `codec_private` = заголовок ASS, метки) → player-core `route_demuxed_packet` → `subtitle_feed` (мимо декодеров) → app-egui `SubtitleOwner` (`owner_embedded.rs`): разбор `subtitle_formats::parse_embedded_cue` → растущий `SubtitleTimeline` на дорожку (`extend` батчем за кадр, дубли после seek игнорирует timeline) → существующий презентатор/GPU-проход.

## Контракты
- media-core: `TrackKind::Subtitle`; `TrackInfo.labels: TrackLabels { language: Option<TrackLanguage> (сырой тег контейнера), title, disposition: TrackDisposition{is_default,is_forced,is_hearing_impaired,is_commentary} }` для ВСЕХ дорожек (`track_labels.rs`); `subtitle_codec` (константы + `classify` → TextRenderable/Bitmap/Unsupported); `attachment.rs` (`MediaAttachments`, `SkippedAttachment{TooLarge,TotalLimitExceeded,Unreadable}`); `Demuxer::take_attachments()` default пусто (забирается один раз; `PrefetchedDemuxer` пробрасывает, Progressive/OrderedSegment — нет → web-MKV без шрифтов).
- symphonia-demux: `DemuxerOptions::with_attachment_read_limits(AttachmentReadLimits)`; лимиты из конфига через `media_source_open::local_media::attachment_read_limits_from_config` (только local; web — дефолт библиотеки 20/100 МиБ). Субтитры никогда не якорь seek/DecodePointBefore. Пакет субтитра = keyframe, dur 0 → `None`.
- MKV-патч: `Name` дорожки → per-track тег `fastiplayer.track.name` (`FASTIPLAYER_TRACK_NAME_TAG`, читается из `metadata().current()` при открытии и кэшируется); лимит вложений — thread-local область `with_attachment_read_limits(limits, || probe)` (generic `Probe` не даёт параметров в `try_probe_new`), FileData сверх лимита пропускается `skip_data()` без чтения; исправлен `FlagDefault` (отсутствует = 1 по спецификации). isomp4: `mdhd` язык → `Track::with_language`.
- player-core `subtitle_feed/`: bounded crossbeam, никогда не ждёт; `SubtitleFeedMessage::{MediaStarted{media_instance_id, attachments}, Packet{media_instance_id, track_id, presentation_time (= Packet.pts, тот же домен, что pts кадра), duration, payload}}`; переполнение → выброс + `dropped_packets`/`dropped_media_starts`. Пакеты субтитров не тратят packet_budget, не дают backpressure, не режутся playback-window. MediaStarted — в `commit_staged_media`. `PlayerWorker::take_subtitle_feed_receiver()` (один потребитель). Ёмкость — `[subtitles].embedded_feed_capacity`, применяется при старте worker-а (после перезапуска приложения). `TrackSummarySnapshot.labels`.
- subtitle-formats `embedded/`: `parse_embedded_cue(payload, EmbeddedCueFormat::{SrtText,WebVttCueText,AssEventLine,MovText}, &EmbeddedCueLimits)` → `Cue|Empty` / типизированная ошибка. ASS: 9 полей, только Text, `{…}` вырезаются. mov_text: `styl` (смещения в символах), белый FFFFFFFF = «цвет не задан».
- subtitle-raster: `PreparedAttachedFonts::prepare` (Send, в фоне) → `install_prepared_attached_fonts` (дёшево, сброс кэшей один раз) → `clear_attached_fonts()` при смене media (FaceId не переиспользуются — tombstone `FaceSource::Detached`).
- app-egui `state/subtitles/`: `embedded_track.rs` (описание из снимка, `cue_format_for_codec`), `embedded_events.rs` (пакет → событие; без длительности → `embedded_cue_max_open_duration_ms`, отклонение от «до следующей реплики»), `owner_embedded.rs` (идемпотентный `sync_embedded_tracks` по снимку, `drain_embedded_feed` ≤2048 сообщений/вызов, сообщения будущего media и неизвестных дорожек ждут в буфере ≤4096 — труба может обогнать снимок), `embedded_fonts.rs` (фильтр font-MIME/расширений, фоновая подготовка, установка/очистка). `TrackDescription::{Sidecar, Embedded}`, `SubtitleFileOrigin::Embedded` ("embedded"), `TrackTraits{origin,is_default}`; ранжирование: язык → не-SDH → sidecar → default → порядок.
- Конфиг v15 `[subtitles]`: `max_attached_font_mb` (20), `max_attached_fonts_total_mb` (100, ≥ per-file), `embedded_feed_capacity` (4096), `embedded_cue_max_open_duration_ms` (5000).

## Сессия 11
PGS больше не серый: путь пакета `EmbeddedPacketPath::{Text, Pgs}`; на каждом `SubtitleFeedPacket` есть `read_run: SubtitleReadRun` (растёт при каждом прыжке демуксера) — `mem:subtitles/pgs-s11`. Серыми остаются VobSub/DVB/BMP.

## Известные ограничения
Seek вперёд: реплика, начавшаяся до точки прыжка, не видна (как mpv). WebVTT-в-MKV без позиционирования. С сессии 08 ASS рисуется со стилями: заголовок едет в `SubtitleFeedMediaStart.track_headers`, шрифт выбирается по имени — `mem:subtitles/ass-layer1-s08`. Дорожки, появившиеся через TracksChanged, без шрифтов. Медиа со встроенными текстовыми дорожками запускает фоновую сборку растеризатора (~90 мс). Найденный на приёмке баг MKV-патча (обязательный `EditionUID` → MKV с главами после ffmpeg-ремукса не открывался) исправлен отдельным коммитом после сессии — `mem:dependency-patches/core`.
